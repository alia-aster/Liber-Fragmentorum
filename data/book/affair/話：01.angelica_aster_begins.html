Chapter 1

戦争の章

Page 1-1

帝国歴2021年
ユラン平原
深夜

Page 1-2

冷え切った夜気の中、
帝国軍の兵士は汚れた毛布にくるまり
塹壕で身を縮めていた。
半月もの間、まともな休息を与えられず
兵たちは泥まみれの前線で
ひたすら命令を待ち続けている。
遠方の闇が、白く裂けた。
雷光ではない――神獣が姿を現した証だ。

Page 1-3

どうか、神獣がここに来ませんように。
兵たちは、 祈ることしかできない。
持ち場から逃げ出せば、敵前逃亡で銃殺。
彷徨う災害である神獣が近づけば、
死体も残らず蒸発する。 どちらにせよ、待っているのは「死」だけ。
ふたつの理不尽な絶望の間で、兵士たちの心は砕けかけていた。
塹壕の片隅に、感情の消えた瞳で
神獣の放つ光を見つめる女性兵士がいた。 海軍少尉、ユノである。

Page 1-4

海を離れた内陸の塹壕に
海軍がいるのは、乗る艦を失ったからだ。
艦を失った水兵は陸戦隊へと再編される。
ユノが最前線へ送り込まれたのは、彼女こそが艦を沈めた元凶であり、懲罰人事だと噂されていた。
「少尉。顔色が悪いな……陸戦の経験は？」
大尉が、掠れた声で尋ねた。大尉は
数多の死線をくぐり抜けてきた古参兵だ。

Page 1-5

「訓練だけです。 実戦経験はありません」
ユノは正直に答える。
「ならば、私が先陣を切る。
安心しろ。 私は不死身だ。
背中に食らいついてくれば、生還できるぞ」
「了解」
大尉の力強い言葉だけが、ユノの崩れそうな理性をつなぎ止める、細い一本の糸だった。
緊張に満ちた待機が続くと、
兵たちは攻撃命令を待ち望むようになる。ユノも凍えた指で小銃を握りしめ、
早く楽になりたいと願うようになった。

同時刻
帝都
陸軍最高司令部

Page 1-7

豪奢な絨毯が敷かれた執務室では
暖炉の火が爆ぜていた。
大陸守護伯にして陸軍大臣
ウェルキン大将は窓を見つめる。
ガラスに映るのは、自身の老いた顔と、
きらびやかな帝都の夜景だ。

Page 1-8

「君は、空想小説を読むかね？」
唐突な問いに、側近が首を振る。
「いえ、嗜みませんが……」
「私はあの手のものが好きでね。
宇宙から攻めてきた未知の敵に、
人類が一致団結して対抗する……。
そんなおとぎ話に、胸を躍らせたものだ」

Page 1-9

「現実は小説のようにはいかんな」
ヴェルキンは自嘲する。
「人類共通の天敵――神獣の脅威を
目の当たりにしてなお、
人類国家は手を取り合うどころか、
終わりなき領土争いに明け暮れている」
そこへ伝令が転がるように駆け込んできた。
「陛下より「御印」が下りました！」
その瞬間、室内の空気が凍りついた。

Page 1-10

ヴェルキンは卓上の作戦地図に拳を叩きつけた。
並み居る方面軍司令と軍団長たちが緊張に背筋を伸ばす。
「ついに、この時が来た」

Page 1-11

「この作戦は、帝国史上最大の賭けである。
だが忘れるな、我らは皇帝陛下の剣である」
「タイクーン作戦、全軍発動。
「誤った世界を正しき形に打ち直す。
それこそが我らの義務だ」
ヴェルキンは
地図上の王国領土を指差した。
「皇帝陛下、万歳！」
「万歳！」
咆哮のような唱和が司令部に響き渡った。

Page 1-12

帝国と王国はこの地に長大な要塞線を築き、それ以来、どれほど神獣に蹂躙されようと
何年も膠着状態を続けてきた。
撤退は許されず、前線では 無意味な死が積み上げられていた。
ユラン平原のにらみ合いは、 神獣の動きに
よって停戦と開戦を繰り返していたが、
その隙を突かれ、王国軍の突破を
許してしまった過去がある。
この泥沼を打破し、
王国本土への道を開く――それがタイクーン作戦の目的であった。

Page 1-13

「突撃ィッ!!」
大尉の号令と共に、
着剣した水兵たちが走り出す。
もう敵兵の顔が見える距離だ。
ユノも泥に足を取られながら駆け出した。間近で弾丸の風切り音がする。
心臓が早鐘を打ち、視界が恐怖で明滅する。
前を走る大尉の頭部が、弾け飛んだ。
隣にいた副官もまた、機関銃の掃射を受け、物言わぬ肉塊となって泥に沈む。
指揮官を失った兵士たちが一斉にうろたえた視線をユノに向けた。
「少尉！ 指示を！」

Page 1-14

上位の指揮官が死亡した今、
指揮権は自動的に彼女へと委譲される。
「わ、私が、指揮官……」
足がすくみ、声が出ない。
震えが止まらない。
叫び声と銃声が遠くなっていく。
ユノはただ、
戦場の真ん中で立ち尽くす。

Chapter 2

ユノの章

Page 2-1

帝国歴 2020
極洋
1年前
ユノにとって、世界がまだ
輝きと希望に満ちていたころ。

Page 2-2

海軍士官学校を首席で卒業したユノは、極洋艦隊への着任を命じられた。
夏以外、氷に閉ざされた海域は、
実戦とは無縁の「訓練海域」のはずだった。
だが、その幻想は王国軍の新兵器、砕氷艦隊による奇襲侵攻により砕け散った。

Page 2-3

機関不調により逃げ遅れたユノの乗艦、
旧式駆逐艦「崇敬」は、
王国海軍の悪名は
極北の地にも届いていた。
氷海に取り残された。
王国は、伝統的に海賊国家である。
略奪と奴隷狩り、拷問と虐殺による恐怖で
植民地を拡大し、栄えてきた。
住民たちは恐怖に怯え、
「敵に辱められるくらいなら、
いっそ集団自決を」
という声まで上がった。

Page 2-4

「王国側は寛大にも、
住民の安全を保証すると言っている……」
吹雪の中、敵艦隊との交渉から戻った
ユノの上官、トリスタン少佐は
蒼白な顔で告げた。
「ただし、条件がある」
「王国兵の要求は、水と食料の供出。そして若い女性による将官の「接待」だ」
「そんな条件は到底受け容れられません」
ユノの抗議に少佐は冷ややかな視線を向けた。
「それを決めるのは少尉ではない。私だ」

Page 2-5

「ユノ少尉、君は村に残り、範を示せ。君がいれば、村の女たちも従うだろう。それに――いい男がいるかもしれないぜ？」
その瞬間、ユノの中で何かが切れた。
国家への忠誠も、軍人としての誇りも、
すべてがどうでもよくなった。
トリスタン少佐は、
ユノと数名の女性兵士を置き去りにして、脱出艇で逃げ去った。
ユノはこれから、
村の娘たちと、自分自身を
王国兵に差し出さなければならない。
クソ野郎たちを逃がすために。

Page 2-6

…… クソだな。
軍隊も。戦争も。人生も。
全部、 クソだ。
これ以上、どう転がっても
マシにはならないだろう。
だったら徹底的にやってやる。

Page 2-7

「総員注目。自分の犠牲で村を守る
そんなクソみたいな事を考える奴は許さん。
我々は、我々を守るため、
我々だけで
敵艦隊の侵攻を阻止する」
ユノは残された少女たちを鼓舞し、
怒りを燃料に変えた。

Page 2-8

ユノは乗艦「崇敬」に火を放ち、
港の入り口で自沈させた。
小さな漁港を浚渫（しゅんせつ）して広げた港だ。
大型艦が侵入できる航路はひとつしかない。
そこを燃え盛る鉄の塊で塞げば、
大規模な上陸は物理的に不可能となる。
怒り狂った敵が小型の上陸艇を出せば、ユノたちは即席の火炎瓶と猟銃による
ゲリラ戦で対抗した。
氷点下の極限状態で、
女たちは三日三晩戦い抜き、ついに敵を撤退せしめたのだ。

Page 2-9

村は守られた。
だが、上官の面子を潰し、軍の失態を白日の下に晒した
代償は大きかった。
海軍は彼女の英雄的行為を黙殺し、 代わりに命令違反の罪を問うた。
ユノは罪に問われることはなかったが、 陸の最前線への配置転換を命じられた。
それは事実上の死刑宣告だった。

轟音が頭上から降ってきた。
兵士たちが一斉に空を見上げる。
雲海が割れ、巨大な影が地上を覆い尽くす。
銀色の巨鯨が、その姿を現した。

Page 2-13

放たれた熱線が、大地を一瞬で蒸発させ、
兵士たちを消し炭に変えていく。
帝国兵にも王国兵にも、
平等に死を振りまいていく。
絶対的で圧倒的な破壊の光景に
ユノは目が離せない――

Page 2-14

銀鯨の神獣が咆吼をあげた。
神獣のそばで何か、
小さなものが舞っている。
何かが神獣をかすめる度に、神獣から
体液が噴き出し、 破片が飛び散る。
あれは……何かが、神獣と戦っている？ 翼の生えた……少女？
直後。 ユノは間近で起こった
爆風に吹き飛ばされ、意識を失った。

「海軍陸戦隊消滅」

作戦地図上に置かれた帝国軍の駒が
次々と取り除かれていく。
取り除かれ、脇に積み上げられた駒は
数千、数万の兵士の命であり……
作戦の失敗を意味していた。

Page 2-16

夕闇が迫る空から、
木の葉のように何かが
ひらひらと落ちてくるのが見えた。
「……天使?」
それは、白い翼を持つ少女だった。
神獣と戦っていたあの少女に違いない。

Page 2-17

地上に激突した天使は、悲惨な状態だった。
翼は折れ、肉体は端から灰となり、
崩れ始めている。
それでも、天使は虚ろな瞳で空を見上げ、震える手を伸ばしていた。
「神獣を……殺す……」

Page 2-18

ユノは、天使を背負い上げた。
重い。 泥に足が沈む。
この翼を持つ少女は
神獣に立ち向かった。
その姿にユノは、かつての自分を――
そうなりたかった自分を重ねていた。

Page 2-19

星明かりの下、
ユノはふらつく足取りで荒野を進む。
背中の天使は何も語らない。
ただ、微かな指の動きで、
行く先を指し示しているようだった。
どれほど歩いただろうか。
ユノの前に信じられない光景が現れた。

星明かりを背に、 異様な存在感を放つ
黒い巨影がそびえ立つ。
「……どうして、こんな場所に？」
海から遠く離れた平原の真ん中に、巨大な艦が横たわっていた。

帝国海軍のユノ少尉の物語。

「何も気に病むことはありません。寄せ集めの、できそこないの世界が、消え去るだけのこと」
「幾度もこの星で繰り返された。 世界崩壊のひとつに過ぎません」
あなたはページをめくる手を止めない。ユノ少尉は天使と共に、荒野を彷徨い、あるはずのない巨大な艦を見つける。

物語は、物語のまま。
何もなかったことにできる」

Page 3-4

扉が、乱暴に蹴破られた。
あなたは顔を上げ、
やってきた人物を見つめる。
それが誰か、ひと目で分かった。
ユノ少尉だ。
あなたが読んでいた物語が、
現実の枠を越えて、侵入してきたのだ。

Page 3-5

「はぁ、はぁ、っ……！」
血と涙にまみれ、瀕死の天使を背負った
ユノ少尉が、そこに立っていた。手にした拳銃をあなたに向けている。
彼女の瞳は、絶望に淀んでなどいない。怒りと、生への執着で輝いていた。

Page 3-6

「ユノ少尉だ。戦時特別規定に基づき、この艦は帝国海軍が接収する！」
ユノは叫ぶ。喉から血が出るほどの気迫で。
震える声。 立っているのもやっとの状態。 それでも彼女は、あなたをにらみつける。
マスターが、あなたにささやく。
「……あなたは知っているはずです。
終わりまで語られることなく消えた、 無数の物語、無数の登場人物たちを」
「あなたは知っているはずです。
すべてはなかったことにされ、
記憶にしか残らない。その空しさを。
なのに、繰り返す必要などありますか？」

Page 3-7

あなたは、ユノを見つめる。
彼女の背で朽ち
灰となりかけた天使を見つめる。
ユノが、あなたに銃口を突きつける。
「お前が何者なのか、
なぜここにいるのか、
知らないし興味もない」
「だが艦にいるからには、
お前には
すべきことがあるはずだ」

戦う者の艦なんだろう！」
「戦えですって？」
マスターが冷ややかに問う。
「いったい何と？ 神獣とですか？
それとも敵国とですか？」
「何もかもだ!!」
ユノの絶叫が空気を震わせた。
「理不尽な運命も。
世界を蹂躙する神獣も。
この間違った世界のすべてと戦え！」
