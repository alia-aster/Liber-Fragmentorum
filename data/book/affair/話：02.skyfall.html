Chapter 1

スレイヤーの章

Page 1-1

深い沢の底から浮かび上がるように、
重いまぶたを開き、目を覚ました。
艦橋の外に、青空が広がっている。
ずっと荒野に横たわっていた艦が
空へと浮上したのだ。

Page 1-2

隣には、泥まみれの女性兵士が
壁にもたれて眠っていた。
海軍少尉の、ユノさん。
ぼんやりとした頭で、記憶の糸をたぐる。
ユノ少尉は墜落した私を背負って、
艦まで運んでくれたのだ。
私は銀鯨の神獣に挑み
空から墜ちた。

Page 1-3

起き上がろうとするが、
身体が言うことを聞かない。
指先も、足も、身体も、胸のあたりまで、
感覚がない。重い石のようだ。
これが、林檎をかじった代償。神獣に立ち向かい、
力を振るった末路。
いずれ私も、
全身が石になり砕けて死ぬ。

Page 1-4

不思議と、恐怖はなかった。
私の物語は、ここで終わる……それが、少しだけ寂しかった。
ふと、視界の端に
誰かが立っているのに気づいた。 大きな、古い本を抱えた人。
ひび割れた唇で私は微笑んだ。
「……よかった」
声は、ひどくかすれていた。

Page 1-5

「あなたが、この艦を
空に戻してくれたんですね。
本当によかった……」
もう指一本動かすことはできない。
けれど、この人なら。
この不思議で、静かな瞳を持つ人になら。
「どうか、私の代わりに……。
この艦で神獣を殺して……」

Page 1-6

「駄目だ」
はっきりとした、強い声だった。
私を見つめるその瞳には、
熱い輝きが宿っていた。
「自分の物語を、手放すな」
その言葉が、私の胸に突き刺さった。

Page 1-7

荒野で絵本を破り捨てられたあの日、
私は誓ったはずだった。
「私の物語は誰にも奪えない」と。
それなのに、私は迫る死を理由に、
大切なものを手放そうとしていた。
スレイヤー
「神獣殺しの物語」は、
私が選んだ、私の物語だったはずだ。

Page 1-8

その人の瞳から涙がひとしずく零れて、
私の頬に落ちた。
熱い――
涙が触れたところで、パキンと
小さな音が響く。
冷え切った私の全身に、熱がひろがっていく。
硬く冷たかった皮膚が崩れ落ちていく。
その下から現れたのは、温かい血の巡る柔らかい私の肌だった。

Page 1-9

「何が……起こっている……？」
目を覚ましたユノ少尉が声をあげた。
その声に応えるように、
ひとりでに、大きな本が開いた。 次々とページがめくられていく。
「ネクタル、あるいは黄金の血」
そう書かれたページで止まった。

Page 1-10

液化した神性。
呪いを退け、不老をもたらす。
かつて世界を統べていた
黄金王の血統には、
その血にネクタルを含むものが
ごく稀に現れる。
もしくは崩壊後の神獣より、
微量を抽出可能。

Page 1-11

ユノ少尉が大きな本を抱えた人に
鋭い視線を向ける。
「……皇帝の血族には見えない。神獣のたぐいじゃないだろうな？」
その声を遠くに聞きながら、
私は、自分の温かい両手を見つめていた。
動く。指が曲がる。鼓動が聞こえる。
助かるかもしれない。
石になって砕けるのではなく、
明日も神獣と戦えるかもしれない。
希望の光が差し込んでいた。

Page 1-12

数日後。
戦艦「冒涜」の甲板。
空を飛ぶ艦の上では、
荒野を吹く乾いた砂混じりの風とは違う、冷たくて気持ちのいい風が吹く。
私はすっかり、 元の温かい身体を
取り戻していた。
白い翼も、ふわりと風をつつみ、
まるで生まれ変わったように、
身体も心も軽かった。

Page 1-13

「あなたのおかげです......」
命を救われ、人としての温もりを
取り戻すことができた。

Page 1-14

私が救われたのは、奇跡だ。
「恩に報いたいのです。救われた命をあなたのために使わせてください」
そう願う私の想いを、あなたは拒絶した。
「君の物語は、君のものだ。
自分の物語を、 手放すな」

Page 1-15

私はその意味を考えた。
私を従順な兵として扱うつもりも
便利な道具にするつもりもない。
ひとりの人間として、自分の意志で生きろと
言われているのだろう。
「……分かりました」

Page 1-16

私は誰かの所有物じゃない。
かわいそうな、見捨てられた孤児でもない。
世界を、他者を、ありのままに受け容れて、その上で、不条理な神獣に立ち向かう。
「もう二度と、そんなこと言いません」
私はまっすぐに、 あなたを見つめた。
神獣を殺し、世界を救う。
それは私が選んだ、私自身の物語だ。

Page 1-17

世界は、理不尽に満ちている。
神獣、終わらない戦争、憎しみの連鎖。 すべてを手放したくなる時もある。
それでも、私は私の物語を捨てない。
私の物語を、
あなたが見守ってくれるから。
「行きましょう。私たちの……戦いへ」
黄金の朝日を浴びて、艦は空を征く。背中の翼が、光を弾いて輝いていた。

Chapter 2

ヨアヒムの章

Page 2-1

潮風が、泥でひび割れた頬をなでた。
空中戦艦「冒涜（ブラスフェミィ）」は、
帝国領内のセルヴァ軍港へ入港した。
灰色の雲を割り、船体が降下していく。
地上では、豆粒のような人間たちが
パニックで慌てふためくのが見えた。
無理もない。空を飛ぶ戦艦など。
この世界の常識には存在しないのだから。

Page 2-2

目立ちたくはないが、艦を維持するには
どうしても軍港の設備が必要だった。
水、糧食、燃料、弾薬、装備と通信手段。
莫大な資源を食いつぶす軍艦を養えるのは、
海軍の兵站（ロジスティクス）だけだ。
泥にまみれた陸戦隊の軍服のまま
私はひとり、 タラップを降りた。

Page 2-3

「いやあ！ よく生きて戻ったユノ少尉！」
出迎えたのは吐き気を催すクソ野郎だった。
「トリスタン少佐」
極北の氷海で私と村の女たちを囮にし、 自分だけ脱出艇で逃げ延びたクズ。
私をユラン平原の死の塹壕へ送り込んだ
元凶でもある。

Page 2-4

「見事な戦果だ！
まさか、空飛ぶ艦を接収するとはね。
ユノ少尉は我が艦隊の誇りだよ！」
トリスタンは、 手の平を返したように
私を褒めそやし、気安く肩を叩いてきた。 その指をへし折りたい衝動を、
なんとか押さえつける。

Page 2-5

「ありがとうございます、少佐殿」
「うむ。君は私の部下だ。よってあの艦は
私の艦隊に編入させてもらう。 君が沈めた
旧式艦「崇敬」の代わりにな！」
厚かましいにも程がある。
それをいいことに、この男は冒涜を
我が物にしようとしている。
「少佐殿の……ご采配のままに」
陸戦隊の少尉が接収した謎の艦の扱いなど、殺意をひた隠し、深く頭を下げた。
軍の規定には存在せず、
上層部も揉めているはずだ。

Page 2-6

数日後。 私は重厚なマホガニー製扉の
前に立っていた。
海軍儀典局。
ここは観艦式の取り仕切りや、来賓接待、礼服のデザインを決める部署である。
陸軍には無い。
海軍が皇帝直属の軍として創設され、 宮廷文化と深く結びついているがゆえの
お飾り部署だと思われている。
だが、現実は違う。
儀典局の実態は、
宮廷とのコネクションを使った裏工作にあるのだと、士官学校時代の
恩師から聞いたことがあった。

Page 2-7

「お待ちしていましたよ、 ユノ少尉」
執務室の奥で、年齢不詳の男が微笑んでいた。
ヨシュア・ヨアヒム海軍大佐。 物腰の柔らかい紳士の皮を被っているが、 裏では 「毒蛇」と呼ばれていた。
油断すれば、 丸呑みにされる。
一通りの社交辞令を終えると、
私は軍服のポケットから、 小さなガラスの
小瓶を取り出し、 机の上に置いた。
中には、金色の液体が揺らめいている。

Page 2-8

「これは?」
「ネクタル。あなた方が
「黄金の血」と呼んでいるものです」
ヨアヒム大佐の細い目が、 見開かれた。
「確認してもよろしいですかな？」
「もちろん」
大佐は小瓶の蓋を開け、付属のガラス棒で
一滴だけ自らの舌に落とした。
次の瞬間、彼の顔色が変わった。
平静を装っているが、 指先が震えている。
本物だと気付いたのだ。

Page 2-9

「「誰」が、これを？」
声の温度が下がり、 尋問者のそれになる。 皇帝の血筋との関連を疑っているのだ。
「ご安心ください。
高貴なお方のものではありません。
これは人工的に合成できる――
製法をお渡しできます」
製法はあの分厚い本に書かれていた。 神獣由来の原料は、
楽に入手できるものではないが、
黙っておく。

Page 2-10

「……何が望みですか？ 昇進？ それとも、あの空飛ぶ艦ですか？」
ヨアヒム大佐が、 腹の底を探ってきた。
「新艦隊の創設です」 私ははっきりと告げた。
一瞬の沈黙。
やがて大佐は、腹の底から愉快そうに
声を上げて笑いだした。
「不可能だ。たとえ天が墜ちようとも、
そんな要求が通るはずがない」

Page 2-11

「とうに、天は砕け墜ちました」
私は真顔で答えた。
巨大な神獣が、空から地上を蹂躙する。 この世に最早、崇める天などない。
「ブラスフェミィは、神殺しの艦です！」
私は机に身を乗り出した。
「対神獣特務艦隊の創設を
考えております」

Page 2-12

私の話を聞いた後、
大佐は眼鏡の位置を直し、肩をすくめた。
「面白い話だ。
だが、我々にそれほどの権力は無い。
いや、皇帝陛下にすら不可能だ」
「陸軍と諸侯にばら撒いている。
対神獣の防衛予算。それらを独占できると
したらどうでしょう？」

Page 2-13

室内に重い沈黙が降りた。 ヨアヒム大佐は、
私を値踏みするように見つめる。
「ユノ少尉。 私個人は、
あなたの才気を好ましく思います。 ですが……宮廷では疎まれる」
私は唇を強く噛んだ。
交渉決裂か。 別の手を探すしか
「良い人物を紹介しましょう。
宮廷政治に長けた、優れた人物を」

Page 2-14

「え……？」
「礼は要りません。代わりに……ネクタルの生産を、
独占させてください」 大佐が口元をつり上げた。
条件としては悪くない。 いや、むしろ好都合だ。 工業的に生産が可能なら、 天使たちの数を増やせる。

Page 2-15

ネクタルを大佐に 「握らせる」ことで、
我々に手綱を付けたという錯覚を
与えることも可能だろう。
「もちろんです。
……よろしくお願いいたします」 私は、毒蛇に深く一礼した。

Chapter 3

天使隊の章

Page 3-1

ヨアヒム大佐に紹介された人物は、私の想像を越えた大物だった。
帝都の閑静な一等地に建つ、広大な私邸。
そこに待っていたのは、
海軍参謀総長にして皇帝の血族、
ハリエット・ヒューム少将だった。
海軍の式典で、一度だけ、遠くから
見かけたことがある。伝説的な女傑として海軍では人気があった。

Page 3-2

「楽にしたまえ、少尉。
タイクーン作戦での活躍は聞いている……」
ヒューム少将は、くつろぎながらも
鋭い眼光で私を見つめた。
「その前の 「やんちゃ」 もな」
心臓が跳ねた。
極北の海で、上官の命令に背き、
軍艦「宗教」を自沈させたことだ。

Page 3-3

「王国軍の上陸を阻むために
そこまでするとは、
なかなか気合いが入っている」
彼女は、北方でのゲリラ戦の顛末を
熱心に聞きたがった。
叱責は免れないと思ったが、
少将の元には笑みが浮かんでいた。

Page 3-4

私が極寒の氷点下で、村の女たちを率いて
火炎瓶と猟銃で王国軍を退けた話を、
少将は膝を叩き、歓声を上げながら
聞いていた。
話を終える頃には、すっかり
私たちは打ち解けていた。

Page 3-5

「素晴らしい! それでこそ海の女だ。
無能な男どもの顔色を窺って、
自分の信念を曲げるような輩など、
何の役にも立たんからな」
「対神獣艦隊……良いではないか。
ネクタルの生産には、
「対神獣戦力。 そして未知の飛行戦艦。 神獣の死体の一部が必要なのだろう？」
「そのとおりです」
老朽艦を一隻沈めた代償など、
比較にならんほどの戦果だ」
少将は熱い眼差しで私を見た。

Page 3-6

ヒューム少将は、私の母よりも年上とは思えないほど、若々しく、美しかった。
美貌の維持への執念があれば、
ネクタルの私的利用も視野に入れているはずだ。
「対神獣戦力も、ネクタルも、
我々海軍で独占する。陸軍の老いぼれ共に、一泡吹かせてやろう」
ヒューム少将は、その場で書類に流れるようなサインを書き込むと、
部下を呼んで、
皇帝家の 「御印」を押させた。

Page 3-7

「「天使隊」を発足する。
予算も指揮系統も艦隊相当の、
対神獣部隊だ」
「ありがとうございます。閣下」
想像をはるかにこえる待遇だ。
「これでもう、
誰も君たちに手出しはできん」

Page 3-8

「君の階級も、この際だ。
少佐まで引き上げよう。
独立部隊を預かる者が少尉では、
示しがつかん」
少佐。
トリスタン
極北で私を見捨てたクソ野郎と
同じ階級だ。
だが、私は首を横に振った。
「階級は今のままで結構です」

Page 3-9

「ほう？ 欲のないことだ」
「私は、指揮官の器ではありません」
脳裏に、ユラン平原の血と涙の臭いが蘇る。
頼りにしていた大尉の頭が弾け飛び、
指揮権が私へと移譲されたあのとき
部下から縋るような視線を向けられても、
恐怖で足がすくみ、
声すら出せなかった。
あの日の無力な自分を、
私は許せない。

Page 3-10

ヒューム少将はソファに深く身を沈め、 リラックスした様子で語り始めた。
「私の先祖は、皇帝家でも特異な
死刑執行人の家系でね」
ぽつりと漏れた言葉に、 私は息を呑んだ。
「皇帝一族の首を
刎ねることができるのは、
同じ高貴な血を引く者だけ――過去にはそう定められていたのだよ」
「それゆえに我々は、一族の汚れ仕事を
代々引き受けてきた」
少将は、楽しげに喉の奥で笑った。

Page 3-11

「当然、他の皇族や貴族からは畏れられ、 ひどく軽蔑されたものだ。 だが我々は、その忌まわしいイメージを逆手に取り、
権力を手に入れた」
少将は私を見すえる。
「ユノ少尉。これからの君たちも同じだ。正体不明の飛行戦艦と、天使たち……。
周囲からは蔑まれ、薄汚い怪物と
唾を吐かれるだろう」
「だが、それは君たちが持つ力への圧倒的な恐怖からくるものだ」

Page 3-12

世界から見捨てられ、人を捨てた
天使たちの部隊、天使隊の結成は、少将の言う通り、茨の道に違いない。
「それでも、戦うのだ」
少将の言葉には、 熱があった。
神獣から世界を取り戻すための切実な願い。
「ただし、ひとつ忠告しておく」

Page 3-13

「君たち「天使隊」の存在が
我が海軍、 および帝国にとって
害となれば、容赦はせん。
私自らが手を下すことになる」
死刑執行人の血を引く女傑の、 通告だった。

Page 3-14

私は背筋を伸ばし、一片の恐れもなく、
少将の冷たい目を見つめ返した。
ここで怯むくらいなら、
初めからこの狂った提案などしていない。
「分かっております。ヒューム少将閣下」
「期待している。ユノ少尉」

Page 3-15

重低音が空気を震わせる。
軍港の係留施設から離れ、
ブラスフェミィが空へと浮上していく。
海軍を味方につけ、私たちは戦うための手段を手に入れた。
理不尽な運命も、世界を蹂躙する神獣も。
この間違った世界のすべてと
戦うための、部隊。

Page 3-16

私は軍服の襟を正した。
ブラスフェミィが空へと昇っていく。
神獣が支配する、空へ。
ここからが、私の――私たちの始まりだ。

Fin.
