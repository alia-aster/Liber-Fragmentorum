Verse: 白城
Subsection: Ｂ

謳：01.騎士の神獣

Chapter 1

[フィルター：青]
「ちから」の章

Page 1-1

[フィルター：青]
むかしむかし
ユーファリアが
七つの王国に
分かれていた時代のお話です。

Page 1-2

[フィルター：青]
森のそばの小さな街に、
「フィー」という小さな女の子が
両親と暮らしていました。
フィーは不思議な
「ちから」を
持っていました。
フィーが水やりをした畑は
他の畑よりもよく育ち、フィーが植えた鉢植えは
他よりも大きな花を咲かせるのです。

Page 1-3

[フィルター：青]
フィーが三歳の時のことです。
生まれた時から一緒だったフィーの愛犬が
ついに動かなくなってしまいました。
「生きているものは必ず死ぬ。
これはどうしようもないことなんだ」
泣きじゃくるフィーに父はそう言いました。
翌朝。父のもとに、フィーと老犬が駆けてきました。 すっかり元気になった
老犬を見て父は目をまるくしました。
それが、フィーの力でした。

Page 1-4

[フィルター：青]
死と生の境をこえることは
あってはならないこと。
そんなことができるのは神だけです。
「強い力は、強い力を呼ぶ。
決してその力を使ってはいけない」
父はそうフィーに言い聞かせると、
老犬を人に譲ってしまいました。
フィーは、大好きだった庭仕事も
生き物に近づくことも禁じられました。
生命であふれた森にでかけることも
許されません。

Page 1-5

[フィルター：青]
フィーの母が病に倒れました。
日に日にやつれていく母を見て、
フィーは悲しくてたまりません。
ある夜のことです。 フィーの隣で寝ていた
母の呼吸が止まりました。
フィーはとうとう
力を使ってしまいました。
使わずにいられなかったのです。

Page 1-6

[フィルター：青]
力を使い、
つかれきったフィーは
眠ってしまいました。
翌朝目が覚めると
母親はすっかり元気になっていて、
フィーのために
食事を用意していました。

Page 1-7

[フィルター：青]
父は、フィーが力を使ったことに
気づいていたはずです。
ですが、 何も言いませんでした。
私の「ちから」は
このためにあるのだわ
フィーは自分の力を、みんなのために
役立てようと決意しました。
この力は、きっと、そのために
女神さまから与えられたものなのです。

Page 1-8

[フィルター：青]
次の日の事です。 小さな街は炎に包まれました。
大きな銀色の鯨が天からあらわれ、硫黄と火の雨を降らしたのです。 人々は何も出来ずに逃げ惑い、炎に巻かれて焼け死んでいきました。

Page 1-9

[フィルター：青]
子供も大人も、男も女も、
病が癒えたばかりの母も、優しい父も
みんなみんな焼け死んでしまいました。
炭となってしまった両親には
フィーの力も通用しません。
それから、どこをどう逃げ延びたのかは
覚えていませんが、気がつけば
フィーは丘の上に立って、
焼ける街を見下ろしていました。

Page 1-10

[フィルター：青]
「強い力は、強い力を呼ぶ」
父の言葉がフィーの頭の中で
ぐるぐると回りました。
私のせいだ……。
フィーは自分を責めました。
あの力を使ったせいで恐ろしい怪物――
神獣を呼び寄せてしまったのです。
銀鯨の神獣は、街を焼き尽くすと 満足したように焼け跡の上に巨体を
横たえました。

Page 1-11

[フィルター：青]
日が沈み、夜が近づいていました。
それでもフィーはどうすることもできず
丘の上で立ち尽くしていました。
銀鯨の神獣が叫び声をあげるのと、
巨大な火柱が立ち上がるのは同時でした。
右手にも左手にも炎をまとう剣を持ち、
神獣と戦う騎士がいました。
街を焼いた神獣が、 今は
騎士に焼かれ蹂躙されているのです。

Page 1-12

[フィルター：青]
フィーは噂に聞いたことがありました。
あれは竜の国にたった一人しかいない
「神獣殺しの騎士（スレイヤー）」 です。
神獣の炎と騎士の炎がぶつかりあい、
その熱は、離れた丘の上にいるフィーの頬に
まで伝わってきました。
やがて、銀鯨はその色を失い黒煙をあげる
瓦礫の山となりました。
騎士が勝利したのです。

Page 1-13

[フィルター：青]
夜明けと共に
国の兵隊がやってきました。
死んだ神獣をかたちづくるオーパーツから
価値のあるものを回収するためです。
フィーは兵隊たちに保護されました。
生きた人に出会えて、ようやく助かった
実感が湧いてきました。
フィーのそばに神獣殺しの騎士が
やってきました。

Page 1-14

[フィルター：青]
近くで見る神獣殺しの騎士は
とても大きく、とても年老いていました。
亡くなったフィーの祖母よりも
うんと年上に見えました。
神獣殺しの騎士は、 フィーに向かって
口を開きました。
それは、フィーが期待した言葉とは
違っていました。

Page 1-15

[フィルター：青]
「お前の力は、古の神の力だ。
その力が神獣を呼びよせた。
この災いはお前が招いたのだ」
フィーは立っていられなくなり、
座り込みました。
人を助けられると思ったちからで、
父も母も、街中のみんなを殺してしまった。
ぜんぶ、ぜんぶ
わたしのせいなんだ。

Chapter 2

[フィルター：青]
老騎士の章

Page 2-1

[フィルター：青]
老騎士エバンスは老いてなお、
竜の国で最強の騎士だった。
誰もが老騎士の武勇を讃え、 老騎士の庇護下にある事に感謝した。
老騎士が戦う相手は人ではない。
――彼に敵う者などいない――
老騎士は竜の国でたったひとり、
「神獣殺しの騎士（スレイヤー）」 であった。

Page 2-2

[フィルター：青]
騎士の左目は白く濁り、 左腕は十分に
動かなかったが、それでも炎の双剣を手に、
神獣を屠ることができた。
神獣に滅ぼされた街で、 たったひとり
生き残った娘を、老騎士は養女にした。
娘の父親と、 祖父と、曾祖父は
老騎士の友人だった。
「騎士よ、立派なものだのう。 民も皆、
口々にお前を褒めそやしておるぞ」
騎士の主君はからからと笑った。

Page 2-3

[フィルター：青]
「あの娘…… フィーをひきとったのは
哀れみではありません」
と、老騎士は 「主」 に告げた。
フィーの「ちから」は危険すぎます。
手元に置き、厳しく躾けなければ
なりません」
「フィーが死んだ犬を蘇らせた」と
フィーの父から、 相談を受けたことがある。
その「ちから」は神の領域に属する。
使えば神獣の気を引く。

Page 2-4

[フィルター：青]
――力を使わないこと。
――都から出ないこと。 ふたつの約束を守れば、
あとはフィーの好きにして良い。
そう言ったにもかかわらず
フィーは、召使いよりも、よく働いた。
捨てられる事を恐れているのだろう。
老騎士はフィーを軽蔑した。
甲斐甲斐しく老騎士の世話をやこうとする
フィーの手をはねのけ、 老騎士はフィー
との関わりをできるだけ避けた。

Page 2-5

[フィルター：青]
フィーが、剣を学びたいと言ってきた時も無視した。
弟子たちに稽古をつけている時
そばでガラクタの剣 (焼けた街で拾ったものだ)をふるっていても、見て見ぬふりをした。
同じ年頃の悪童から、心ない言葉でからかわれる場面を見たこともあるが、
これにも何も言わなかった。
それなのに――
フィーは老騎士のそばにいたがった。
何が楽しいのか、いつも嬉しそうに
その日の出来事を報せに来た。

Page 2-6

[フィルター：青]
老騎士はフィーの愛嬌と信頼が
煩わしくてたまらなかった。
「我が主君にお前を紹介する。
非礼のないよう身を清め、準備せよ」
そろそろ頃合いか……。
老騎士はフィーを呼び出した。
そう言うと、フィーは満面の笑顔で
支度をはじめた。

Page 2-7

[フィルター：青]
主君の御座は、都で最も古い建物
白き女神アシュタルの神殿にある。
正装させたフィーを伴い、 神殿の最奥を 訪れると、暗闇の奥で巨大な何かが、 長い首をもたげた。
そばでフィーが息を呑むのがわかった。

Page 2-8

[フィルター：青]
「我が主君であらせられる」
宝物の中に寝そべる巨大な竜に老騎士が一礼すると、 フィーも深々と頭を下げた。
竜の国の竜は、国の守護者であり支配者である。
老騎士は人の王ではなく、 この古き竜に仕えていた。

Page 2-9

[フィルター：青]
《この娘か。「ちから」を持つのは》
騎士の頭の中で、男とも女ともつかぬ声が響いた。
神の声だ。

Page 2-10

[フィルター：青]
フィーに竜の声は聞こえていない。
不安げに老騎士の顔を見つめている。
《左様でございます》
老騎士も、頭の中だけで返事をした。
《我の力はお前の力でもある》
老騎士が老いたのは、竜が老いたからだ。
神獣殺しの力は、老騎士がこの竜から
授かった力だ。
《ならばこそ、この娘の「ちから」を
捧げましょう》
老騎士が、 フィーをひきとったのは
竜の生け贄にするためだった。

Page 2-11

[フィルター：青]
フィーを見つめる竜の巨大な瞳が
すっと細くなった。
《まだだ……。この娘の「ちから」は
まだ大きくなる。 果実が熟すまで待とうぞ》
「帰るぞ」
そうして、老騎士はフィーとともに
神殿をあとにした。
「立派な竜でございましたねえ！
それにあの宝物の山！」
老騎士の心の内も知らず、フィーは
歓声をあげた。

Chapter 3

[フィルター：青]
竜の国の章

Page 3-1

[フィルター：青]
老騎士の身体は限界に近づいていた。 骨は軋み、内臓も朽ちていく。
口にできるものは薄い粥だけだった。
早朝、 身体をほぐそうと立ち上がると 胸に激しい痛みを感じ、うずくまった。
(忌々しい身体だ……)
老騎士の身体は、とうに寿命なのだ
竜に生け贄を捧げなければ死は免れない。
煩わしい子供を側に置いているのは
竜と共に永遠の命を得るためだ。

Page 3-2

[フィルター：青]
気がつくと、 寝台の上に寝かされていた。
ここ数年なかったほど具合がいい。
枕元でフィーがせっせと看病をしていた。
「騎士様。目が覚めたんですね!?」
老騎士を見つめるフィーの瞳から
大粒の涙がこぼれた。
「……なぜ泣く？」
「もうひとりは嫌です。
家族を失うのは、怖い」
家族だと？ 老騎士は狼狽した。
自分とこの娘が家族だと言うのか。
竜への供物とするため
置いているだけだというのに？

Page 3-3

[フィルター：青]
「これはただの病ではない。
治療のすべはない」
そう口にすると、
「……」
と言ったきり、フィーは
ふらりとよろめき老騎士にもたれかかった。
顔色が悪い。
この娘がこれほど憔悴している
ところなど見たことがない。

Page 3-4

[フィルター：青]
「「ちから」を使ったな」
老騎士の身体にあふれる活力はフィーの
「ちから」によるものなのだ。
「ごめんなさい」
かすれた声でつぶやいたきり、
フィーは深い眠りに落ちた。

Page 3-5

[フィルター：青]
老騎士の頭に竜の声が響く。
《熟したな。我に果実を捧げよ》
竜は感じたのだ。
フィーの「ちから」 が十分に熟したことを。
老騎士は騎士鎧と炎の双剣を身につけた。
主君たる竜の前に出るための正装だ。
倒れたフィーを軽々と抱き上げると
老騎士は神殿に向かった。

Page 3-6

[フィルター：青]
神殿の最奥、竜の間には供犠台が置かれ
竜が舌なめずりして待ち受けていた。
竜は「ちから」に満ちたフィーの肉体を
前に獣じみた声をあげる。
《供物を捧げます》
竜は返事もせずに騎士の身長よりも大きく
口を開き、 フィーに喰らいつこうとした。
そこに隙が生まれた。
老騎士は炎の剣を抜くなり、
竜の目に突き立てた。

Page 3-7

[フィルター：青]
竜が悲鳴をあげる。
同時に、老騎士の白く濁った片方の目から
熱い血が噴き出した。
《なぜだ！》
《気が変わりました》
老騎士は神獣を見る力を得るため、
これまで多くの生け贄を竜にささげてきた。
神獣から民を国を守るためには
やむを得ない事だと思っていた。
だが、何十年と繰り返すうちに、
自分の心の在処が分からなくなっていた。

Page 3-8

[フィルター：青]
そこに、フィーは現れた。
衰え行く己の生だけを見つめ、
虚ろだった老騎士の心に火を灯した。
《小娘にほだされたか！
竜の国が終わるぞ！ 我が力なければ
国土は神獣に蹂躙されるであろう！》
左目から血を流しながら竜が絶叫する。
それで良い。 人の命を贄として竜の巨体を
維持してきた国など、 とっくに終わって
いなければならなかったのだ。

Page 3-9

[フィルター：青]
「騎士様！」
目を覚ましたフィーに、
老騎士は「逃げろ」 とだけ指示をした。
「加勢いたします」
フィーは竜がベッドにしていた宝物の中から
大小の宝剣を拾いあげると、竜に向けて
構えた。老騎士と同じ構えだった。
「フィー、ばかな娘だ……」
ふふ、とフィーは笑みをもらした。
「はじめてフィーと呼んでくれました」

Page 3-10

[フィルター：青]
「今のフィーの力では竜に敵わぬ」
だが、 手はある。
老騎士は腰に残ったもう一振りの炎の剣を
抜き自らの胸に突き立てた。
その燃える刃先が心臓に達する。
「騎士様！ 何を！」
フィーが悲鳴をあげる。
《我が傷はお前の傷となるが、
お前の傷はお前のもの。忘れたか？》
竜の声が老騎士の頭の中に響く。
《それとも、 自害して詫びるつもりか？》

Page 3-11

[フィルター：青]
くだとしても敵わぬぞ。
我が炎にて奥まで焼き尽くしてやる。
「騎士様……」
フィーは理解した。
老騎士は命を絶つことにより、
自らに宿った生命の「ちから」――
フィーから受け取ったものを
フィーに返したのだ。

Page 3-12

[フィルター：青]
フィーの目に涙が浮かんだ。
「ちから」を使えば、
必ず悲しい出来事が起こる。
フィーが手にした両手の剣が緑の蔓に覆われ
花が咲き乱れる。あふれる生命の力が、 生命なき武器にまで生命を与えていた。
《なんと強い「ちから」か……その「ちから」、喰わせろォ！》
竜が首をもたげ、フィーへと襲いかかる。

Page 3-13

[フィルター：青]
――神を殺せるのは、神の力のみ。
「この力ならば！」
フィーは花咲き誇る双剣をふるった。 老騎士と同じ構え、同じ呼吸で。
フィーは、ずっと老騎士を見てきた。
神獣に焼かれた街で出会った日からずっと。

Page 3-14

[フィルター：青]
目に焼きつけてきた老騎士の剣さばき、
身のこなし、 所作の全てが、
今のフィーに宿っている。
ほとばしる生命の「ちから」に満ちた
フィーの身体から、老騎士と
寸分違わぬ双剣技が繰り出され、
稲妻のような速度で
十字に竜の胸を切り裂いた。

Page 3-15

[フィルター：青]
美しいな。フィーの力は……。
これこそが本物の神の力なのだろう。
竜の巨体が
落ちていく。
その胸から流れる血に宝物が沈んでいく。
竜の傷は、私の傷となる。
だが、既に私は胸を切り裂いていた。
そうか。
フィーが竜の胸を狙ったのは、
……
これ以上私の身体を傷つけぬためか。 なんと優しい娘だろう……。

Page 3-16

[フィルター：青]
「騎士様……逝かないで」
フィーが、私の手をとった。
頬に落ちたフィーの涙は温かかった。
もう間に合わない。
私の命は竜とつながっている。
竜が死ねば、私も死ぬ。
「感謝するぞフィー」
フィーと出会えたことで、
竜の道具ではなく、
人として死ねる。

Page 3-17

[フィルター：青]
「我が名を受け継げフィー。いや
「神獣殺しの騎士（スレイヤー）」 オフィーリア」
アシュタル神殿の古き竜を屠った
オフィーリアには十分にその資格がある。
「なります。
私もエバンス様のような
立派な騎士に」

Page 3-18

[フィルター：青]
お前ならなれる。
私よりもよほど立派な騎士に……
新たな神獣殺し（スレイヤー）の誕生を
見届けることができた。
もう思い残す事はない……。
Fin.
