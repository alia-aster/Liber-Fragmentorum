Chapter 1

Occupation

Page 1-1

じゅうたん
真っ赤な彼岸花の絨毯がゆれている。
私はあぜ道となっている土手に身を隠し、
息を殺して、 彼岸花の向こうを
見つめていた。
燃えるように咲き誇る彼岸花の中で、
裸の女に帝国兵がまたがり、
女の首をしめている。
やがて、女の白い手がだらりと下がり、
女は動かなくなった。

Page 1-2

帝国兵は、 共通語で悪態をつき、
女にツバをはきかけると、 私がいるのとは反対の方角へ。 大股で去って行く。
帝国兵が去ってからも、
陽が暮れるまで私は動けずにいた。
目の前で人が死ぬのを見るのは、 初めてだった。
人が人を殺すところを見るのも、 初めてだった。
どうしてこんな事を······
怒りと恐怖、悔しさが ない交ぜになって、 手が震えた。

Page 1-3

オウハラ
邑原は小さな島だ。
初まりは、嵐で航路を外れた帝国の軍艦が 立ち寄ったことだった。 困った船乗りは
助ける。 それが、 島の習わしだ。
島人は帝国兵を歓待し、 気前よく水と食料を
提供した。 艦長はいたく感激し、
「この礼は必ず」 と約束して、島を去った。
しばらくして、たくさんの軍艦が
乗り込んできた。
それは島への恩返しのためではなく、
帝国軍の基地を建設するためだった。

Page 1-4

帝国の権威を笠に着て、 帝国兵は
王様気取りだった。 島の人々の家を奪い、 田畑を荒らし、男たちを基地建設のために
働かせ、女たちに乱暴した。
すりよる者に帝国は物資を与え、
逆らうものは殺した。 島で一番大きな
広場には、見せしめのため首が並べられた。
邑原の港はひとつしかない。 港を
帝国に押さえられれば、船を出すことも
できず、助けも呼べない。
このままでは邑原は帝国に吸い尽くされ、
遠からず滅ぶだろう。 それなのに、
私には何もできない。

Page 1-5

数日後の夜。
父が家に帝国兵を連れてきた。
「彼はお前の事を気に入ってね・・・・・
話があるそうだよ」
あらわれた帝国兵を見て、 足がすくんだ。
彼岸花の中で人殺しをした男だった。
父は、私をこの男に一
帝国に売るつもりなのだ。私は絶望した。
「支度をして参りますので・・・・・・」
どうにかそう言うと、私は奥へ下がり 家の裏口から山へと駆け出した。

Page 1-6

「死ね!死ね! みんな死んでしまえ!」 呪詛を吐き出し、 真っ暗な山道を
駆けのぼる。
やがて、幾重ものしめ縄が張られた
場所に出た。 縄には無数の
草鞋がかけられている。

Page 1-7

この犬は人が入ってはならない禁足地
ここで草鞋を脱ぎ、 縄にかけて入るのが 掟だ。そうしなければ、 禁足地から
出られなくなると言われている。
構うものか。
私はそのまま土足で禁足地に踏み込んだ。 二度と、あそこには戻りたくない。

Page 1-8

やがて私は、古い社にたどり着いた。
冷たい夜気が肌を刺す。
ここにも、彼岸花が咲いている。
暗闇の中、浮かび上がる灯火のようだ。
土足で社の中に踏み込むと、
その奥に祀られているもの
神骨を両手で持ち上げた。
神骨は人間のものよりも、 ひと回り以上も大きな頭蓋骨だ。

Page 1-9

意を決し、巨大な神骨を頭にかぶると、
神骨の眼窩を通じて、
見たことのない風景が見えた。

Chapter 2

Manifestation

Page 2-1

神骨をかぶると、眼前に恐ろしくも
美しい景色が広がった。

Page 2-2

水が流れる平野、石造りの建物。
すぐそばに誰かが立っている事に気付いた。
輝く蝶が舞い、 青い彼岸花が咲いている。 彼岸の景色だ。
そちらに目を向けた途端、
私の眼球が破裂した。

Page 2-3

美しい女性の姿が目に焼き付いている。
一言い伝えは本当だった!
私は神を見たのだ。
私は平伏した。 目が潰れたはずなのに、
神の放つ輝きが、 香りが、 実在感を持った
映像として私の脳に突き刺さる。
あすたりのおおかみ
「掛けまくり畏き明日粛大神!
かしこ かしこ まお
恐み恐みも、自す・・・・・・」

Page 2-4

《フツーに話してくれていいよ》 神の声を聞いた途端、
暴風の中に 投げ込まれたように全身が震えた。
耳から血か何かが吹き出し、
私は聴力を失う。
それでも、 神の声は私の脳に直接響いた。
《叶えたい願いがあるのでしょう?》
はい・・・・・・。神様。
どうかどうか島をお救い下さい。
お願いします!
私は必死に祈る。

Page 2-5

《それは無理かな》
そんなそんなどうして
《だって、あなたはそんな事
望んでいないもの》
そんなはずは
《叶えられるのは、
心からの願いを、ひとつだけ≫

Page 2-6

まがつき
《禍津姫迪子、
あなたの心からの願いを教えて
私の心からの願い ?
それは帝国兵どもの死だ。
あの彼岸花の中で死んだ女よりも 苦しんで、 苦しみ抜いて死んで欲しい。
あの男だけじゃない。 帝国の下衆ども すべてだ。 その家族、友人、軍も帝国も!
帝国に従う連中も私を売ろうとした父も

Page 2-7

顔も喉り、神の光に焼かれ、声が出ない。 だから私は爪を立て自分の肌に刻んだ。
凡縳我
悉滅之
我を縛るすべて、ことごとくびよ。
何もかも。 すべてを滅ぼしたい この苦しみを味わってもらいたい。

Page 2-8

《叶えてあげるね≫
嬉しそうな、 神の声。
手の中に、ずしりとした何かがあらわれた。
鮮烈な果物の香りがする。
《そちらはサービスのデザートです》
よもつへぐい
デザート? 黄泉戸喫彼岸のものを
食べれば、現世に戻れなくなる。
口をつけるかどうか、ためらっている
うちに、私は意識を失った。

Chapter 3

Annihilation

Page 3-1

目が覚めると、夜が明けていた。
目も見えるし、音も聞こえる。
一長い夢を見ていた気がする。
社は崩れ、 神骨はどこにも見当たらない。
禁足地の入り口にあったしめ縄は切られ、
無数の草鞋が地面に落ちていた。
神との対話 夢だったのだろうか。

Page 3-2

木々の合間から、海が見える。
帝国の軍艦数隻が、 煙突から煙をあげ、
出港していくのが見えた。
どこかから軍艦に向けて閃光が走り、 数秒後に、落雷のような音が聞こえた。 黒い霧と共に、 山影から、 巨大な何かが姿を現す。

Page 3-3

それは、宙に浮かぶ巨大な骸骨だった。 骸骨が電撃を放ち、巨大な腕を軍艦へと
振り下ろす。
神獣だ!
帝国の軍艦はこの神獣から逃げようと していたのだが、次々に沈められていく。
あはは!
沈んでいく軍艦を眺めながら、
私は久しぶりに、 腹の底から笑った。
―本当に神様は私の願いを 聞き届けて下さった!

Page 3-4

もっと近くで見たい。苦しむ帝国兵の顔を
拝んでやりたい。
足取り軽く、山を駆け下りると
町は大変なことになっていた。
家が焼けていた。
黒焦げの死体がいくつも転がる。
どれが父か、使用人か、あの帝国兵かは
分からない。

Page 3-5

オウハラ
邑原の町も、焼き尽くされて
いた。 私の他に動くものはいない。 帝国の基地も、港燃え尽き、
港の向こうで、最後の軍艦が沈むのが
見えた。 神獣の姿はもう見えない。
炭と、 灰だけになっていた。

Page 3-6

神は神獣は願いを叶えてくれた。 でも、島の人まで皆殺しにするなんて······。
私のせいで、みんな死んでしまった。
帝国軍だって。 こんな非道いことは
しなかった。
私は・・・・・・こんなこと望んでいない・・
いや、それは違う。
私は確かにこれを望んだのだ。

Page 3-7

島を救うのは、私の心からの願いではないと
神は告げた。
その通りだ。 この小さな島で、 いつも悪態をついて暮らしていた。 小さな人間関係のしがらみに
縛り付けられ、 窒息しそうだった。
だから、 これが、 私の心からの願い。
何かり消え去り、私だけになった島が。

Page 3-8

憎んでいたものすべてが消えて
私は自由になった。
なのにこんな気持ちになるなんて。
本当は、私だけが消えれば良かったのだ。
喉が渇く。
懐に何かが入っていた。
それを取り出すと、輝く林檎があった。
神より賜った、あの果実だ。

Page 3-9

奇妙な色の果実をかじり、 天使となった者が
いるという話を聞いたことがある。
しかし、大半の者は力を得られず死ぬとも
聞いていた。
死んだとしても自業自得だ。
私は、半ば衝動的に林檎をかじった。

Page 3-10

目を覚ますと、
私の背には翼が生えていた。
ならば、 私は天使になったのだ。
命拾いをした―いや、これは 償いをしろということかもしれない。
まずは、あの神獣を滅ぼす。
あれを殺し、島の人々に報いなければ。
その次は帝国だ。
私は地面を蹴り、
思いきり空へと舞い上がった。
Fin.
