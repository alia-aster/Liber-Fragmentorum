Chapter 1

クソくらえ

Page 1-1

FXXk! FXXk! FXXk!
貴族らしくあれ！
名門の名を汚すな！
マジ信じらんねー！
善良であれ！
あたしが間違ってるっていうのか!?
どれもクソくらえだ！
なんでハゲジジイじゃなくて、
そもそも悪いのは
あたしのメイドが罰を受けるんだよ!
あのハゲジジイじゃねーか！

Page 1-2

クソ実家のクソ貴族ばかりが集まる
クソパーティでの出来事だ。
偉い軍人サマだか何だか知らねーが、 ハゲジジイがうちのメイドのケツを
触りやがった。

Page 1-3

だから善良なあたしは 「善」 を為した。
つまりジジイをぶっ飛ばしてやったんだ。
結果、 メイドはクビになり、 ジジイはお咎め無し

Page 1-4

絶対に逆らえない女のケツを触るのと、
スケベジジイのハゲツラをフルーツポンチに ぶち込むのは、どっちが 「悪」 なんだ?
社交パーティーを本当にぶち壊したのは、そいつとあたしどっちだ!?
あたしにはわっかんねー!!
あたしが何かやらかすと、
酷い罰を受けるのはあたしじゃなくて、 いつも、あたしの周りの人間なんだ。
そうすりゃ、 親父はあたしが
反省すると思ってやがる。

Page 1-5

親父はあたしを呼び出し、
けど今回はメイドを首にしただけじゃ
気が済まなかったらしい。
長い溜息をついた後にこう言った。
「修道院へ行け！」
どうやら、親父殿はスケベジジイに
タマを握られてたようだ。
は？ 修道院？
素行不良な娘はいよいよ勘当って?

Page 1-6

フン、そっちがその気なら構わねえ。
窮屈な実家には辟易してたとこだ。
あたしはニッコリ笑って親指を立て、
そのまま勢いよく下にさげた。
「こんなお綺麗な家
こっちこそ願い下げだ！ クソくらえ！」
こんなクソみたいな家を出られるなら
修道院だろうがどこだろうが、
喜んで行ってやるぜ！ ヒャッホウ！

Chapter 2

一発くらわせろ

Page 2-1

分かっちゃいたが――
修道院はマジでクソだった。
何でもかんでも、
「聖女さまのお導きのままに」だ。
意味もわかんねーし、
納得できねールールばっか。
こんなの実家の方がまだマシじゃねーか！

Page 2-2

純真無垢な心で日々を過ごし、
愛の気持ちを忘れず人に接し、
規律に則り、聖女さまに仕えるに
相応しく 「善良であれ」

Page 2-3

あたしたち修道女は
起きる時間、食べる時間、寝る時間
ぜーんぶ決められた通りに動く。 1秒だって遅れは許されねえ。
靴下を履く順番も、飲む水の量も
祈りの手順も、聖女さまの像をどこから 磨くかも決められてる。
ケツの拭き方だってどっかに書いてあるんじゃねーか？

Page 2-4

ルールを破れば説教反省部屋に監禁
鞭打ちと、 お仕置きのフルコース。
だから、どいつもこいつも お行儀よく聖女さまの言うとおりだ。
多分、ここの連中はみんな狂ってる。
聖女さまの事だけ考え、せこせこ奉仕してウットリしてやがる。
マジで最悪だ。
何が聖女だ。 そいつも人間だろ
何がそんなに偉いんだよ？

Page 2-5

で、あたしは面白いことを思いついた。
なんと、新入りシスターの中で、
一番いい子ちゃんだったヤツは 聖女さまに面会ができるらしい。
ネコをかぶって、聖女さまに近づいて、
一発かまして鼻を明かしてやる。
あたしはやればできる女だ。
目的のためならいくらでも
ネコをかぶってやる。

Page 2-6

その日から心を入れ替えたフリをした。
規則正しく毎日を過ごし、
他の修道女より率先してご奉仕、
聖女さまに長く濃ーいお祈りを捧げた。
あなたさまにお会いしたいです。
そのツラ拝んでやりてーです。
そんで一発くらわせろわしてやりてーです。

Page 2-7

聖女さまの教えに感銘をうけ、
俗世の狼藉を反省し、
敬虔な修道女となったあたくしちゃん。
先輩修道女どもは、やっと聖女さまの
思いが通じたのですね！
とかなんとか大感激だ。
ネコを被り続けて数ヶ月。 ついに聖女さまの
おそばに近づくチャンスをゲットした。

Page 2-8

さあお楽しみだ。聖女か何だかしらねーが、 裸にひんむいて尖塔から吊してやる！
期待してくれよな！ レッツゴー！

Chapter 3

林檎を食う

Page 3-1

[ページ種別：青]
結論から言おう。
裸にひんむかれて、尖塔から吊されたのは、
あたしだった。 マジわけわかんねー
「ハックショーイ!!」
くしゃみと鼻水がずぴっと飛び出す。
マッパでぷらぷら揺れるあたしを
聖女さまはニコニコしながら
見下ろしている。
一発でわかった。
このお方は聖女なんてもんじゃねー！
あたしの側の人間だってな。

Page 3-2

[ページ種別：青]
聖女さまはニコニコしながら言った。
「マジ、この暮らし最悪。もううんざり」
ってな。
みなに集められる存在として
規則正しくお綺麗に過ごして、
生きとし生けるものすべてに優しく
手本になるよう 「善良であれ」
つまり究極のいい子チャンでいろってことだ。
そんなの窮屈で仕方がないよな。
……わかるぜ。その気持ち。

Page 3-3

「私はお前のネコかぶり力を
高く評価している。だから……」
――マジしびれたね。
聖女さまは慈愛に満ちた笑みを浮かべ言った。そんなの絶対面白いじゃん！
「ドロシー、 私の影武者になれ。 きみが私のフリしてるあいだ、
てことで、あたしは表向き、
聖女さまのおつきの修道女になった。
不良修道女として、遊びまくるからさ」

Page 3-4

聖女さまと一緒なら退屈しない。
あたしと聖女さまは交互に抜け出して
たらふく肉を食ったり、 禁書を持ち帰ったり
銃をぶっぱなしたりして遊んだ。
退屈な牢獄でしかなかった教会は、
聖女さまと戯れ踊るパーティー会場になった。
死んだように同じことを繰り返す日々は
ふたりだけの遊びに耽る月に変わった。
聖女さまはやることなすこと面白いし、 一緒にいれば最強だって気分になれた。

Page 3-5

ある日、聖女さまはソレを持ってきた。
白くてちっせー手に乗ったソレは
ただれた肌のような毒々しい色をしていて
見るからにアブネー感じだった。
「ドロ子さぁ、この林檎知ってる？」
聖女さまが内緒話をするようにささやく。 あたしは首を振った。
んなマズそーなもん、知らねえよ。

Page 3-6

聖女さまは林檎を掲げて、
とろけるような声であたしにささやく。 「食べて。 絶対面白いことになるから」
あたしは迷わず林檎を食った。

Page 3-7

林檎を口に入れた瞬間、
あ、これグレゴールの林檎じゃね?
目の前が柔らかい光に包まれた。
その光のベールの先で、
聖女さまがわくわくと目を輝かせている。
意識を失いながら思い出す。 実家にいたころ、 聞いたことがある。
食べれば待つのは死か、それとも……

Page 3-8

ってのが、天使になったあらましだ。
ウケるだろ?
そうそう。 天使になる時わかったが、
聖女さまはマジとんでもねぇ聖女だった。
どういう意味かって？
まあ、それについちゃ
どっかで誰かが語ってくれるだろ。

Fin.
