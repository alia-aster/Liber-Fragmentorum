Chapter 1

艦の中の天使

Page 1-1

どこまでも澄み切った着天に、
一羽の鳥が円を描く。
鳥は、いつも自由だ。
ライカは目を細め、 空を見上げていた。
ふと視線を落とすと、 大草原の彼方。 地平線から立ち上る幾筋もの黒煙が見えた。 他人事だと思っていた火は、
もう目に見える場所まで迫っている。
(こちらにまで
来なければいいのだけれど・・・・・・)

Page 1-2

数日後の静かな夜。
ライカのささやかな祈りは踏み躙られた。
寝静まる宿営地に、
王国軍がやってきた。
ライカたち遊牧の民は抗う術もなく
捕虜へと成り果てた。
殺されないだけマシだと、
誰かが震える声で言った。
家族の温もりが詰まった天幕が、
赤々と燃えていた。 その炎の赤を、
ライカは涙で滲む目に深く焼き付けた。

Page 1-3

ライカたちは銃床で小突かれながら、
草原を延々と歩かされた。
捕虜同士が喋ると殴られた。
だから、両親も祖父母も、家畜たちも、
どうなったのか分からない。
身内でたったひとり一緒だった姉が、
兵士の目を盗んで
おそろいのブレスレットを
手首に結んでくれた。
「ライカ、 「お守り」だよ。
がんばろうね」

Page 1-4

肺の奥まで凍りつきそうな極寒の地
白い氷原を越えた黒い海原のただ中に、 人工島がそびえていた。
「王立総合進化研究所」 それが、王国兵の目的地だった。

Page 1-5

道中、捕虜の中で働ける男と、
これから何をされるのか。
見た目の良い女は他へ連れて行かれた。
体力の無い子どもと老人は
氷原に捨てられ、
底知れぬ恐怖の中、 ライカたち捕虜は 冷たいコンクリートの地下室
閉じ込められた。
女だけがここに連れてこられた。

Page 1-6

ガラス張りになった壁の向こうに、
白衣の男たちが並び、 爛々と輝く目で、
ライカたちをめ付けている。
刺すような寒さと、先の見えない不安。
ライカたちは互いの体温だけを頼りに、 震えながら身を寄せ合った。
何の説明もないまま。
指の先ほどの小さな塊が配られた。
手のひらに乗せられたそれに鼻を近づけると、
何か果物のような香りがした。

Page 1-7

何日もまともな食事を与えられていない。 香りを嗅いだだけで、脳がしびれ、
ライカが口に含んだ果物の欠片は、 涙が出るほどに甘く、美味しかった。
生唾が口に溢れた。
あちこちから、喉を鳴らす音が響く。 不審に思っても、空腹には勝てなかった。
まるで初雪のように舌の上で解け、 身体中に満ちていく。
その心地よさに身を委ねようとした、
次の瞬間

Page 1-8

突如ライカの目の前が真っ暗になった。
内側から身体が引き裂かれるような 激痛が走る。身体の中に 嵐が巻き起こったようだった。
助けを求めて手を伸ばそうにも、 分厚い膜のようなものに包み込まれ、 指一本動かせない。

Page 1-9

自分の身体が、別の何かに
作り替えられていく。
永遠にも思える苦痛の嵐が
ようやく過ぎ去ると、 ライカは
全身を覆う膜を破り開けた。
たったそれだけで力尽き、冷たい床の上で
胎児のように丸くなって咳き込む。
視界は涙で滲み、 焦点が合わない。
ライカの周りを
赤黒く蠢く 「何か」 が
取り囲んでいた。

Page 1-10

肉塊だった。
辛うじて人の形を残した肉の塊が、
這い回っている。
顔らしきものに埋もれた眼窩からは、 絶え間なく血の涙がこぼれ落ち、 肺から漏れた空気が声帯を震わせて、 無意味な声を上げている。

Page 1-11

ライカは恐怖に絶叫した。
その声をききつけて、異形の肉塊が
ライカの方へ集まってきた。
血まみれの触手が、
ライカの足にからみつく。
その触手に見覚えのあるものが巻かれていた。
「お守り」、
おそろいのブレスレット

Page 1-12

次の瞬間、その肉塊は、
軍靴に乱暴に蹴り飛ばされた。
ライカは視線だけを緩慢に動かして
辺りを見回す。
イヌ
「成功した被験体はこいつだけだ」
悪夢の底を這うような感覚の中、
ライカの身体は、兵士たちに
両側から抱え上げられた。
そうかー
蠢く肉塊は、 姉さんの、 仲間たちの、
なれの果て――
ライカは絶叫した。

Page 1-13

ライカが放り込まれたのは、
どんなにがんばっても
翼はぴくりとも動かない。
白い無機質な牢獄の部屋だった。
白衣の男は 「できそこない」 と呼んだ。
ライカは自分の背中に、
小さな翼が生えていることに気付いた。
それでもライカは 「天使」 となり、 姉さんと仲間は 「怪物」に
成り果てた。

Page 1-14

(どうして? 何で、私だけが••・・・
涙がこぼれた。
生き残った安堵、
仲間を喪った悲しみ、
自分だけが選別された罪悪感。
全部が一緒くたになって押し寄せる。
凍てつく檻の中で、 ライカの涙は
いつまでも流れ続けた。

Chapter 2

番大

Page 2-1

微かな痛みがうずいた。
ファラは荒れた手のあかぎれを見つめ、
小さく舌打ちをした。
ぱっくりと割れ、血が滲んでいる。

Page 2-2

「一手を、どうかしたのですか?」
イヌ
「黙れ。被験体が話しかけんな」
ファラは檻の中の天使に毒づき、
あかぎれに滲んだ血を軍服の袖でぬぐった。
目をふせた 「天使」 に罪悪感がこみあげる。
だが、どうせこいつも、すぐ死ぬ。
気を使うだけ無駄だ。
そう自分に言い聞かせる。

Page 2-3

ファラは人造天使計画の全容を知らない。
だが、死んだ天使から抽出した物質を 捕虜の女に食わせ、 「天使」 とやらを
造り出していることは知っていた。
王国は 「天使」 について
帝国よりも遅れている。
どんな手段を使ってでも、
帝国に追いつく必要があるのだ。
だが、 現在の王国の技術では、
運良く天使ができたとしても、
命が萎むように短命で死んでいく。 何かが足りないのだ。

Page 2-4

「あの、怪我をしているようなら、
あまり触らないほうが......」
こちらを気遣うような天使に、
ファラは無意識にいじっていた手を
背中に隠す。
いきもの
得体の知れない天使の監視が、
ファラの任務だった。

Page 2-5

ファラは食い詰めて、 兵士になった。
人に媚びる才能がなく、上官と衝突して
戦場で一旗揚げる夢も潰え、
こんな最果ての僻地へ飛ばされた。
回ってくるのは
如何わしい研究の片棒かつぎ。

Page 2-6

「一だって、しょうがないだろ。 私だって生きてかなきゃならねえんだ。 弟も妹も飢え死にした。
食えるだけマシだ」
ファラはか細い声で、 弱音を吐いた。 いつからか ファラは天使に向かって
愚痴をこぼすようになっていた。
上官への不満、自身の不遇への嘆き、
理不尽な世界への怒り・・・・・・。
最初はライカを腐すような物言いだったが、
天使はいつだって、 文句ひとつ言わず
ただ静かにファラの言葉に
耳を傾けていた。

Page 2-7

「一お前だって、王国軍に
言いたいことがあるんじゃねえの?
何もねえなんて、それこそ天使サマかよ」
ライカはファラが監視についてからずっと、 一度だって恨み言を口にはしなかった。
けれど恨みや憎しみがないはずがない。
捕虜にされ、 人造天使にされ、
仲間を怪物にされた。
なんの文句もないなんて。
ライカは寂しげに目を伏せただけだった。
「言っても、どうにもなりませんから」

Page 2-8

(どうにもならない。 か······)
けれど、自分たちの理不尽な不遇を、
そんな言葉ひとつで
諦めてしまっていいのだろうか。
ファラは上手く考えがまとまらないまま。
所長室のドアを叩いた。
研究所長の呼び出しを受けたファラは、 足早に向かいながら、顔をしかめた
”どうにもならない”も、 ”しょうがない”も、諦めの言葉だ。

Page 2-9

「八三号被験体の
生体解剖が決定した。
よって、 お前を監視の任から解く」
いきたまま
生体解剖?
ードクン、と。
ファラの胸の奥で、何かが嫌な音を立てた。
「了解。 通常警備任務に戻ります」
努めて無機質な声でそう告げると、
踵を返し、部屋を出た。

Page 2-10

胸の奥が熱い。
なんだ、この気持ちは?
そうか、あたしはムカついてるんだ。
でも、命令だ。
できることなんて、何もない。
どうにもならないんだ。
しょうがないだろ・・・・・・!

Page 2-11

一本当に?
固く握り締めた拳に
パッと弾けるような痛みが走った。
監視役の任についてから 治り始めていたあかぎれが、 再びぱっくりと割れていた。
じわりと、鮮やかな血が滲む。
じくじくとした痛みが わずらわしい。

Page 2-12

[......。
「どうにもならない」
そうだ、
どうにもならないんだよ・・・・・・」
白い息と共に虚しい自嘲をこぼし、 ファラは薄暗い廊下に立ち尽くした。

Chapter 3

天使の翼

Page 3-1

一翼が重い。
私に生えたこの翼は、ただの飾りだ。
少しも動かせない、 できそこないの翼。 飛べない鳥は、どこにも行けない。
できそこないの私は処分される。
手枷をはめられた私を、 兵士たちが
取り囲んで連行していく。
ファラさんも、私のすぐ後ろを歩いていた。
裏切られたとは思わなかった。
だって、 “しょうがない”。
彼女だって、 この理不尽な世界で
生きるためなのだから。

Page 3-2

事は一瞬だった。
背後から強い力で腕を引かれたかと思うと、
ファラさんが飛び出て、
警備兵たちを昏倒させた。
「・・・・・・ ファラさん?」
「逃げるぞ!」
ファラさんは私の枷を外すと、
強い力で引っ張った。

Page 3-3

熱い手だった。
ファラさんが自分を助けようとしてると
気付くまで、 しばらく時間がかかった。
「ファラさん! やっぱり優しい人」 「うるせぇ黙ってろ!」
照れた声でファラさんはそう言った。

Page 3-4

私たちは地上ではなく、最下層へ向かった。
仲間を助けたいという
私のわがままを、 ファラさんが
聞いてくれたのだ。
たとえそれが、 どんな姿に
成り果てていようとも一
それなのに。
余計なことをしている時間なんて
現実は想像を絶するほど残酷だった。
ないのは分かってる。
けれどどうしても、
姉さんと、仲間を諦められなかった。

Page 3-5

分厚いガラスの向こう。
かつての仲間たちは、
互いの肉をむさぼり食いながら、
ひとつの大きな肉塊となっていた。
どこまでが姉さんなのか分からない。 痛みも、理性も、感情も消え、
ただ原初の欲望に突き動かされている。
姉さんの面影を探そうとしたが、 無駄だった。
絶望に膝から崩れ落ちた、 その時

Page 3-6

巨大な肉と目が合った。
その喉の奥から、 空気が漏れるような音で、
「遊牧の民の子守唄」 の
旋律が響いた気がした。
身体から絞り出された空気が、
似た旋律になっただけかもしれない。
それでも、魂の底に刻まれた故郷の歌で、
何かを伝えようとしていると思いたかった。

Page 3-7

人でなくなってしまった姉さんと仲間は、
安らかな眠りを求めている。
ここで終わらせることが、
救いになるなら。
「ファラさん・・・・・・ どうしたら、
ファラさんは顔を歪め、 非常スイッチを指差した。
毒ガスを檻の中に 放出するスイッチだ。
みんなを楽にしてあげられますか・・・・・・?」
「一私がやろうか」
「いいえ。 私がやらなきゃだめなんです」

Page 3-8

「おやすみなさい。 姉さん、みんな。
••••••どうか、安らかに」
この手で みんなの命を奪ったことを、 私は絶対に忘れない。
致死性のガスが充満する部屋に背を向け、 私たちは走り出す。
鼓膜を裂くような警報が鳴り響いた。
「急ぐぞ。 搬出ドックを
押さえられたら終わりだ!」

Page 3-9

ドックに辿り着いた直後、
ファラさんがハッと息を呑んだ。 武装した兵の足音が近づいてくる。
ファラさんは舌打ちをすると、
私を脱出艇の中へ押し込んだ。
「乗れ! 早く!」
そのまま、外からハッチを閉めようとする。
私は押し返した。
「待って、ファラさんも一緒に!」

Page 3-10

「心配すんな。
ヤツらに挨拶したら、すぐ追いかける」
「嘘です!
お願い。 あなたまでいなくならないで・・・・・・」
ファラさんは不器用に、
ヘタクソに笑った。
「飛べ、 ライカ!」

Page 3-11

「誰もお前の自由は奪えない!
飛べ、ライカ。 お前と、お前の仲間と······
あたしの命を乗せて!」

Page 3-12

強い力で脱出艇の奥へと突き飛ばされる。 立ち上がる間もなくハッチが閉ざされた。
「ファラさん・・・っ!」
射出装置のロックが外れる音が響いた。 私ひとりを乗せた脱出艇は、
すさまじい加速度で 研究所から射出された。

Page 3-13

そうして私ひとりを乗せた脱出艇が
辿り着いたのは、
どこまでも白い大地が広がる氷原だった。
「ファラさん・・・・」
脱出艇から出てどこを見回しても、
研究所は見えない。
私は途方に暮れた。
これからどうすればいい? どこへ行けばいい?
こんなできそこないの翼じゃ。
どこにも行けないのに......。

Page 3-14

「•••••• ううん。 違う」
止まらない涙を何度も拭う。
何をしてもうまく動かなかった 天使の翼が
初めて呼吸をするように震えた。
この翼は、たくさんの仲間の犠牲と、 ひとりの兵士の命でできている。
ファラさん
私はもう、飛べない鳥じゃない。
できそこないの天使じゃない。

Page 3-15

今なら飛べる。どこへだって。
「この大地のどこでだって
生きてやる!」
「飛べ、 ライカ!」
ファラさんの声が、胸の奥で響いた。 心が熱く震える。 全身に力が漲る。

Page 3-16

私は、仲間の命が宿る翼を広げ、
力強く雪を蹴り上げた。
足元の白い大地が、遠ざかっていく。
冷たい風を切り裂き、高く、もっと高く。 ファラさんが繋いでくれた。
この命を燃やして。
私は、どこまでも澄み切った蒼天を目指し、
一羽の鳥となって飛び立った
