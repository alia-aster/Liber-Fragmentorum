Chapter 1

そして少女は旅に出る

Page 1-1

幾筋もの白い煙が、 細く天へと昇っていく。
犠牲になった人々の魂のように。
緑に囲まれた自壁の街は何もかも焼け落ち、 見渡す限りの黒い瓦礫の山となっている。 この街に神獣が現れたのだ。
「うう......」
小さな手で瓦礫を掻き分ける少女の顔は、 蝶で汚れ、涙のあとが残っている。

Page 1-2

「あっ」
少女は燃え落ちた自宅の瓦礫の隙間から
何かを見つけた。
それは絵本だった。
父の膝の上で、あるいは母の腕の中で、
物心つく前から何度も、何度も
読み聞かせてもらった絵本。

Page 1-3

主人公が苦難を乗り越え、
スレイヤー
神獣殺しへと成長していく物語。
少女はその絵本が大好きだった。
オフィーリア。
少女の名は、絵本の主人公と同じ名前だ。
両親がくれた名前を、
少女は心から誇らしく思っていた。

Page 1-4

少女は物語のオフィーリアに憧れていた。 強い 「ちから」を持ち、
運命に立ち向かった少女。
自分にもそんな「ちから」があったなら。
そんなことを夢想して、
時にはオフィーリアの物語のような
人生を生きてみたいと思ったこともある。
でも、
神獣の襲撃（こんなこと）を望みはしなかった。

Page 1-5

突然、空に現れた巨大な銀色の神獣は、
火と毒を放ち、街を焼き尽くした。
悪い夢のようだった。
誰かに手を引かれ、 オフィーリアは
街の外へと逃げ出した。
轟々と立ち上る炎を遠くから
眺めながら、 オフィーリアは
絵本の一節を思いだしていた。

Page 1-6

「小さな街は炎に包まれました。
大きな銀色の鯨が天からあらわれ、
硫黄と、銀の雨を降らしたのです。
人々は何もできずに逃げ惑い、
毒と炎に巻かれて
焼け死んでいきました」
物語が、現実になってしまった。

Page 1-7

両親も、家も、 街も、全部燃えた。
オフィーリアは唯一焼け残った 本をぎゅっと抱き締め、泣いた。
やせた小さな背中を大きく震わせて、 声の限りに泣いた。
涙が涸れ果てたころ、
オフィーリアの冷たい頬に、 暖かな熱が優しく触れた。

Page 1-8

美しい朝日だった。
絵本を抱き、黄金に輝く空を仰いで、
オフィーリアは理解した。
そうかー
あの神獣は私の銀の鯨だ。
これ
絵本は、私の物語なんだ。
涙を拭い、 オフィーリアは立ち上がった。
彼女は歩き出す。
もう二度と泣かないと心に決めて。

Chapter 2

荒野の風に散る

Page 2-1

「オフィーリアねぇ・・・・・・?」 王国軍の兵士が、 少女の顔を
じろじろとめつけた。
「ここで世話になろうってヤツが、 帝国の 伝説的英雄の名前を名乗るのはマズいな。 お前は、今からマリアだ。 いいな」

Page 2-2

去って行く兵士の背中を見ながら、
オフィーリアは絵本をぎゅっと抱き締めた。
絵本の表紙がほとんど焼けていてよかった。
オフィーリア
もしその英雄の物語だと知られたら、
取り上げられていただろう。

Page 2-3

絵本を抱いて、 荒野を彷徨っていた
オフィーリアを見つけたのは、 帝国と敵対する王国の兵士だった。
王国軍の部隊は、 オフィーリアの他にも
大勢の子供を「保護」 していた。
子供たちは一様に暗い目をしていた。 新参者のオフィーリアを探るように見ては、
むっつりと黙り込む。
彼らも自分と同じような境遇なのだと、 オフィーリアは誰に聞かずとも理解した。

Page 2-4

子供たちを連れて、隊列は荒野を行く。
子供の足にあわせた行軍に苛立つ兵士もいた。
「ガキは足手まといだ。 捨てていこう」
「こいつらは盾だ。 子供がいれば
帝国も攻撃してこないからな」
兵士たちはそんな会話をしていた。
わずかばかりの休憩が与えられた。
配られた固いパンをかじっていると、
「おい、チビ」
年上の少年たちが
オフィーリアのパンを取り上げた。

Page 2-5

「チビなんだからオレたちに寄こせよ」
パンに手を伸ばすと、抱えていた
絵本が地面に落ちた。
「何だこれ? きったね一本」
「だめ、 返して!」
オフィーリアの真剣な声を聞き、
少年たちの顔に、醜悪な笑みが広がった。
オフィーリアの手の届かない高さに
絵本を掲げ、必死になる少女を嘲笑する。

Page 2-6

少年たちは、すまし顔のオフィーリアが
気に食わなかった。
誰も彼もが絶望に沈む中で、
だから―――
すり切れるほど読み込まれ、 神獣の炎でも焼け残った本を
オフィーリアの澄んだ眼差しが
気に食わなかった。
少年たちは無残に引き裂いた。

Page 2-7

「ああ..................」
本は表紙まで念入りに破かれ、
紙片となって荒野の乾いた
風にさらわれる。
両親の思い出が、 幸せな記憶が、
オフィーリアの物語が。
破り捨てられ、
手の届かないところへ飛んでいく。

Page 2-8

少年たちはゲラゲラと笑いながら
オフィーリアを見る。
オフィーリアは泣かなかった。
澄んだ瞳で少年たちをただ見つめる。 その瞳に宿った意志に彼らは怯み、 その場を逃げ出した。
私は、大丈夫.......・。
絵本の欠片は風に舞い散り、 手が届かない。
だが、 オフィーリアは
思い出の欠片を胸に抱いている。
名前も、絵本も奪われたが、
思い出までは奪えない。

Page 2-9

全部ちゃんと覚えてる。 自分の真の名前も、 両親との記憶も、
オフィーリアの物語も。
「私の物語は誰にも奪えない」
オフィーリアは、そう確信していた。

Page 2-10

強い日差しを遮るもののない荒野。
兵士の隊列が、 オフィーリアの遥か前方に
小さく揺らめいている。
空腹はもう感じない。 乾ききった唇は白く皮がめくれ、 麺は痩せこけていた。
地面を踏む感覚さえあやふやだ。
歩いているのか、倒れないように
足を前に出しているのかも分からない。
どんな希望を抱いていても現実は残酷だ。 助けてくれる騎士は現れない。 絵本の中のオフィーリアとは違うのだ。

Page 2-11

オフィーリア
私は主人公にはなれない。
名前が同じだけ。 境遇が似ているだけ。
「ちから」 なんてない。 奇跡なんて起こせない。

Page 2-12

物語のように生きられないし、
現実は物語のようには報われない。 それでも、信じていたかった。
オフィーリアは地面に倒れた。 彼女に目を向ける者はいない。 隊列が遠ざかる。
涙が、乾いた荒野に滲んで消えた

Chapter 3

これは“私”の物語

Page 3-1

遠く、どこかから獣の遠吠えが聞こえる。
オフィーリアはぼんやりと目を開けた。 夜の荒野は凍えるほどに寒く、
指先にはもう何の感覚もない。
かすむ目を瞬くと、
頭上に満天の星空が広がっていた。

Page 3-2

誰も隊列から脱落したオフィーリアを
探しには来なかった。
見捨てられたのだ。
いや、気付いてもいないだろう。
きっと、これは
わたしじゃない誰かの物語。
だから、脇役の死なんて、
誰にも知られることはない。

Page 3-3

それでも、脇役は脇役なりに祈る。
もうこれ以上、誰かが理不尽に奪われて、 悲しい涙を流すことがないように。
命の火が消えていくのを感じながら
目蓋を下ろすその瞬間、
少女は空を切り裂く流星を見た。

Page 3-4

オフィーリア!

Page 3-5

はじけるように頭の中で声が響いた。
天使の声だ。
オフィーリアはそう直感した。
心臓がひとつ大きく脈打つ。 彼女は深く息を吸い込んだ。 目蓋の裏がチカチカする。
胸を叩く鼓動とともに、 熱い血が全身に駆け巡った。

Page 3-6

「あ、あ、あああ!」
大地を割れた爪で掻きながら、
心のままにオフィーリアは声を上げた。
空っぽの身体に魂を込めて、
震える足に力を込めて、
絶望した心に希望を込めて。
オフィーリアは進んだ。
前へ 前へ、
ただ、 流星の墜ちた場所へ向かって。

Page 3-7

昼も夜もなく歩いた。
オフィーリアがくじけそうになる度に、 天使の声は彼女を呼んだ。
一度でも歩みを止めれば、
二度と立ち上がれはしなかっただろう。
だから彼女は立ち止まらずに歩き続けた。
そうして、オフィーリアはたどり着いた。
体力などとうに尽きていた。 皮と骨だけに等しい有様だった。
命だって、きっととっくに尽きている。
荒野のただ中 墜ちた流星の元に。

Page 3-8

それは巨大な艦だった。
遠く離れた荒野に
あるはずがないもの。
それこそが、この艦が
空を渡ってきた証だ。
崩れた船腹から、中に入る。
薄暗い船室を抜け、
階段をのぼり甲板に出る。

Page 3-9

甲板の中央に青々と葉を茂らせて大樹が、
そびえていた。その枝には、林檎に似た
虹色の実がなっている。

Page 3-10

甘い芳香に誘われて手を伸ばす。
林檎は待ちわびたかのように
オフィーリアの手の中へと落ちてきた。
オフィーリアは、 そっと林檎にかじりつく。

Page 3-11

オフィーリア!
スレイヤー
神獣殺しのオフィーリア!

Page 3-12

スレイヤー
脳裏に神獣殺しの物語が
走馬灯のように駆け巡った。
ひび割れた唇に歓喜の笑みが浮かぶ。
ここから、私の物語が始まるんだ

Fin.
