Chapter 1

花開く

Page 1-1

あの人と出会ったのは、
帝都で催された舞踏会でした。
帝都の壮大な建築も、文化的な生活も、
初めて見るものばかりで、
私はすっかり舞い上がっておりました。
私の国、 アーニスリンナ大公国は
北方の小さな国です。 王族とは言えここでは
ただの田舎娘でしかありませんでした。

Page 1-2

絢爛たる舞踏会の雰囲気に気圧され
勝手が分からない私は、無様にも飲み物を
こぼし、ドレスを汚してしまいました。
そんな私を助けてくれたのが、
あの人――メルニッツ少尉でした。

Page 1-3

帝都への滞在中、 少尉は私に何かと
便宜を図ってくれました。
帝都の見所を巡り、美味しい食事を教えてくれました。
議事堂や、 特別な人間しか入ることが
できないという研究所も見せてくれました。 私はすっかり少尉に頼りきりでした。

Page 1-4

アーニスリンナ大公国は歴史ある国です。
少尉と私はいろいろなお話をしました。 過去の歴史、国家とは何か、
その由縁は遠い昔の七王国時代、薔薇の国と呼ばれた頃にまで遡ります。
人間が中心となる新しい時代について。
それは、私が知りたかった事。 私の国の未来につながるお話でした。
薔薇の国は戦争で滅び、 国土は荒れ果てました。
祖先である「開墾王」こと 初代アーニスリンナ女王が不毛の地を耕し、
国土を切り拓いたのです。

Page 1-5

我が国の気候は厳しく、 作物の実りは
わずかです。 鉱山が見つかり栄えた時期も
ありましたが、今は閉鎖寸前です。
厳しい土地だからこそ人を第一に考えよ。 そう父は繰り返し私に言いました。
メルニッツ少尉と話をして、父の言葉の 意味をようやく理解した気がしました。

Page 1-6

帝国の進んだ技術を導入し、有能な若者を
国内外から分け隔てなく集めれば、
アーニスリンナは、 帝国のように豊かで
進んだ国へ成長できる……。
「いや、負の遺産を引きずる帝国よりも、 はるかに豊かな国へと成長できるでしょう。
ケアト公女。 あなたは、その中心となる人物です」
「私に、 そんな大それた事が
できるのでしょうか？」
「公女の高貴な血は、
大公国民の魂を結びつけるでしょう。 必ずやできますとも！」

Page 1-7

嗚呼！ 私を認め、励ましてくれた方は
少尉が初めてでした。
王族としての重圧は今や、希望へと 変わりました。 私の心には、色鮮やかな花が
咲き乱れるような、そんな心地でした。
少尉の考えこそが、 故国を救う
たったひとつの冴えたやりかただと。
そう思い込んでしまったのです。

Chapter 2

花枯れる

Page 2-1

私が、取り返しのつかない間違いをしたと 気付いたのは、議会が王家の追放を
議決した時でした。
帝国議会を模して新築された議事堂で
最初に決まった法律が、 それでした。
議員の大半は帝国出身者で占められて
いました。 皆、少尉が推薦した者たちです。

Page 2-2

王家が消滅しようと、国さえ良くなれば
構いません。
ですが、そうはなりませんでした。
議会には、かつて少尉が語った理想も
思想もなく、 帝国に媚びへつらい、 私腹を肥やす者ばかりです。
ただでさえ乏しい資源は帝国に奪われ、 人々の生活は苦しくなる一方です。
帝国軍の駐留部隊が、昼夜を問わず 睨みをきかせています。 帝国に逆らい、
不平を言うものは容赦なく投獄されました。

Page 2-3

アーニスリンナ大公国は
帝国の属国と成り果てたのです。
国民たちは私を信じ、 私が提案した改革を
受け入れてくれました。 その結果がこれです。
すべて、私が悪いのです。自分の頭できちんと 考えず、あの少尉やその周りの人物の考えを
鵜呑みにしたせいなのです。

Page 2-4

私は、木の葉のように揺れる漁船の上で、 寒風に凍えながら身を締めていました。
国に留まれば、命の危険があったからです。
国民の不満は全て「売国姫」 である私に
向けられていました。 これもきっと
あの人の仕業でしょう。
「私はなんと物知らずで、 愚かだったのでしょう……」 悔し涙が頬を濡らしました。
国から持ち出すことができたのは、 王家の証である国宝の宝石と、
母より受け継いだ虹色の林檎だけ。

Page 2-5

「いいですか、 ケアト。
どうしても耐えられないことがあったとき、
この林檎をかじるのですよ」
私が大公位を継ぐ時、母はそう言いました。
母はもういません。
私にはもう、誰も頼れるものがありません。
この、たったひとつの林檎を除いては。
心は決まりました。
私は、冷え切った指先で、冷え切った林檎を
つかみ、ひと思いに林檎をかじりました。

Chapter 3

花咲かす

Page 3-1

[ページ種別：青]
暖かい日差しの下で、私は
「姫様! およしください!」
私の周りで、疲れ切った顔の民が
驚いた声をあげます。
ヒールを脱ぎ捨てドレスの裾を
まくると、 素足で土の上に立ちました。
「大丈夫、この国はきっと蘇ります
私は大きなスコップを
「なんといいお天気なのでしょう。
ここから始めるには
持ってこいの日和ですわ」
大地に突き立てます。
今日のこの日、この場所から、
アーニスリンナという国が始まるのです。

Page 3-2

[ページ種別：青]
全てが焼き払われ、砂に覆われ、
見渡す限り不毛の大地となっていても、
希望は捨てませんでした。
空行く鳥の声を聞いたから。
降る雨に土が濡れていたから。

Page 3-3

[ページ種別：青]
額に浮かんだ汗を拭っては、
手にできたマメをさすり、
私はひたすら、スコップをふるいます。

Page 3-4

[ページ種別：青]
小さな木の苗を植えました。
種を蒔き、 毎日水をやります。
何日も、何カ月も、何年も。 土を耕し、 水を運んで、
じっと待つ。
ただ、それだけ。
あまりにも愚直です。 ですが、
たったひとつのやりかたしか
私は知らないのです。

Page 3-5

瞬きをすると、
「今のは、夢……!?」
辺りを見回すと、
陽の光の眩しさが目を刺しました。
先程と同じ景色が広がっていました。 ただ、ひとつだけ違うのは――

Page 3-6

林檎の代わりに、
私は大きなスコップを手にしていました。 そのスコップには、翼が生えています。
見覚えはありません。
ですが、 柄を握る感触は知っています。
夢の中で握った、あの柄です。

Page 3-7

私の頭上を、
鳴き声とともに鳥が飛んでいきました。
海は凪ぎ、風も収まっています。 漁船は、港へと近づいています。
「なんといいお天気なのでしょう」
私は顔を上げました。
何より、体も、気持ちも、とても軽い。
――先程夢に見た女性は、
アーニスリンナの祖、
開墾王だったのかもしれません。

Page 3-8

「……私も、
もう一度ここから始めましょう。
この国を取り戻すために、戦います」
スコップの柄を握りしめ、心を決めました。
愚かかもしれません。
無謀かもしれません。
けれど。
再び花を咲かせるためにできる。
これがたったひとつの冴えたやりかた。天使になった私は今、そう信じています。
Fin.
