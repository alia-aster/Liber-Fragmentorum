Chapter 1

笑わない少女

Page 1-1

道化師は踊る。
煌めく豪奢な明かりの下で、軽やかに。
甘やかな戯れ言を唄っては、
宝石のようなお菓子をひとつまみ。
くるりくるり、くるくるり。
プロメネス帝国の宮殿の一室で、
ぬいぐるみに埋もれる少女に跳ね寄り
お辞儀をひとつ。

Page 1-2

道化師が桃色の唇に差し出したお菓子に
見向きもしない少女は、
ただゆっくりと息をしていた。
まるで人形だ道化師は思う。 無気力に開かれた少女の目は何も追わず、 閉ざされた唇に笑みが浮かぶことはない。
瞬きをしていなければ、
呼吸をしていなければ。
道化師はその少女を人形と信じて
疑わなかっただろう。

Page 1-3

おどけた化粧の下で道化師は焦る。
このまま少女が笑わなければ
「どうしてなの!!」
キンと響いた女の金切り声が 夢のような時間を切り裂いた。 道化師は咄嗟に跪く。

Page 1-4

「どうして笑わないの!」
ぬいぐるみの中から少女を引きずり出して
女が肩を揺さぶった。
少女の細い首が折れそうなほどに揺れる。 それでも少女の顔には恐れも怯え
浮かばない。

Page 1-5

「どうして!! 笑いなさい!
何とか言ったらどうなの!」
女は叫び、少女に手を振り上げた。 皇帝、アレクルスト・プロメネスは
妻であるメガーナ皇后を一瞥し、
「やめないか」
女の細い腕を男が掴む。
堂々たる偉丈夫を女は涙目で見上げた。
「陛下・・・・・・」
娘の小さな顎に手をかけた。

Page 1-6

「エディナ」
人形のようにされるがまま。
ガラス玉にも似た娘の目をのぞき込み、
皇帝は不敵に口角を上げた。
「皇帝である私を無視して
生きていられるのはお前だけだな」

Page 1-7

「陛下、申し訳ありません。
姫が、 こんな······ 無礼な······」
皇帝がエディナの薄い肩を軽く押すと、
青ざめる皇后に皇帝は手を振った。
少女はぬいぐるみの中へと埋もれていった。
起き上がるそぶりさえ見せない。
「子を産むための道具に 感情など必要なかろう」
蓄えた顎髭を撫で、皇帝は酷薄に笑う。

Page 1-8

「愛だの恋だのほざきながら、役にも立たん 男に現を抜かす馬鹿娘になるよりはましだ。 違うか?」
皇帝は無表情のエディナを
じっくりと眺める。
無情な眼には愛情の欠片も見られない。
「愛想などなくても子は産める。
それで十分であろう?」
「ですが陛下のお子はエディナしか・・・・・・」
震える皇后の肩を抱き、
皇帝は低くささやいた。
「ならば、跡継ぎを作ればよい。 皇后よ。 そなたが産めばよいのだ」

Page 1-9

男と女が去って行く足音を聞きながら
道化師はブルリと身を震わせた。
(助かった・・・・・・)
姫を笑わせられなかった咎で殺されると
思ったが、難は逃れたらしい。
(あの子も可哀想に・・・・・・)
道化師が姫を哀れんだ、そのときだった。 「誰か あの役立たずを始末しておけ。 道化師は好かんのだ」
遠くから皇帝の無慈悲な声が聞こえる。 道化師の頬に描かれた偽りの涙の上を、 本物の涙が流れて落ちた。

Page 1-10

「今日からここがあなたの部屋です」 乱暴に手を引かれたエディナが
放り込まれたのは、宮殿の片隅にある 暗くて狭い部屋だった。
エディナの周りから仕えていた者たちが
いなくなったのはいつのことだろうか。
甲斐甲斐しく世話をしていた者たちは消え、 そうして連れてこられたのが、
寝台以外、何もないこの部屋だ。
それでも自ら何も望まない少女には、
十分な部屋だった。

Page 1-11

エディナは突き飛ばされた勢いで膝をつく。
彼女の手を引いてきた侍女は
悪意をその幼い耳に吹き込んだ。
「皇后様がお世継ぎをお産みになりました。
だから、あなたはもう必要ないのです」
「道具は物置に
しまっておくのが一番。 いずれ年頃になれば、 また使い道ができるでしょう」
それまでお待ちくださいね。
侍女のケラケラと嗤う声が!
部屋の中に満ちていった。
帝都は跡継ぎの誕生に沸いていたが、 エディナの周りは凪いだように静かだった。

Page 1-12

宮廷の一室に閉じ込められ、
必要最低限の世話だけ与えられる。
けれどエディナは悲しまなかった。
怒らなかった。
嘆くことも、怯えることさえなかった。
そうして、 エディナ姫という存在は、 人々の中から忘れ去られていった。

Chapter 2

道具の賢い使い道

Page 2-1

「どうしてなの!?」
皇后は絶叫した。
火が付いたように泣く赤ん坊を抱きながら、
呪うように医者たちをにらみつける
(わたくしには、この子しかいないのに)
身ごもっている間に皇帝が
先天性の不治の病必死の思いで産んだ
皇太子への残酷な宣告だった。
第二皇妃を迎えた。
皇后よりも若く、気立てもいい。
皇帝は溺れるように寵愛を与えている
きっとすぐにでも子を宿すだろう。

Page 2-2

「治しなさい! 何としてでも!
できなければ命はないと思いなさい!」
皇太子を失えば、 名ばかりの皇后になる。
そんなことには耐えられない。

Page 2-3

皇后の気迫に震え上がりながら、 医者は必死の思いで口を開いた。
ロから出任せだった。
「手術をすれば、わずかではありますが、
延命できるでしょう。
すべては、医者のための延命手術。 ――そのはずだった。
その間に治療法が見つけられれば・・・・・」

Page 2-4

「エディナ」
誰からも忘れられて生きていたエディナは、 久しく聞いていない声に目を開けた。
強く引っ張られた腕が抜けそうだった。
あっという間に身体が宙に浮き
ぐるりと視界が回る。
「早く連れて行ってちょうだい」 背の高い屈強な兵士の肩の上から、 エディナは声の主を見下ろした。
母だ。 皇后はエディナと目が合うと、
歪な薄ら笑いを浮かべて見せた。

Page 2-5

腕から輸血用の血を抜かれる娘の傍らで、 皇后はさえずるように言葉を紡ぐ。
「ああ、エディナ。 やっと、 役に立つのよ。
これからあなたの弟が手術をするの。
あなたの血を分けてやってね」

Page 2-6

皇后の腕には宝物のように抱かれた皇太子が
穏やかな顔で眠っている。
初めて弟を見ても
エディナには何の感情も湧かない。
何もかもがどうでもいい。
少女はただ寝台の上で静かに目を閉じた。

Page 2-7

「これは・・・・・・何ということでしょう。
皇太子殿下の病が完治しております!」
医者が喜色を浮かべて告げたのは、
手術から数日後のことだった。
「ああ、奇跡だわ! けれど、なぜ?」
皇后に問われた医者は、
あるひとつの仮説を立ててみせた。
「医学的には説明できません。
これは、 高貴な血が成せる奇跡かと!」
プロメネス帝国の歴史は古く、遡れば 古代に栄華を極めた黄金の国へと行きつく。 名高い 黄金王の血が現皇帝にも流れていた。
長い歴史に刻まれた伝説によれば、
皇帝の血統にはごく稀に、
不思議な力を持った子供が生まれるという。

Page 2-8

「エディナが伝説の力を持っている。 と?」
皇帝は疑わしげにエディナを見下ろす。 相変わらず人形のように表情が動かない。
「この血をよく調べるべきですわ。 陛下」 興奮気味に告げる皇后の目は
爛々と輝いていた。

Page 2-9

「エディナはこの帝国の姫だ。 高貴な血を研究対象とするだと?
皇后よ、 気でも触れたか」
「わたくしは正気ですわ、 陛下。
ご覧になって、皇太子の病が治ったのです」
「知っている。 不治の病であったと······ だが、なぜエディナの血を使ったのだ」
「高貴なる血にどうして下験な血を
混ぜられるでしょう。
エディナは姉ですもの。
弟のために尽くすのは当然ですわ」

Page 2-10

「しかし」
「陛下」
渋る皇帝の耳に皇后は密やかにささやいた。
「永遠の命が欲しくはありませんか?」 目を丸くする皇帝に、皇后は艶然と笑う。

Page 2-11

皇帝の一族に永遠の命を
もたらすと・・
「伝説では、その不思議な力が
毒婦のような皇后の誘惑に、
試す価値はありますでしょう?」
皇帝の喉が大きく上下した。

Page 2-12

エディナ姫、 逝去。
その訃報を聞いた帝都の人々は、
一様に首をかしげた。
「エディナ姫? そんな姫、 いたっけ?」
幼くして事故で亡くなったと聞いても、
可哀想にとありきたりな哀れみが
よぎるだけ。
葬儀は国を挙げてしめやかに行われたが
人々の顔に悲しみはなく、
悲劇は日常に埋もれていく。

Page 2-13

「ああ、エディナ。 可哀想な子・・・・・・」
喪服姿の皇后は、
娘を失った悲しみに身を震わせた。
その顔を覆う黒いベールの下で、
皇后が残酷な笑みを浮かべていたことは
誰も知らない

Chapter 3

怪物の夢と目覚め

Page 3-1

「なんて美しいのかしら......」 皇后は白衣の研究員に捧げられた 小さなガラス瓶を
うっとりと目の前にかざした。
淡い金色に輝く液体がとろりと揺れる。

Page 3-2

「これが、黄金の血清・・・・・・」
古代は黄金の国。
皇帝の血脈に受け継がれてきた奇跡の力。
「これで、永遠の命と美貌が手に入るわ」
皇后はすっと視線を動かした。
「嬉しいでしょう? エディナ」
帝国第九研究所。
その一室で、 エディナは死んだように
ぐったりと目を閉じて眠っていた。
顔色は紙のように青白い。
小さな唇にはひび割れた皮が白く浮いて、 みずみずしさも若々しさも失われている。

Page 3-3

エディナの訃報は偽りだ。
人体実験の終わらない苦痛の中を、 死ぬことも許されず、 生かされていた。
「もっともっと、役に立ってちょうだいね」 眠るエディナへの優しげなささやきは
まるで呪いのようだった。

Page 3-4

永遠に続くかと思ったエディナの苦痛は、 ある日突然終わりを迎えた。
研究所を揺らす振動が
激しい音と共に近づいてくる。
部屋の外で研究員たちの逃げ惑う声がした。
彼らはエディナを捨てていくようだ。

Page 3-5

何が起きているのか分からなかった。 何が起きていてもどうでもよかった。
(これでおしまい)
そう思ったエディナの目の前に、
真っ青な空が、 ぽっかりと広がった。

Page 3-6

青が広がったのは一瞬。
全て土煙に呑まれ、 エディナはいつの間にか
瓦礫の上に放り出されていた。
体中が痛んだ。
どうにか起き上がって見回すと、 研究所が破壊されていた。
震える両膝に力を込めて立ち上がる。 裸足の足裏に瓦礫が食い込んだ。

Page 3-7

土埃の舞う空気を肺いっぱいに吸い込めば、
近くで上がる炎の焦げ臭いにおいがした。
「私、 生きてる」

Page 3-8

エディナの足取りは軽やかだった。
いつか見た道化師のように、
足下の瓦礫を軽やかに踏みながら行く。
うめき声を上げる研究員を
無感情に見下ろした。
血溜まりを作って絶命する研究員を
無感動に踏みつけた。
誰も何も言わない。
エディナは自由だ。
ふと と誰かに呼ばれた気がして
エディナは振り返った。

Page 3-9

呼ぶ声の先にあったのは林檎だった。 不思議な色に美しく輝く林檎が、 破壊を免れた研究室で少女を待っていた。
輝く宝石のようなお菓子よりも
ずっとずっと美しくおいしそうな林檎を、 エディナは初めて食べたいと思った。

Page 3-10

愛おしむように口づけて、
その甘い甘い匂いを胸いっぱいに嗅いで、 エディナは小さな歯で林檎をかじる。
その瞬間、目映い輝きが少女を包み込んだ。
エディナはまどろむように、
光にその身を預ける。

Page 3-11

[ページ種類：青]
（数本の触手と黄金の城が燃え盛る絵）

Page 3-12

長く、 そして爽快な夢を見た気がする。 エディナはまつげを震わせて目を開いた。 頭がはっきりせず、 夢と現実の境が曖昧だ。
「あ、ああ! 化け物・・・・・・!」 どこに化け物がいるのだろう。
職員の悲鳴に振り返ったエディナの目に、 すぐに怪物が映り込んだ。
[Page41]
「これは······ 私?」
ガラスに映るエディナの背中には異形の翼。 幾本もの触手が小さな身体を覆い。
触手の目がぎょろりとエディナを見返した。

Page 3-13

そうだ急に頭の中のモヤが晴れた。
夢の中でエディナは怪物だった。
この姿こそ、本当の姿だ。
銃声が響いた。 十や二十では足りない。
エディナを殺そうと雨のように降り注ぐ。 けれど、痛みも何も感じない。
ただ煩わしかった。
虫を払うように手を振れば、
うるさく逃げ惑う兵士や研究員たちは、 たちどころに弾けて消えた。
「あは!」

Page 3-14

軽やかな笑い声が崩壊した研究所に響いた。
これまでの短くも苦痛に満ちた人生の中で、 こんなに愉快だったことはない。
「そうだ! お母様に見せてあげましょう」
あんなにも笑えと言っていたあの人に、 この姿を見せてあげるのだ。

Page 3-15

そうして、そうして一
「ふふ・・・・・・ふふふ......」
天使のように笑ったエディナは
異形の翼を羽ばたかせ、
研究所を飛び立った。

Page 3-16

黄金の血清を手に入れてから、
皇后の人生は何もかもが順調だった。
永遠の命、若さと美貌、
皇帝の寵愛も戻った。
もう自分を脅かすものは何もない。
不意に部屋の中に風が吹いた。
誰が窓を閉め忘れたのかと 苛立たしく思いながら振り返る。
「こんばんは、お母様。お元気でした?」
開け放たれた窓の外。
あどけなく笑う娘が異形の姿で立っていた。

Page 3-17

皇后の突然の病死により第二皇妃が皇后に 即位したその日、帝都ではある噂が
まことしやかにささやかれていた。
「知ってるか? 皇后は病死なんかじゃ
なかったんだってよ」
「じゃあ、なんで死んだって言うんだ?」

Page 3-18

「全身の血を抜かれてたらしい。
しわしわでミイラみたいになってたんだと」
「何だ、そりゃあ。 誰がそんなことを?」
「そんなの決まってる。 怪物さ!
怪物が皇后を殺したんだ!」
ーと。

Fin.
