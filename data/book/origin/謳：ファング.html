Chapter 1

オオカミ

Page 1-1

「旧市街」は帝都で最も治安の悪い地区だ。 神獣に破壊された廃墟で暮らすのは
弱者か犯罪者しかいない。
真夜中 旧市街の入り組んだ街路を、 ジリアン・ジルダは歩いていた。
帝都の中心にそびえるオーパーツ
「不滅の炎」の放つ光が、 汚れた路地に
長い影を伸ばす。

Page 1-2

届くのはオーパーツの光だけだ。
「不滅の炎」は無限のエネルギーを生むが
「商売女は呼んでねえぞ」
その恩恵が旧市街にもたらされる事はない。 部屋から現れた刺青だらけの男が
古く汚い集合住宅、 その一室の前に立ち
ジリアンは呼び鈴を押した。
ジリアンを恫喝する。

Page 1-3

ジリアンは男の鼻柱を殴りつけると、
ひるんだ男の足を払い、床に叩きつけた。
そのまま男にのしかかり、
ナイフを喉元に突きつける。
「この娘に見覚えは？」
ジリアンは男に写真を見せた。 幼い少女が
陽だまりの中で微笑んでいる。
男の顔色が変わった。
「お前、「狼」か」
それはギャングたちの間で噂になっている
殺し屋の名前だった。

Page 1-4

帝都の裏社会では長く抗争が続いている。 ギャングたちの抗争は無関係な市民さえも 巻き込み、多くの罪もない人々が
命を落としていた。
長年の抗争を制し裏社会のトップに 君臨したのは、ゴルギアス・ファミリー。
ジリアンの目の前で無様に震える男が
属している組織だ。
ジリアンの妹はゴルギアスの抗争に
巻き込まれ、流れ弾で死んだ。 不運と言えばそれまでだろう。 旧市街では
珍しくもない、ありふれた日常だ。
ジリアンは許せなかった。 それでも、 妹の復讐をせずにはいられなかった。
「私を知っているなら話は早い」 「待てっ、待て！ 俺の話を――!!」

Page 1-5

命乞いを聞く耳など持っていない。
切り裂かれた男の首から血しぶきが 吹き上がり、薄汚れた壁を赤く染めた。 「あの子の痛みはこんなものじゃない」

Page 1-6

小さな気配を感じ、 ジリアンは振り返った。
クローゼットの扉を開けると、 その中に
ガタガタ震える幼い少女がいた。
ジリアンは目を細め、 血に濡れた顔を
少女に近づけて、ささやいた。
「お前の兄貴が悪いんだ」
少女の絶望が、 ジリアンを見あげた。

Page 1-7

もうここに用はない。 身を翻し部屋を後に する。 ジリアンの背後で、少女が兄の名を
呼び、泣き叫ぶ声が響いた。

Chapter 2

ケダモノ

Page 2-1

脇腹を焼け付くような痛みが襲う。
流れる血を押さえ、 廃病院の床にうずくまり
ジリアンは荒く息を吐いた。
あの日から、何もかも滅茶苦茶だ・・・・・

Page 2-2

殺された妹のための復讐は正当な復讐。
あの子の魂を救うには、ゴルギアス
ファミリーを滅ぼすしかない。
そう信じてジリアンは血で手を染めてきた。
けれどあの日殺した男は――ゴルギアス・ファミリーとは無関係の男だった。
罪悪感がジリアンから冷静さを奪った。 運にも見放された。 何をしてもケチがつく。
最大のケチがこれ――
ゴルギアス・ファミリーの急襲だった。
罪のない人間を手にかけたのだ
あの男の妹の泣き声がまだ耳に残っている。

Page 2-3

妹を殺したヤツらに殺されるわけには
いかない。向かってくる者を殺した。 旧市街を駆け抜け、 廃病院に逃げ込み、 ひたすら殺し、殺し尽くした。
「それ」に気づいたのは、最後のひとりが 倒れた後だ。血溜まりに顔を突っ込んだ
死体を仰向けにする。
呼吸が止まった。

Page 2-4

仰向けにした少女の顔に見覚えがあった。 クローゼットの中で震えていた少女―― 間違えて殺した男の妹だった。
「なぜだ……」自問するまでもない。
罪もなく殺された兄の復讐に来たのだ。

Page 2-5

また罪のない人間を手にかけた。 それでも、 ゴルギアス・ファミリーを消滅させるには
殺しを続けなければならない。
ジリアンが復讐を続ける限り、
罪無き者の死体が増えるだろう。
ジリアンの妹のような死体が。

Page 2-6

(疲れた......)
押し殺していた感情が言葉になった。 その時、廃病院の窓から 小さな缶が 放り込まれた。缶からガスが噴き出す。
逃げなければ。 だが、身体が動かなかった。
このままここで死んでしまいたい。
ジリアンの意識が薄れていく。 暗闇の中で大勢の足音を聞いた気がした。

Page 2-7

白い天井にジリアンは眉根を寄せた。
「地獄とは案外美しい場所かもしれません」
聞き覚えのない声。 反射的に起き上がると、 身体を激痛が襲い、うずくまる。
「おお、 お元気そうだ。 さすがは「狼」」
白い帽子に白いスーツ、部屋に同化して しまいそうな男が足を組んで座っていた。
「お前は…… ここは……？」

Page 2-8

警察病院だと奇妙な風体の男は言った。 自分は帝国軍の徴兵官だ とも。 「徴兵官? そんなものが私に何の用だ」 「はて、徴兵以外に理由があると？」
男は悠然と足を組み替えると、
2本の指を立てた。
「あなたにはふたつの道があります
「ひとつ、裁判を受ける。 よくて無期懲役。 まず死刑でしょう。 あまりに殺しすぎた。
まあ、裁判を受ける前にどこかしらで
暗殺されるのは目に見えていますがね」
「もうひとつの道は、 林檎をかじること。
あなたに資格があれば天使になれる。 資格がなければ無様に死んでいく。 どう転ぶかは賭けですな」

Page 2-9

「林檎を寄越せ」
手を突き出すジリアンに男は目を瞬かせた。
「やはり狼も生に執着しますか？」
ジリアンは男を睨んだ。
「命は惜しくない。 だがこのままでは
私は殺される」
「殺されたくはない、と」
白い帽子の男が皮肉めいた口調で言う。

Page 2-10

「私は殺されて当然の人間だ。
だが。 誰かが私を殺せば、殺した者も
罪に問われるんだろう？」
「それはまあ。 殺人ですから」
つみびと
「罪人を増やしたくない。 罰を受けるのは私だけで十分だ」
「おもしろい考え方をしますね。
あなたには資格がありそうだ」
男は、 異世界の空を閉じ込めたような輝きを
放つ林檎を、 ジリアンに差しだした。

Page 2-11

受け取った林檎はずしりと重かった。
「私は獣だ。
天使になれる資格などあるわけがない」
ジリアンは自嘲した。
「確かに。 殺されたから殺すなんてのは
人間のやることじゃありません。
男は爪を立てる獣の仕草をした。
「あなたはさしずめ、
「人狼 というところですか。
醜く愚かで、残虐な獣
ですが獣はもっと賢い。 本物の狼は
復讐に走るほど愚かではありません」

Page 2-12

「「人狼」 か・・・ その通りだ」
小さく笑い、 林檎に歯を立てる。
(これは、贖罪だ。 死をもって私は
ジリアンの手から林檎が転がり落ちた。

Chapter 3

Page 3-1

長い 長い夢を見た。
人狼となり、逃げ続ける少女の夢だ。
夢の中でジリアンはアビーと呼ばれていた。 嫌な夢だった。
結論から言うと、ジリアンは天使として 目覚めた。 見知らぬ者たちがジリアンの
天使化を祝った。
(何がおめでとうだ。 反吐が出る)

Page 3-2

眠っている間にずいぶん時が経ったらしい。
噂によれば、 帝都では
ゴルギアス・ファミリーの勢力が弱まり、 抗争が再び激化しているそうだ。
より多くの市民が犠牲になった。 「私のしたことは、全部無意味か……」 今日もまた、街のどこかで銃声が響き、 誰かが涙を流すのだろう。

Page 3-3

獣になれば、 妹を奪われた悲しみを
正当化できると思っていた。
復讐をすれば、この気持ちを追いやれると。 だが――。
(残酷な殺人者は人でなし。
狼は復讐をしない。
復讐をした私は、狼ではない……。 では、私は何だ?)
あなたはさしずめ、
「人狼」 というところですか。
「……醜く愚かで、残虐な獣」 男の言葉を舌先で転がし、 呑み込む。
不意に、人狼の少女の夢が
脳裏をよぎった。

Page 3-4

「お前は獣にはならない。お前が俺たち 一族の罪を背負う必要なんてないんだ」
夢の中で、少女の兄はそう言った。

Page 3-5

ヒトを喰わねば獣に一狼になってしまう。
そう固く信じていた妹に向かって告げられた 「獣にならない」 という言葉が、 そのままの意味であったなら?
そうならば悲劇だ。
それを、少女は知らなかった。 だからヒトを殺し、 ヒトを喰らった。 狼にならないために……。
あの少女は人狼でなくヒトで、何らかのそんな妹に、どうして真実を告げられる?
理由で人狼の家族として育てられた。
一家の非常食だったのかもしれない。

Page 3-6

兄は妹を殺さなければならなかった。 真実を伝えれば無用の殺人という罪を負う。
真実を伝えねば新たな食人という罪を生む。
ならば真実を伝えず、
妹を押しとどめたら?
食人を止めれば、 妹は真実を知るだろう。
正しい食事をしなくても獣にならない自分が
人狼でないと気付くはずだ。
生きるためと信じて殺して喰らった行為が
何の意味もなかったことを――それどころか 生きるために喰らう狼にも劣る生き物に
なったことを知るだろう。

Page 3-7

妹に真実を知らせてはいけない。 真実を気付かせてはならない。
だから妹を守り、 その罪を背負うために……
兄は、妹を殺さなければならなかった。

Page 3-8

「余計な事をしたりんだ」
ジリアンはぽつりと呟いた。
「……罪は消えない」
あがな
「自分の罪は、 自分で贖うものだ」
誰も、他人の罪を背負えない。
たとえどんなに残酷な真実でも、
兄が背負えるのは唯一、
罪に押しつぶされそうになったとしても、
殺すことで妹を救ったという。
背負い続けて生きていくのだ。
自己満足に塗れた新たな罪だけだ。

Page 3-9

ジリアンは両手で顔を覆い長く息を吐いた。
林檎をかじれば死ねると思っていた。
なのに、今もこうして生きている。

Page 3-10

「なら、 私は生きよう」
罪を背負い、 生きる。
生きて、贖う。
天使となったその意味を、
神獣との戦いに問いながらー。

Fin.
