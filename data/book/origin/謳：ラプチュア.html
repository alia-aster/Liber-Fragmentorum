Chapter 1

裏路地の女王

Page 1-1

青空の下、 まぶしい陽気を浴びながら
彼女は帝都の繁華街を歩いていた。
商売に勤しむ人々には目もくれず 彼女は狭い道に体を滑り込ませて
裏路地に向かう。

Page 1-2

「ども、 ネフェル姐さん」
「今日もめっちゃセクシーっすね」 裏路地の住民たちは競うように彼女を ほめそやし、彼女の後をついて歩いた。
「相変わらずお前らは 余のことが大好きじゃのぅ」
彼女 ネフェルはつんと鼻を上げ、 当然のように男たちを従えて歩く。
「輝き」は手に入ったんですか?」
翠色の瞳を持つ男がそう尋ねると
彼女は足を止めた。

Page 1-3

「まだじゃ。だがいつか手に入れてやる」
顔を輝かせて彼女は笑った。
裏路地一帯で、彼女を知らぬ者はいない。
ネフェルが通ればみな畏敬の視線を向け、
彼女の寵愛を受けようと必死になった。

Page 1-4

だが時としてそれを知らぬ新参者が
ネフェルに居つくこともある。
「「輝き」を欲しがるなんて どんな豪胆な野郎かと思ったら女かよ」
何も知らない田舎者の大男が
「女が、 どうした?
余に文句をつけるとはいい身分じゃのぅ」 ネフェルは臆することなく彼を見上げる。
「なんならわからせてやろうかの。 お前ごときが余には勝てぬということを」
にやつきながらネフェルを見下ろした。

Page 1-5

「おいおい。あんたみてぇなか弱い女を 殴ったら俺の方がダサいじゃねーか」 馬鹿にしたように男は笑い、 肩を竦める。
「安心せい。 貴様が余を殴れるわけがない」
ネフェルの瞳がざらりと光った。
「ぐはっ......」
田舎者のみぞおちに拳を叩き込んだ。 男の身体はあっけなく沈み、 派混じりの水たまりに叩きつけられた。
次の瞬間彼女はぐっと身を沈め

Page 1-6

周囲の野次馬がわっと湧く。
ネフェルへの賞賛が飛び交う中、
男は呆然としたまま泥水に浸かっていた。
ネフェルは、自分の足が汚れるのも構わず
彼に歩み寄って顔を覗き込んだ。
「これから三ツ星レストランで 昼飯にするのじゃが、お前も来るか?」

Page 1-7

ネフェルは仲間と田舎者を連れて
帝都で最も有名な三ツ星レストラン
の裏口にやって来た。
「今じゃ! 行くぞお前ら!」
シェフが店内に戻ったのを確認し、 ネフェルはゴミ箱に飛びついた。
「よしきた! 姐さんに続け
薄汚れた裏口のドアが開き、
若いシェフが現れた。
ゴミ箱の蓋を開け、残飯を放り込む。
ネフェルの後を追い、みながゴミ箱に
よじ登ると、協力して蓋を開ける。

Page 1-8

ゴミ箱の中にはかじりかけの肉や
骨にこびりついた白身魚の身、
野菜の切れ端などが詰まっていた。
「にょほー!食べ放題じゃー!」
「姐さんはグルメだからなあ!」
「やっぱここの飯が一番っすよね!」
仲間たちが飯にかじりつくのを見ながら、 ネフェルはゴミ箱の上から呼びかける。
「ほう、でかいの。お前も食うじゃろ?」 「うっす! 姐さん!」

Page 1-9

「そういえば姐さん、聞きました?」
重く暗い雲が空を覆うある日、
すっかり仲間に馴染んだ大男が尋ねた。
「なんでもこの帝都に神獣ってのか 襲撃してくるって噂があるらしいんす。 そいつが来ると帝都が滅ぶんだとか」
「それ俺も聞いたことある。
最近人間たちみんな噂してるよな」
仲間たちは口々に「自分も聞いた」と話す。

Page 1-10

「ふうむ…… 人間共がのぅ」 ネフェルは鋭く目を細め、
人々が行き交う繁華街を振り返った。
神獣とやらに怯えながらも、 人間共の生活は何も変わっていない。 こちらを見ることもなく、
普段通りに金と物を交換している。
(やはりあれは愚かな生き物だ。
ろくに考える脳もなく、想像力が足らぬ)

Page 1-11

ネフェルはかつて飼い猫であった。
彼女は飼い主の人間の愛情を信じて
疑わなかったが、人間は突如彼女を捨てた。

Page 1-12

ネフェルがその後どうなるかなど、 まるで考えもせずに。
生き残るためには強くなるしかなかった。 裏路地の男共に負けないくらいたくましく けれど裏切られぬよう慈愛も忘れずに。
気づけばネフェルは、
裏路地の女王猫になっていた。
「人間たちは滅んでもいいが お前らのことは守ってやらんとなぁ」
自分を取り囲む仲間たちの顔を眺め、
ネフェルはゆったりと尻尾を左右に揺らす。

Page 1-13

そして、にっと不敵な笑みを浮かべた。
「ま、 神獣ってのが何かよく知らんが、 余は強いから大丈夫じゃろー!
「さすがっす、 姐さん!」
「一生ついていきますぜ。 姐さん!」

Chapter 2

ゴミ溜めの参

Page 2-1

(……どうしたものかのぅ)
ネフェルはぼんやりと空を見上げた。
(こんな穴ぼこに落ちるとは想定外じゃ)

Page 2-2

――数時間前。
ネフェルは路地に捨てられていた
ソファの上で昼寝をしていた。
ぽかぽかした陽気にくるまれて ぐっすり眠り込んでいたせいで
気づかなかった。
ネフェルはゴミ収集のトラックに
積み込まれソファと共に収集所に運ばれた。 そして、深い縦穴に放り込まれてしまった。

Page 2-3

(うむむ……脱出しようにも
の深さじゃどうにもできぬのぅ)
ネフェルの視線の先には「輝き」がある。
(眩しい……)
「輝き」は昼間の空にだけ浮かび、
いつも堂々と力強く光っている。
(敗しいが、 綺麗じゃ)

Page 2-4

(いつかはあれが欲しい。
あの眩しいものの近くに行って
「輝き」を余のものにしたい)
くうと腹の音が鳴った。
いくら空を見上げ夢を見ても、 現実はゴミ溜めの穴の中。
(腹が減ってはなんとやらじゃな ネフェルは食料を探すことにした。

Page 2-5

だがいくら歩いても食べ物はない。 生ゴミがあればまだよかったが、 この穴には粗大ゴミしか見当たらなかった。
(まさかこのままここで力尽きるのか?
夢も叶わぬまま、こんな間抜けな状況で?)
ネフェルは穴の底をさまよい続けた。 やがて前足も重たくなり、あまりの空腹に
倒れそうになった頃、見つけた。

Page 2-6

(これもゴミか? いや……)
ソレの形は見知った果物だったが、 その色は摩訶不思議に煌めいている。
「林檎……なんじゃろうか」
つん、と前足でつつく。

Page 2-7

ころんと転がったそれは「輝き」の光を
照り返し、奇妙な色合いに光る。
鱗をまとった林檎か…… まずそうじゃな
まるで魚の鱗のようでもあった。
しかし背に腹は変えられない。
腹の虫は飢えを訴え続けている。

Page 2-8

ネフェルが恐る恐る林檎を響ると、 甘い果汁が口の中に広がった。 喉も乾いていた
彼女は一心不乱にかぶりついた。
だが林檎を食べ終えようかという頃、 ネフェルは自分の体が金糸のような
光に包まれていることに気づく。
「にゃ!? なんじゃこれはぁ!?」

Page 2-9

光に気づくと同時に、
ネフェルの身体はぐうりと倒れた。
仰向けになったネフェルは
空に浮かぶ「輝き」 を見上げる。
まぶたが重く閉じていく。
「毒林檎じゃった か……」
後悔と共にネフェルの意識は沈んだ。

Page 2-10

「ああ、女神よ。
再び彼らの前に現れたまえ。 再び我らに救済を――」
豚を地につけ、組んだ両手を掲げながら
神官たちは祈りの言葉を唱え続ける。

Page 2-11

[ページ種別：青]
かつて、ここは楽園と呼ばれていた。
だが今となっては古い遺跡でしかない。
神官たちは遺跡の神殿で
季節も昼夜も関係なく救済を願い続ける
神官・ネフェルトゥムは神殿の中で祈る。
「再び我らに救済を――」
共に生きる仲間たちのために、
この世界を救わなければならないから

Page 2-12

[ページ種別：青]
楽園はごみくずと化した。
崩れた瓦礫に囲われた中で、
涙が枯れても女神を呼び続ける。
しかし何日、何ヶ月何年と祈り続けても
女神はいっこうに姿を現さない。
(いつになれば女神は復活するのですか?)
(世界は救われるのですか?)
(祈りは報われるのですか?
女神の復活など叶わぬ夢なのでは?)

Page 2-13

[ページ種別：青]
毎日毎日神殿に足を運ぶうちに
神官としてあらぬ考えがよぎったその時、 ネフェルトゥムの耳に 「声」が届いた。
「ネフェルトゥム。 聞こえますか。 これよりあなたが女神となり、
この世を救うのです」

Chapter 3

救いは誰の手に

Page 3-1

[ページ種別：青]
「ネフェルトゥムよ。 聞こえますか
あなたは選ばれし者。
世界を救済するのです」
ネフェルトゥムは歓喜した。
ついに祈りが届いたのだ!
心の中に響く美しい声に向けて
ネフェルトゥムはおずおずと尋ねる。

Page 3-2

[ページ種別：青]
「あなたは女神様なのですね」
「いいえ。 私は御使いにすぎません。
あなたが女神となるのです」
「私が... 女神に……?」
「然り」
「一体どうすれば良いのですか」 ネフェルトゥムは声に問いかける
声は導くように優しく答えた。
「歌の断片を集め、
真の顔の肉を喰らうのです。
さすれば、女神の力を得るでしょう」
「なんということ......」
ネフェルトゥムは息を呑んだ。

Page 3-3

[ページ種別：青]
「甘言を弄するでない!」
ネフェルトゥムの言葉が空気を断ち切った。
かつて、同じように女神を名乗る声を聞き 偽りと気づかず破滅した聖女がいた事を
ネフェルトゥムは知っていた。
「消えろ!」
ネフェルトゥムは虚空に向かって叫ぶ
それきり声は聞こえなくなった。

Page 3-4

[ページ種別：青]
……その夜。
ネフェルトゥムは焦げ臭い匂いと 熱気で目を覚ました。
ネフェルトゥムの寝室が轟々と燃えていた
壁際の書物や家具は火に包まれ、
絨毯を這う炎は寝台に向かってきている。
(……あの「声」の仕業か。
神官の誰かが 「声」 にそそのかされ、 寝室に火をかけたのだろう)

Page 3-5

[ページ種別：青]
(ああ、女神様。
私を救ってほしいとは願いません。
声に惑わされた者をお救いください)
女神への祈りを中断し、
ネフェルトゥムは目を見開いた。
(祈っても仕方がないのでは?
願っても叶わない。 救いなど訪れない。
これまでずっとそうだったじゃないか)
私が 「声」 を止めなければ!」

Page 3-6

[ページ種別：青]
ネフェルトゥムは走り出した。
肌が焼けるのも構わず炎の壁を抜け、 寝所の外へ出る。
そして彼女は、夜の闇に消えていった

Page 3-7

ネフェルは目を覚ました。
どのくらい寝ていたかは定かではないが、
空はまだ明るかった。
(余は生きてるようじゃな……。
だが、やけに身体が重たいのう) 身体を起こし辺りを見るとゴミが無かった。 いつの間にか穴の外に出ていたようだ。
(妙な林檎を食べたのは覚えておる。
あれは毒林檎かと思ったが、
生きているならば違ったのじゃろうな)

Page 3-8

ネフェルはどうにか立ち上がり、
ちょうど近くを通りがかった猫たちに
手を振って声をかけた。
「なあお前ら。ここはどこじゃ?」 問いながら歩み寄ろうとすると、 猫たちは 「にゃあ!」と叫び一目散に逃げていく。
「なっ、余から逃げるなんて……。 おい待て、質問に答えるのじゃ!」 ネフェルは重い身体で必死に追いかける。
やがてネフェルは繁華街にたどり着いた。 猫たちは人間たちの間を縫って走り、 裏路地に消えて行ってしまう。

Page 3-9

「まったく仕方のない奴らめ……。
まあ、ひとまず知っている道に出られたから
よしとしてやるか」
見慣れた繁華街をぐるりと見渡す。 するとやたらと人間たちと目が合った。 人間はネフェルを興味深そうに眺めている。
(なんじゃ? ゴミの穴に落ちていたから よっぽどみすぼらしい姿になっているのか)
ネフェルが自分の姿を確かめるために ショーウィンドウのガラス窓を覗くと
「え……」

Page 3-10

「なんじゃあ!?これは!?」 ショーウィンドウのガラスに映る自分を見て ネフェルは悲鳴に似た叫び声を上げた。
ガラスに映っていたのは人間だった。 前足でぺたぺたと顔や全身を触るが、 そこに自慢の毛並みはない。

Page 3-11

代わりに頭から艶ややかな髪が生え、 肌はもちもちつやつやになっており、 身体を支える後ろ足はすらりと長く、
「にゃん、なんなんじゃ、 一体。
余は人間になったのか? しかしならば、 この羽はなんじゃというのだ!?」
背中からは七色に神々しく 輝く翼が伸びていた。
ネフェルは背中の翼を確かめようとするが、
くるくると回るばかりで上手く見れない。
そんなネフェルを見て人間たちは足を止め、 どんどんヤジ馬が増えていく。

Page 3-12

「…… 天使様だ……」
誰かがつぶやいたのをきっかけに、
「やめろやめろー!!
人間風情が余に近づくなぁ!」
ネフェルが逃れようと手を振り回すと
人間たちはわっと声を上げネフェルを囲む。
ばさりと両翼が大きく動いた。

Page 3-13

するとふわりと重たい身体が持ち上がる。
「おお? おおおおー!!」 ネフェルは地面から飛び立ち、浮いた。 翼を使って飛ぶことに成功したのだ。

Page 3-14

翼を羽ばたかせると、さらに上へ浮かぶ。
ネフェルの眼下には呆気に取られた人間共と
建物の底に止まるスズメが居た。
ネフェルは羽ばたき、天を目指した。
「そうじゃ、 鳥のように飛べるのならば……その姿に人間たちはさらに盛り上がった。
余はついに 「輝き」 を手に入れることが
できるのではないか!?」

Page 3-15

「ああ天使様! 我らをお救いください!」 「神獣から帝都をお守りください!」
「天使様! お願いです、 天使様!」
両手を組んで祈りながら、
人間たちはネフェルに救済を願う。 だがネフェルはそれを鼻で笑った。

Page 3-16

「知らん! お前ら人間がいくら祈ろうと
余は勝手にするだけじゃ!
お前らがそうしてきたようになぁ!」
そして彼女は、空高く舞い上がる。
「輝き」を手に入れる。
その夢を叶えるために――
