謳：スレイヤー（水着Ver.）

Chapter 1

スレイヤーの休息

Page 1-1

スレイヤーは、完全装備で白い砂浜に
降り立った。
「命令は、ここで間違いないのですが......。 どういうことでしょうか?」
水着ではしゃぐ若者たち。 日光浴をする者、
ヤシの実のジュースを売る屋台・・・・・・。
そこは紛れもなくリゾートビーチだった。
何度命令書を見返しても、この場所だ。
みじん
だが、ここに敵の気配など微塵もない

Page 1-2

ざぱーん。
波打ち際に、
「あざらしさんも一緒なんですね!
ここで私に特別任務があると聞いて
やってきたのですが......」
「その通りキュ! 私がスレイヤーの 教官として特別訓練を受け持つキュ。 めちゃくちゃ鍛えてやるから覚悟しろキュ」
「分かりました、 あざらし教官!」
丸くて白くてふわふわしたものが
打ち上げられた。
「キュキュ! スレイヤー待ってたキュ!」 あざらし (種族名) の
あざらし(コールサイン)だ。

Page 1-3

「スレイヤー、 行っくキュー!」 ふわり。 あざらしがトスした
ピーチボールが宙を舞う。
スレイヤーは助走と共に高くジャンプ!
神獣殺しの豪腕でピーチボールを思い切り
ブッ叩いた。

Page 1-4

-チボールが大気を切り裂いた。 砂浜に突き刺さり、破裂する。
周囲に砂煙が舞った。
「目標を撃破しました」
「キュ・・・・・・ ナイスなアタッキュ・・・・・・。
つ、次行くキュ!」

Page 1-5

スレイヤーは複雑な表情で
バナナボートにまたがる。
あざらしに曳かれ、 スレイヤーを乗せた
波しぶきをあげ、
バナナボートが波を切り裂き、 凄まじいスピードで海面を突き進む。
ボートをひっぱるのは、あざらしだ。
「これでバランス感覚を鍛えるキュー!」

Page 1-6

「あざらしさん、 前!」
前方に、大きな壁のような波が迫ってきた。
「ビッグウェーブキュー!」
ふたりは見事に海へと放り出された。
「スリル満点で楽しいキュ!」
海面からぷかりと顔を出してあざらしが笑う。
「······ そうですか?」
「つ、次キュ!」

Page 1-7

南国風のカフェで、
スレイヤーは背筋をピンと伸ばし、
リラックスとは無縁の表情で座っていた。
「キュキュ。 これを飲むキュ。
ココナツ、マンゴー、トロピカルなフルーツ
たっぷりのドリンキュ......」

Page 1-8

ズゴッ!
神獣殺しの肺活量で、 スレイヤーは
一瞬でドリンクを飲み干した。
「キュイッ!?」
「いったいどこが訓練なんですか?
遊んでるだけですよね?」
スレイヤーは真顔で立ち上がる。
「・・・・・・仕方ない。 教えてやるキュ」

Page 1-9

「人生を······ 楽しむ訓練だキュ!」
そう言い放ったあざらしのドヤ顔を
スレイヤーは醒めた目で見つめる。
「人生を楽しむ訓練だキュゥゥウウ!」
さらに、もう一度繰り返した。
「••••••騙したんですか?」
冷え切った声でスレイヤーがつぶやいた。
「キュキュ!?(やば••••••)」

Chapter 2

スレイヤーの眠り

Page 2-1

膝をかかえ、うずくまるスレイヤーのもとに
魚と貝を抱えたあざらしがやってくる。 「さあ、貝を焼いて魚をフライにするキュ。
捕れたてはめちゃ美味だキュ~」
「・・・・・・」
スレイヤーは返事をしない。
あざらしは料理が下手だった。
魚フライと貝のホイル焼きが
できあがるころには日が暮れていた。

Page 2-2

無言のまま、 気まずい夕食を終えると、
スレイヤーはじっと、焚き火を見つめた。
・・・・・ 家族を焼いた火も、同じ色をしていた。
「私は・・・・・・ 神獣を殺すため、
天使になったんです」
スレイヤーの脳裏に、 家族を、故郷を失った
あの日の記憶が蘇った。
何もできなかった自分。
街を焼く神獣の炎。
その熱を、今でもはっきりと思い出せる。

Page 2-3

--こんなことをしてる場合じゃないのに。 スレイヤーは、唇を噛み あざらしをにらみつける。
そんな彼女にあざらしは
穏やかな声で語りかけた。
「騙してでも、 スレイヤーの心と身体を
いたわりたいと思ったんだキュ」
あざらしの言葉に、 怒りはわかない。
それでも言葉があふれてくる。
「・・・・・・ 楽しんでなどいられません。
死んでいった者たちのために、
戦い続けなければならないんです。
そうでなければ、 皆の魂が浮かばれない」

Page 2-4

「自分をすり減らし、戦い続けて、
その先に何が残る?」
「それは・・・・・・」
言葉が出ない。 唇がわななき吐息がもれた。
その先なんて考えたこともなかった
いや、考える余裕がなかった。
頭がずきりと痛む。
身体が重い。
それ以上に、心が・・・・・・ 重い。

Page 2-5

「今のスレイヤーは身も心も限界
気力だけで神獣と戦えると思うか?
戦えば、待つのは破滅だけだ」
スレイヤーの視界が揺れた。
世界が歪む。
あざらしの言葉は正論だ。
それでも一
(復讐が――神獣を殺し続けることが
私の人生の意味だから······)
スレイヤーが立ち上がろうとした瞬間、 足下が崩れるような感覚があった。 夕空が眩しく映ったのを最後に、
スレイヤーの意識は暗闇へと沈んでいった。

Page 2-6

柔らかな手が、髪に触れるのを感じた。
その感触に、 スレイヤーは目を閉じたまま、 穏やかな笑みを浮かべた。
••••••母さん?
母はよく、こうして髪をなでてくれた。
熱が出たときも、怖い夢を見たときも。 母の手は、いつもそばにあった。

Page 2-7

やさしいぬくもり。 なつかしい気持ちに、
心が軽くなっていく。
波の音が近くでささやいていた。
とても静かだった。
スレイヤーは久しぶりに
ぐっすりと眠った。

Chapter 3

スレイヤーの言葉

Page 3-1

朝、 潮風に吹かれながら目を覚ます。
スレイヤーはあざらしのお腹を枕にして
寝ていた。
「よく眠れたかキュ?」
あざらしの声は穏やかだった。
スレイヤーは何も言えず、
こくりとうなずいた。
あざらしの言っていることは分かる。
スレイヤーを心配してくれていることも。
痛いほど伝わってくる。
それでも一

Page 3-2

「私は、 神獣を倒すため、復讐のため、
歩き続けてきたんです······。
······ここで足を止めたら、
私が私でなくなってしまう・・・・・・」
「足を止める必要はないキュ。
だが、 自分の幸せを捧げ、
人生の楽しみをあきらめる必要もない」
あざらしはスレイヤーを見据える。
「焼き尽くされた過去があったとしても、 心を灰にしたら、もったいないだろう? 自分自身からも、自由になれ、スレイヤー」

Page 3-3

「自分自身から、 自由に······ ?」
「そうだ」
その言葉は遠い昔、
あざらしが大切な人からもらった言葉だ。 スレイヤーと同じ名を持つ、 神殺しの騎士
「自由になって、スィちゃん」 その声が、 吐息が今も耳に残っている。
だが、 あざらし自身はその言葉通りに
生きることはできなかった。
過去に囚われ、 自棄になり、
何もかも捨て、ただのあざらしとなった。

Page 3-4

スレイヤーには同じ轍を踏んでほしくない。
「できるでしょうか。 私に
スレイヤーがつぶやく。
「できるさ。 私がついているのだから」 私は、 スレイヤーをひとりにしない。
あざらしは、不意に顔を上げて
にやりと笑った。
「それに、 私だけじゃない。 見てみろキュ」
「え?」
海の向こうから近づいてくる艦
ブラスフェミィの姿があった。

Page 3-5

「おーい! 遊ぼうぜー!」
波打ち際で手を振る仲間たちの姿があった。
艦の天使たちが、
浮き輪やビーチボールを手に、
はしゃぎながらスレイヤーたちのいる
ピーチへ飛んでくる。

Page 3-6

「思いっきり楽しもうキュ!」
「はい!」
スレイヤーが、久しぶりの笑顔を見せた。

Page 3-7

スレイヤーは、
生まれ変わったような気分だった。
仲間たちと一緒なら、
まだ心の奥底に、 人生を楽しむことへの
罪悪感は残っている。
自分をしばっていた復讐の呪いから、 自由になれるかもしれない。
でも共に戦う仲間たちがいる。
神獣を倒すという同じ意志を持った仲間が。
いつか、 神獣を殲滅したその先に 続くような、 楽しい時間を
これからは作っていこう。

Page 3-8

仲間たちとはしゃぐスレイヤーを
見つめながら、
あざらしはピーチチェアに寝そべる。
あざらしは覚えている。
遠い昔。 自分が痩せ細った 小さな娘だったころの事を。
神獣殺しの騎士が、 共に旅をしてくれたこと。
彼女が優しく髪をなでてくれたこと。
目尻に繋いものがあふれる。

Page 3-9

ズゴッ!
トロピカルドリンクを吸いこむと
あざらしは海へダイブ!
あざらしは海を駆け回り、 天使たちの
バナナボートをゆらしてまわる。
「あざらしさん! 一緒に泳ぎましょう!」
スレイヤーの笑顔にこたえて、
あざらしはキュキュー!と鳴いた。

Fin.
