Chapter 1

祈り届かず

Page 1-1

「ママ! パパ!」
モルトラは絶叫した。
路地裏の石畳に、両親の血が広がっていく。
強盗の足音が遠ざかっていった。
あたりには、聴診器、 カルテ、 薬
診療カバンの中身が散らばっている。
パパは商売道具のカバンを
死ぬまで手放さなかった。
そのせいで強盗ともみ合いになって刺され一
助けに入ったママも殺されてしまった。

Page 1-2

「誰か 誰か助けて!」
血が流れ続けて止まらない。
このままじゃママもパパも死んじゃう。
集まってきた野次馬は、遠巻きに
眺めるだけで誰も助けてくれない。
モルトラが握る両親の手が、 どんどん冷たくなっていく。

Page 1-3

「女神様お願い。 助けてください・・・・・・」
掠れた声で祈る。
「女神様は必ず、私たちを助けてくれる
ママはいつもそう言っていた。
それなのに一
両親は死んだ。

Page 1-4

路地裏の片隅に小さな花束を置くと、 モルトラは息を吐き、天を仰いだ。 路地裏から見上げた青空は狭い。
—5年か」
両親の魂は、まだこの路地裏に
留まっている気がする。

Page 1-5

あの目、誰も両親を助けてくれなかった。
――それなのに、
父は医者として、多くの患者を救った。誰もふたりを救ってくれなかった。
母は、毎日女神様に祈り、
貧しい者に多額の寄付をしていた。
ぎり、と奥歯をかみしめる。

Page 1-6

やがて、ひとりの男が近づいてきた。
目深に帽子をかぶった男は、
黙って汚い布袋を差し出す。
モルトラも無言で
カネの入った紙袋を差し出し、
布袋と交換した。
男が姿を消すと
モルトラは布袋の中身を取り出した。
虹色に輝く林檎。
ーグレゴールの林檎だ。

Page 1-7

この林檎を口にしたものは、天使となる。 運が悪ければ死ぬが、運良く天使になれば、
神獣に立ち向かえるほどの
他人も、女神も、両親を救わなかった。 悪党は今ものうのうと生きている。
誰もモルトラを救ってくれない。
ならば
力が手に入るのだという。
モルトラ自身で、力を手にするしかない。

Page 1-8

誰にも頼らず、ひとりで悪党を倒す。
両親を見捨てた人々を、
街を滅ぼす
天使になれば、 それができる。
ちゅうちょ
モルトラは躊躇なく、 林檎をかじった。

Chapter 2

復讐のため

Page 2-1

[ページ種別：青]
剣と大鎌がぶつかり、重い音を立てた。
魔王城の庭園。
黒騎士が相手にするのは魔王そのひとだ。
「黒騎士よ。 なぜそこまで抗うのだ?
主君も国も、とうに失ったというのに」 息ひとつ乱さず、 魔王が言う。
「黙れ、 魔王!」
黒騎士は声を絞り出した。
その身体は限界に近い。

Page 2-2

[ページ種別：青]
何合目かの打ち合いの後、
一際大きな音を立て、
黒騎士の剣が弾き飛ばされた。
魔王は大鎌を黒騎士の首へつきつける。
[......]
黒騎士は、己の技量が魔王に及ばぬことを
既に悟っていた。
黒騎士は命乞いをしない。
復讐を遂げられないのであれば、
生きていても仕方がない。

Page 2-3

[ページ種別：青]
魔王は黒騎士の瞳をしばしみつめ。
武器を降ろした。
「気に入った。 私に仕えよ」
「魔王様はお優しいですなあ」
戦いを静観していた
赤いローブの魔術師が進み出た。
「忠義に狂った犬（ヒト）を城にいれれば、
寝首をかかれますぞ」
魔術師の言葉を、 魔王は鼻で笑った。
この程度の者に寝首をかかれるなら、
私もそれまでだ」

Page 2-4

[ページ種別：青]
かくして、黒騎士は魔王の配下となった。
ヒトからは裏切り者と呼ばれ、
魔族からも白い目を向けられる。
誰も黒騎士を助ける者はいない。
それでも黒騎士は、
かつての主君キベーレ女王に従ったように、
魔王のあらゆる命令に従った。
無論、黒騎士は
心まで屈したわけではない。 魔王と側近たちの信頼を得て、
油断を誘うためだ。
黒騎士は復讐のため、
虎視眈々と機会を狙い続けた。

Page 2-5

[ページ種別：青]
その日。戦場は、混乱を極めていた。 魔王は前線に立ち、自ら指揮をとる。
あちこちから届く報告と伝令の対応中、 魔王は黒騎士に背中を向けた。
好機!
黒騎士は、剣の柄に手を掛ける。

Page 2-6

[ページ種別：青]
だが、 黒騎士は剣を抜けなかった。
否、抜かなかった。
ここで魔王を討てば、明日の戦に敗北する。
そうなれば、多くの血が流れる。 これ以上の犠牲を、黒騎士は望まない
だから今は、あえて剣を抜かない。 きっと、我が主君も認めてくださる。
黒騎士は自分をそう納得させた。

Chapter 3

復讐の先へ

Page 3-1

[ページ種別：青]
魔王が消えた。
謀反により、 魔術師アルブレヒトが
王座を簒奪したのだ。
魔王は死んだとも、海の藻屑となったとも
伝えられた。
「魔王を倒すのは、 私だったはずなのに...」
胸に湧き上がる激情に、 黒騎士は
打ちのめされた。
それは怒りではなく、悲しみだった

Page 3-2

[ページ種別：青]
なぜだ 魔王は主君の仇だ。
アルブレヒトに先を越され、
悔しいというなら分かる。
悲しみから、気をそらそうとしても、
主君を失ったとき以上に深い悲しみが、
黒騎士の心をわしづかみにする。
だが、 なぜ私は魔王を失い、
これほどの喪失感を味わうのだ?
黒騎士は魔王に心惹かれていた。

Page 3-3

[ページ種別：青]
あの日、戦場で背を向けた魔王に、
剣を抜かなかったときから、
幾度となく王を討つ機会はあった。
だが、それを認めてしまえば、
にも関わらず、 黒騎士はそうしなかった。
理由はいくらでもある。
復讐を理由に生きてきた自分の在り方を
否定することになる。
だが真意は
王を殺したくなかったのだ。

Page 3-4

[ページ種別：青]
自分の気持ちを潔く認めていれば、
もっと魔王の力になれたかもしれない。
失うことはなかったかもしれない。
黒騎士は仕えるべき主君を、 二度も失った。
一度目は実力不足で。
そして二度目は、己の優柔不断さで。

Page 3-5

[ページ種別：青]
「スィ様・・・・・・」
海に西日が反射してきらめく。
その光が妙に眩しく、 黒騎士は目を閉じた。

Page 3-6

痛む目を開けると、
薄汚い路地裏と、狭い青空が
視界に飛び込んできた。
手に持っていたはずの林檎がない。
どこへ行ったのかと
手や足元を見回すと一
「翼か......」
背中に、 天使の翼が生えていた。

Page 3-7

モルトラは天使になっていた。
目を開ける前とは体の軽さも、 着ている服も、 装備すらも違う。 そして一
胸に、深い悲しみがあった。
魔王を失った、あの騎士の嘆きが。
憎しみで自らを奮い立たせていた彼女が、
その対象を失って初めて向き合った
素直な気持ち。

Page 3-8

ふと。
林檎をかじる前まで抱いていた憎しみが、
揺らいだような気がした。
私はこの力を使って、
きっと今の私なら、 それができる。
だが―
両親を、私を傷つけた人々や街を、 滅ぼしたいと思っていた。
これまでの私を否定しないために、
私はこの力を使おうとしているのでは?
そんな疑問が湧き上がってくる。

Page 3-9

私はどうしたらいい?
もしあの騎士に尋ねることができたら、
何と答えるだろう。
行動を起こす前に、 後悔する前に、
まだできることがある。
自分の素直な気持ちに、向き合うこと
黒騎士は空に向かって羽を広げた。 もう狭くはない。高く広い空へ。
Fin.
