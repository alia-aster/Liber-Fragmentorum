Chapter 1

きっとお姫様

Page 1-1

今日も眩しいスポットライトが
檻の中のあーしを照らす。
檻の鉄格子をつかんでガタガタ揺らせば、 子供たちが 「ひっ」 と息を呑んだ。
「さあさあ、ご覧あれ!
狼に育てられた、恐ろしい狼少女!」 座長の大仰なあおりに拍手が重なる。
「ガウゥゥゥ、 ガァウッ!!」
うなって吠えて、髪を振り乱し、 宙返りやアクロバットを見せれば、 子供は泣き叫び、大人は拍手喝采!

Page 1-2

あーしはシド。
狼に育てられた狼少女ってのが、 あーしのイケてる売り文句だ。
あーしが旅芸人の一座に拾われたのは、 ちっちぇー赤ん坊の頃だった。
周りに可愛がられてすくすく育ち、 今じゃ立派な旅芸人の一員だ。
歌も踊りもイマイチだったけど、
犬の真似だけは得意だった。
そんで、座長があーしを“狼少女”って
ことにしたら、これが大当たり!
狼に育てられたどころか、 本当はただの捨て子だけどな。
でも……あーしは信じてるんだ。
誰にも言ったことはないけど、 絶対そうに違いないって信じてる。 あーしはどこかの国のお姫様だって。

Page 1-3

“誘拐されたか、何かの手違いで、
ここにいるだけ。
いやマジでそれしか考えられないっしょ。
だって、あーし..
めちゃくちゃカワイイもん
おめめぱっちり、まつげはくるりん。 今日もテントで鏡を見ながら、
つやつやお肌の手入れをして星に願う。
いつか、本当の両親(王様か女王様) が あーしを見つけてくれて、一緒にお城で
贅沢三昧の暮らしができますよーに!

Page 1-4

んで、あーしたちが、でかい街の広場で
芸を見せることになった時のこと。
結構実入りがいい仕事らしくてさ。 座長も仲間たちも大張り切り!
陰気な占い師以外はみんなご機嫌だ。 もちろん、 あーしい嬉しかった。
だって、だってさ。
この街にしばらく滞在するんでしょ?
だったら…… あーしの夢の第一歩が
叶うかもしれないじゃん!

Page 1-5

「ねね、 座長、 あーし、
学校ってとこに行ってみたい!」 あーしは前のめりで座長におねだりした。
学校ってとこには前からキョーミがあった。
学があるってなんかかっこいーし。 主様があーしを見つけてくれたとき 字も書けないんじゃ恥ずかしいからな!

Page 1-6

機嫌がよかった座長は、
「いいんじゃないか?
どうせなら立派な学生さんになれや!」
と、すんなりOKしてくれた。
思えば、これが間違いの始まりだった

Chapter 2

狼少女の群れ

Page 2-1

「お前、 狼少女だろ」
登校初日、ある男の子がそう言って
あーしにびしっと人差し指を突きつけた。
どうやらテントに芸を見に来てくれたらしい。 嬉しかった。 友達ができるかもって思った。 だから隠さず教えてあげたんだ。
あーしは今、 狼少女をやってるけど……
本当はお姫様なんだって。

Page 2-2

すると、 男の子だけでなく
その周りにいた子たちまでも、
あーしを指差して一斉に笑った。
「お前はやっぱり、狼少女だ!」
くすくすくすくす。
あーしは彼らの笑い声を黙って聞いていた。
そんなことより、 アルファベットを 覚えることの方が大事だったから。
学校には3日通った。
さざ波のような笑い声があーしを取り巻く。
狼少女―それは嘘つきって意味らしい。

Page 2-3

あーしはアルファベットを覚えると、
昼メシの時間、あーしのことを狼少女って 呼んだヤツをひとり残らずタコ殴りにして、 メシを全部奪って貪り食った。
食えない分は窓から捨てた。
動物をしつけるときと同じだ。
どっちが強いのか、小さい頃に徹底的に
教え込めば、二度と逆らわなくなる。
これが最初の間違いだった。

Page 2-4

あーしは、学校を追い出されちまった。
でも、他のやり方なんて
知らなかったんだよ。
あーしは途方に暮れた。
座長や仲間たちに、
学校をクビになったなんて言えない。

Page 2-5

あーしは毎朝ウキウキで
学校に行くフリをして、
街のはずれで川を眺めて過ごしていた。
これが、次の間違いだった。
空をつんざく咆哮が、 大空に轟いた。 それはあーしのうなり声なんかより、 ずっとずっと恐ろしく重厚だった。
見つめていた川が流れてきた血に染まる。
神獣が街を襲いに来たんだ。
あたしは走った。 仲間たちのところ

Page 2-6

あーしが駆けつけた時には、
一座のテントはめちゃくちゃになっていた。 そっから、 家族みたいだった仲間は、
みんな散り散りになっちまった。
あーしは、ひとりぼっちになってしまった。 焼け落ちた廃墟をさまよう。
足は疲れて棒になり、空腹でお腹が痛い。
あーしは間違いばっかりだ。
でも、何が悪かったのか分からない。 これからどうすればいいかも……
何か、食べられるものを探していると、 瓦礫の中に、見たこともないようなものが
一杯落ちているのを見つけた。

Page 2-7

そーいや、 神獣がたまに、 何か高価なブツを
落としていくって話を聞いたことがある。
今はカネになるものより
食べ物があった!
かすんだ視界の先に虹色の林檎を見つけた。
いかにも体に悪そうな色だけど、
今さらどうなっても構わない。
あーしはその林檎を拾って食った。

Page 2-8

[ページ種別：青]
目を覚ますと、暗い洞窟の中だった。
ろうそくの明かりに照らされて、 大勢の
人影が壁に映って揺れている。
狭い空間に、言い争う声が響いていた。
「戦況は？ 分からないの？」
「どうすれば私たちは助かるの!?」
目の前には大勢の少女たちがいる。
彼女たちを見て、あーしは目を疑った。

Page 2-9

[ページ種別：青]
少女たちの頭には獣の耳が生えている。
それは彼女たちの感情を表すかのように、
ぴょこぴょこと動いている。
マジの狼少女じゃん。
なんかモフモフしてて超かわいい。
・・・・・ヤバ、マジかわいいんだけど!
「だから、ヒトにつくべきだって!」 「でもカゲとまともに戦えるの!?」
ワンワンキャンキャン、
少女たちは何かモメている。

Page 2-10

[ページ種別：青]
「ねえ、 族長に決めてもらおうよ!」
ひとりが焦れたようにそう言うと、
全員があーしに注目した。
族長って? なになに?
あーしのこと? どゆこと??
何を決めればいいわけ?
「えーっと、もっかい言って?」

Page 2-11

[ページ種別：青]
「仕方ないですねマイロード。 もう一度最初からおさらいしますよ?」
あーしに注目を集めさせたひとりが
こほん、と咳ばらいをして話し始めた。
一この世界では、 ヒトとカゲの戦争が続いている。 ヒトでもカゲでもない我々人狼は、
どちらかにつかなければ、
両方から滅ぼされる運命にある。
軽くまとめるとそーいうことだった。
ヒトだとかカゲだとか人狼だとか。 あーしにはよく分かんないけど、 そんなに難しい話じゃない気がした。
「そんなのらくしょーだよ。
強い方につけばいーだけじゃん!」 あーしはばちっとウインクして拳を上げた。

Page 2-12

[ページ種別：青]
「やっぱそうですよね! さすが族長!
「族長が言うなら間違いないです!」
狼少女たちは霧が晴れたように笑う。
「強い方について、
弱いヤツらはタコ殴りだ! 戦争だー!」
とんとん拍子に話が進み、
狼少女たちが「ワオン!」と頷く。
盛り上がってるところで、急に頭が
冷えてきた。
・・・・あれ?
ホントにこれでいいのか?

Chapter 3

きっと何者にでも

Page 3-1

[ページ種別：青]
近頃のあーしは、 間違えてばかりだ。
きちんと考えなきゃ駄目だ。
ホントにいいのか? だって戦争だよ?
カシコイあーしは考えた。
第一の間違いは、 気に食わないヤツを
全員ボコって、 敵を作ったこと。 動物と同じやり方じゃ、人は動かない。
次の間違いは、
座長やみんなに何も言わなかったこと。 言うタイミングを逃したせいで、
二度と会えなくなってしまった。

[ページ種別：青]
てことで、あーしは狼少女たちに言った。
「待て待て。 ヒトとカゲの戦争、
強い方につくって言ったけど、今のナシ」
ハテナ?って顔をした狼少女たちが
あーしに注目する。
「敵は作らねー。 どっちとも仲良くする。
あーしらは、ヒトでもオオカミでも、
ないからな。 両方の間に立てるっしょ。 そんで仲直りさせるんだよ」
そもそもヒトとカゲの争いなんか
関係ねーし。 巻き込まれたくねーからな。

[ページ種別：青]
「マジすか」
「その発想はなかったっす...・・・」
と、狼少女たちは感激している。
「まあ、ボコってる時はよくても、
だいたいしっぺ返しが来るもんだしな」 あーしは実感をこめて彼女たちに語った。
「でも、できるんすかね仲直りなんて」
不安そうに視線を落とす狼少女に、
あーしはドンと胸を張ってやった。
「できるかじゃなくて、 やるんだよ」
あーしの言葉に、おお!と狼少女たちが
盛り上がる。

[ページ種別：青]
「んじゃ、 まずはヒトとカゲの両方に
手紙を送ろーぜ。
直に話つけにいくと、ヒトとカゲの
どっちと先に話したとかでモメるからな」
あたしの提案に、 狼少女たちは
「名案!」 「それだー!」と浮き立つ。
しかし不安げなひとりは、
頭の獣耳をぺしょりと下げたままだった。
「でも族長、 あたしらは
カゲの言葉が分かりません。
あろふぁぺっとって言うらしいですけど......」

Page 3-5

[ページ種別：青]
アルファベット? あーしはここで会心のドヤ顔をした。
「それくらい、書けますけど?」
狼少女たちは目をまんまるに見開いて、 あーしに期待と憧れの眼差しを向けた。
クラスメイトはクソだったけど、やっぱ学校行っててよかったじゃん!

Page 3-6

[ページ種別：青]
「それなら、大丈夫ですね!!」
不安そうにしていたひとりも やっと明るい笑顔を見せてくれた。
他の狼少女たちもぴょんぴょん跳ねながら、
「これで平和になる」と喜ぶ。
その素直な笑顔に、こっちも気分がアガる。
……あーし、 こいつらのこと超好き

Page 3-7

ぴちゃんと水粒が落ちる音で目が覚めた。
いつの間にか雨が降っていたらしい。
崩れた廃墟の天井からは、
雨上がりの澄んだ空が垣間見える。
なんかよくわかんねー夢を見た。 モフモフ耳の狼少女に囲まれて 族長だなんだと持ち上げられて……。
「っとに、なんだったんだろうなー」
あーしはうーんと腕を伸ばす。
立ち上がると、 水たまりにつま先が浸った。
「ん?」
何気なく水たまりを見下ろし、目を見張る。 そこにはさっきの狼少女たちと同じ姿をした、 いつも以上にカワイイあーしが映っていた。

Page 3-8

「えっ?え? 超カワイイ!」
あーしが踊るように跳ねると、
頭の上の獣耳も同じようにぴょこんと弾む。
体が軽い。
いつの間にか背中に生えた翼は力強く、
自然と顔も気分も上を向く。
まるで 生まれ変わったかのようだった。

Page 3-9

あーしは久しぷりに、空を仰いだ。
あーしのそもそもの間違い。 それは、王様だか何だかが
「ま、いつまでもくよくよしててもあーしを見つけてくれるのを待ってたこと。
しかたないっしょ!」
待っててもいいことなんてねーし、
こっちから自分の足で歩いていかねーと。

あーしは自力でお姫様になるからな。
・・いや、 族長の方がいいか?」
あーしは耳をぴょこんと立てて、
翼を広げて、 廃墟から飛び立った。
