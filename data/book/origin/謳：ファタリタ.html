Chapter 1

踊り子の

Page 1-1

「帝国による
「不滅の炎」 の独占を許すな！」
エネルギー支配から、世界を解放せよ！」 口角泡を飛ばし、 男が熱弁を振るう。
「わぁ……」
店の片隅で圧倒される。 アルフライラには、
男の言っていることが半分も分からない。
分かるのは、彼が反皇帝派の
レジスタンスであることと、 ここが誰もそんな熱弁に関心がない 踊り子小屋であるということだけ。

Page 1-2

男が語る「不滅の炎」 とは、
帝国の中心で燃え続ける大きな大きな それはもうとーっても大きな炎だ。
アルフライラは
漠然とすごいなーと思っている。 毎日元気に燃えてますねーと。 でも、それだけ。
なにせ、自分のことで手一杯なので。
世界に目を向ける暇があるのなら、
振り付けのひとつも覚えていたいのだ。

Page 1-3

トントントン、トトトン。
太鼓の軽快な音が鳴り始めれば、
演説中だろうと構わずに
男が舞台から引きずり下ろされる。
めくるめく舞台の幕開けだ。
踊り子たちがしゃらしゃら飾りを鳴らし、
ふわふわ衣装を翻して舞い踊る。
「わあ……」
踊り子たちに、 アルフライラはうっとりと
ため息を漏らした。

Page 1-4

アルフライラは捨て子だ。
双子の姉とぴったり寄り添って道ばたで
飢えていたところを、
踊り子小屋のおかみに拾われた。
名前のなかった双子の姉妹に
ワライラ、アルフライラと
名前をくれたのもおかみさんだった。
残念なことに、姉のワライラは
拾われてからしばらくして、
お空の星になってしまったけれど。

Page 1-5

道ばたの捨て子も、 踊り子小屋の踊り子も、 まともな教育とは無縁だ。
けれど、踊り子たちはアルフライラを 可愛がって真剣に踊りを教えてくれた。
踊りがまともに上達しないのは、
アルフライラの覚えが悪いからだ。
得意なことは失敗すること。 家事もお手伝いも踊りも、 なにひとつ誇れることがない。

Page 1-6

「お荷物のアルフライラ」 意地悪なお客が
言った。 本当にその通り。
それでも、おかみさんや
踊り子たちに愛されて、
アルフライラは健やかに成長していった。
バカだけど、グズだけど。
それでもみんなの役に立ちたいのです。
いつかは私もあのステージに立ちます！ 夢はでっかく、希望は高く。
けれど、現実は厳しくて……。

Page 1-7

踊り子小屋が店を閉めるのは夜明け前。
夢が終わる時間だ。
華やかな舞台の裏で、仕事の手伝いや
閉店後にまとめたゴミを出し、
白んできた空に目を細めるそのときだ。
踊りの練習に精を出していたアルフライラは
クタクタだった。
「やあ、お嬢さん」
「はいです？」
男の声に、アルフライラは振り返った。

Page 1-8

アルフライラに声を掛けてきたのは、
舞台で熱弁を振るっていた
レジスタンスの男だった。
きょとんと首をかしげるアルフライラに、
男はにこやかに近づいてくる。
「さっきはありがとう。
僕の話を真剣に聞いてくれたのは
君だけだった」

Page 1-9

「それは……誤解と思いますよ」 だって、半分も理解できずに
ただ、聞いてただけなのだから。
男は、アルフライラの言葉を意に介さず
饒舌（じょうぜつ）に語りかける。
難しい言葉ばかりで、 アルフライラの
疲れ切った頭はじんじんと痺れた。
「だから、一緒に世界を変えないか？」

Page 1-10

何が 「だから」 なのか、これっぽっちも
分からなかった。
けれど、この人が自分を
必要としてくれていることは分かった。
だから――
だから、 アルフライラは愚かにも 男の手を取ってしまったのだ。

Chapter 2

炎の中で踊れやれ

Page 2-1

「ハア、ハア……ヒイ、ん、はあ……」
ボロボロと涙を流しながら、
アルフライラは巨大な螺旋（らせん）を描く
鉄骨を駆け上がる。
螺旋の内側から吹き付ける熱風が
頬を舐めて、流れた涙を蒸発させた。
なんで、なんでと混乱しながら、
アルフライラは少し前のことを
思い出していた。

Page 2-2

「これで、すべてが救われる」
レジスタンスの男がアルフライラに
重いベストを着せて言った。
「不滅の炎を破壊すれば世界は変わる。 帝国の圧政は終わり、 人類が自らの力で
生きる時代が訪れる」
男は何やら立派なことを言ってるようだが、 アルフライラの心には響かなかった。
不安な顔をするアルフライラに、 男は穏やかに笑って見せた。 「つまり、歴史に残るんだ。
世界を変えた殉教者として」

Page 2-3

「何言ってますか？」
アルフライラがおずおずと尋ねると、
男はアルフライラの肩をつかんだ。
「君が着ているベストには、爆薬が 仕込んである。 私の計算では、不滅の炎を
消し飛ばすだけの威力があるはずだ」
着せられたベストがずしりと重い。 慌てて脱ごうとするが、 身体に固定され、 脱ぐことができない。
騙されたのだ。 アルフライラは理解した。 人間爆弾として利用され、殺されるのだと。

Page 2-4

「いやです！」
アルフライラは悲鳴を上げて、 男を突き飛ばして逃げ出した。
逃げ場は限られていた。
上へと続く螺旋の鉄骨に飛びつくと、
裸足で上り始めた。
熱い。 炎で熱せられた鉄骨が、
アルフライラの手を、足裏を焼いた。
それでも、逃げなければ!
爆弾の外し方も、いつ爆発するのかも 分からない。 男もアルフライラを
追ってきた。 恐怖に突き動かされ、
アルフライラはひたすらに上を目指した。

Page 2-5

「う、うう・・・・・・」
言われなくても分かっている。
本当に、なんてバカなんだろう。
難しいことは何も分からなかった。
頂上にたどり着いた頃には、
足裏は焼けただれていた。 血の足跡が鉄骨に焦げ付いている。
「バカなヤツ。 お前を選んで正解だったよ」
逃げ場を失ったアルフライラを男が嘲った。
分からなかったくせに、誰かの、何かの 役に立ちたくて、 理解しないまま言うことを
聞いてしまった。
「さあ、不滅を滅ぼそう」
男が陶酔した笑顔でアルフライラを
突き飛ばす。

Page 2-6

その手をアルフライラはとっさにつかんだ。 「バカだって、道連れくらいできます！」
不滅の炎の中へ、男もろとも落ちていく。

Page 2-7

ベストの爆薬が炸裂した。
閃光と爆風をまき散らしても、 男の上半身と アルフライラの右腕を吹き飛ばすだけの
威力しかなかった。
あああああああああああ 熱い熱い熱い熱い!
髪が燃え尽き、皮膚が焼けただれていく。
不滅の炎に触れた男の肉片が、爆弾の破片が それなのに、 アルフライラの意識は
はっきりとしていた。
焼かれ、煙のように燃え尽きる。

Page 2-8

喉が焼けた、肺が焼けた。
眼球が乾き上がって、脳がドロドロになる。
どれだけ苦痛が押し寄せても、
アルフライラは死ぬことができない。
痛い 熱い、苦しい、助けて!
たすけて
たすけて
殺して! 誰か 私を殺して!!
永遠に燃える炎の中では、永遠に身体を 焼かれ続けるしかないのだろうか。

Page 2-9

永遠に燃え続けるアルフライラは、 焼け落ちた眼で、 炎の中に浮かぶ
奇妙な物を見た。
不思議な色のあれは、林檎だ。
（ああ……そうだ。
おかみさんに拾われたばかりの頃、 お腹を空かせていた私と姉さんに――）
おかみさんが焼き林檎を食べさせてくれた。 その甘酸っぱい味が、どれほどおいしく、 どれほど嬉しかったか。

Page 2-10

身体は真っ黒に焦げて強ばっていたが、 心だけはみずみずしい記憶に満たされる。
たったひとりの家族との美しい思い出が、 苦しみを拭い去ってくれるようだ。
この愛おしい奇跡が、
私のさいごとなるのなら。
微笑んだアルフライラの元に、 そっと林檎が触れた。

Chapter 3

踊り子の目覚め

Page 3-1

[ページ種別：青]
「今年の生け贄はお前だ」
長老が重々しく告げる。
アルフライラは目を伏せた。

Page 3-2

[ページ種別：青]
ついに来たか、とも、
やっときたかとも思う。
アルフライラに家族はいなかった。 たったひとりの姉はもう亡くなった。
友人も、親しい人もいない。
未来も、希望もなかった。
「――分かりました。
みなさんのためならば」
アルフライラは淡々と頭を下げた。

Page 3-3

[ページ種別：青]
かつて黄金の国と呼ばれ栄華を極めた この国は、「怪物」によって滅んだ。
その怒りを静めるために、街を壁で囲った 城壁の街では、年に一度生け贄を
捧げる儀式を行っている。
アルフライラも遠からず
生け贄にされるだろうと思っていた。
それが、今年だったというだけだ。

Page 3-4

[ページ種別：青]
生け贄の丘と呼ばれる場所には
巨石で作られた祭壇がある。
アルフライラを祭壇に縛り付けた男は、
逃げるように丘から去って行った。
(こんなことしなくても
別に逃げたりしないのに……）
「怪物」のことも、死ぬことも、
アルフライラはちっとも恐ろしくなかった。
（早く終わって……）
アルフライラの願いに応えるように、
「怪物」 が姿を現した。

Page 3-5

[ページ種別：青]
無数の触手に包まれ、他のどんな動物にも 似ていない醜悪な姿に、 アルフライラは
恐怖した。大きな身体を揺すり 怪物が
近づいてくる。
「ああ……」
アルフライラは身を固くした。
だが「怪物」は、 生け贄には
目もくれなかった。
怪物は城壁を破壊し、 街の中へと向かった
人々の悲鳴が響き渡り、血の臭いが漂う。

Page 3-6

[ページ種別：青]
やがて、怪物が戻ってきた。
逃げ惑う人々を殺し尽くしたのだろう
怪物は来たときと同じように、
アルフライラを一顧だにせず。
来た方向へと去って行った。
アルフライラは遠ざかる 「怪物」 の背中を
呆然と見つめながら、ぽつりと呟いた。

Page 3-7

「――どうして？」
激しく渦巻く炎に、痛みと絶望の記憶が
押し寄せて、喉の奥がひくついた。
目覚めたアルフライラの目の前には、
炎の海が広がっていた。
「……?!」
炎に焼かれながら夢を見ていたのだ。
アルフライラはパチパチと瞬きをして
両手を目の前に突き出した。

Page 3-8

熱くない。 燃えてない。
真っ黒に焦げていたはずの身体は、 火傷のあとひとつ残っていない。
それに、服装も替わっていた。 まるで炎をまとうような綺麗な衣装。
くるりと回った瞬間、 アルフライラは
空へと飛び上がっていた。
不滅の炎を抜け出して、 高く、 高く。
「うひゃぁ!? 落ちます！」 咄嗟に身体に力を込めて羽ばたいた。 そう、背中に翼が生えていたのだ。

Page 3-9

「なんで？どうして？
どうなるんですか!?」 混乱するアルフライラの身体を
暖かな気配が優しく包んだ。
「……姉さん？」
もしかして、 姉のワライラが
助けてくれたのだろうか。
「姉さん、姉さん……怖かったよう……」
分からないけれど、きっとそう。
アルフライラは涙が溢れそうな目を
両手でぎゅっと押さえた。

Page 3-10

「不滅の炎」は爆発も悪意も知らぬように
変わらず燃え続けている。
あの男こそ、無駄死にだった。
（私に何ができますか……）
生き残ったことには、
きっと意味があるはずだ。
たとえ、単なる偶然なのだとしても、 この力は 「不滅の炎」 を壊すためじゃなく、 誰かを救うために使いたい。

Page 3-11

（――夢の中の生け贄さんは、
あの後どうなったですか）
みんなが怪物に殺されたあと、
祭壇に縛り付けられたまま残された生け贄は
どんな人生を送ったのだろう。
（きっと、私と同じように……） 生き延びた意味を
探しに行ったのかもしれない。
（そうだったらいいのになぁ……）
そう思いながら、
アルフライラは大空へと羽ばたいていった。
