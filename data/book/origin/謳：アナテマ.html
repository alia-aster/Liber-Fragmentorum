Chapter 1

下剋上ですわー!

Page 1-1

「ポメ！ ポメー！」
ポメ! 私のかわいいポメ!
もこもこの毛玉のような子犬が
いかにもな悪党の小脇に
抱えられ連れ去られていきます。
そのつぶらな瞳には涙が……。 血統書つきのポメはきっとどこかに
売られていくのでしょう……。

Page 1-2

ポメばかりではありません。
家も財産も押さえられ、
私はひとりぼっちです。
使用人たちも去っていきました。

Page 1-3

私は最強のお嬢様でした。
我が家は戦争成金と陰口を叩かれながらも 栄華を誇り、
それはもうスペシャルで ロイヤルな日々を過ごしておりました。
しかし、お父様がバナナの皮で 滑って転んで頭を打って死ぬと、
あっという間に没落してしまったのです。
何人めか忘れた若い後妻も財産をたっぷり
持って出ていきましたし、
ハゲタカどもが押し寄せて、
なんだかんだと財産を奪っていきました。

Page 1-4

財布の中身はスカンピン。
住む場所も食べるものもなくなりました。
およよのよ……これからどうやって暮らしていけばよいのでしょう!?
こうなったらイチ庶民として、
慎ましく生きていく

Page 1-5

なんてできませんわぁ
贅沢を知ってしまったら戻れませんもの。
こうなったら、私も ワルになりますわ。 どんな手を使ってでも。
のし上がってやりますの！ おほほのほ！

Page 1-6

まずはパワーが必要ですわ!
そう、私の命令を聞く兵隊が大勢いれば、
ハゲタカどもなんかに
と、いうわけで帝国軍に入隊しましたの。
突飛な発想、 急展開などとは
自由にさせなかったのに……。
生憎、お父様と違い私に商才はありません。
であれば! 物理的なパワーで テッペンを取ってみせますわ!
言わないでくださいまし。
私は本気も本気でございますわ

Page 1-7

軍は飯も寝床も無料だなんて助かりますわ。
ここで成り上がり、兵隊を大勢引き連れて もう一度、大金持ちになってみせますわよ!
そのためには、
どんな苦労でもしてみせますわ。
見てなさい!
私が、このツインドリルヘアーに相応しい
お嬢様に返り咲く様を!
おほほのほ!
おーっほっほっほのほ!

Chapter 2

地獄ですわー!

Page 2-1

ひー!もういやあっ!
軍隊は地獄ですわー!
毎日行進と穴掘りばっかり!
地べたを這いずり回って、 沢だらけ!
こんなの、私のようにエクセレントな
お嬢様がやることではありませんわ!
周りの庶民どもと育ちが違い過ぎて お話も通じませんし、 本当に嫌になります!
さっさと出世して、クソ教官どもを
アゴで使ってヒィヒィ言わせたいですわー!

Page 2-2

と思っていたら、
さっそくチャンス到来ですわ。
よくわかりませんが、スペシャルな存在――天使とやらの志願を募っていましたのよ！
なんでも天使とは、 美しくて、 空も飛べて 神獣とも戦える最強の存在らしいですわ。
こんなに私にふさわしいものはありまして？

Page 2-3

私、 速攻で志願しました。
兵隊なんかいなくても、
私が最強になればいいのですわー!
おーっほっほのほ!
誰にもできないことをやってのけるのが私!
同僚どもの憧れと羨望の視線が
心地いいですわ~!
というわけで、さっそく
林檎をかじることになりましたの

Page 2-4

「マジかよ……あいつ」
おっとー? 庶民どもが私の勇姿に
惚れ惚れしていますわね。
さて、ひとくちアーン……。
ーゴクリ。 バタン。
「失敗したら死ぬぞ」
……え？
それを早く言ってくださいまし!?

Page 2-5

[ページ種別：青]
「おほほのほ！ 聖騎士アナスタシアがやってきたからには、万事解決ですわ～！」
高飛車な名乗りが酒場に響き渡り、同時に
彼女がぶち破った扉の破片が飛び散る。
グラスが割れ、客同士の殴り合いで
ぐちゃぐちゃになった店内は、
ピタリと時が止まったように静まり返った。
「やばい」――客同士は、冷や汗を
流しながら無言で目配せをする。
とんでもなく面倒な女が来てしまった、と。

Page 2-6

[ページ種別：青]
アナスタシアが 「万事解決」 と言う通り
酒場の喧嘩は猫に水をぶっかけたように
収まってしまった。
「ほら、ご覧なさい。
水回りのトラブルと、 酒場のトラブルは
アナスタシアにお任せですわ」
むんっとアナスタシアは胸を張る。
異論を唱える者はいなかった。
怪力の彼女に逆らうと大変なことになる。
この間、喧嘩を止めようとした彼女に 店を破壊され、潰れた酒場もあったらしい。
「さて。トラブルは解決したことですし、
タダ飯を用意してくださいな？」 アナスタシアは全く悪びれず、
自慢の ツインドリルを揺らしテーブル席についた。

Page 2-7

[ページ種別：青]
「お前がトラブルメーカーなんだよ……」
客のひとりが拳を下ろしながら
疲弊したように呟く。
「あのぉ聖騎士様、ちょっといいですか……」 気弱そうな酒場の店主が怖々と切り出した。
「こんな噂を聞いたのですが……」
「素行不良で聖騎士を破門されたにも 関わらず、 聖騎士を名乗ってあちこちで
騒動を起こしている者がいるのだとか……」
「そそそ、そんな不届き者なヤツが
いるんですの!？」
途端にアナスタシアの視線が泳ぎまくる。

Page 2-8

[ページ種別：青]
店主と客が一斉に指差した先には、
酒場の壁に貼られた人相書きがあった。
「注意！ 元聖騎士、騙されるな！」
という文と共にアナスタシアそっくりな ツインドリルの似顔絵が描かれている

Page 2-9

[ページ種別：青]
「お、おほ……。
きっとその方にも、事情があるのですわ」
引きつった笑みを浮かべるアナスタシアに、 客のひとりがため息をついた。
「もし本物の聖騎士さまでしたら、
もっとやることがあるんじゃないすか？
神獣をどうにかするとか、
魔王を倒しにいくとか……」

Page 2-10

[ページ種別：青]
アナスタシアははっとしたように
立ち上がり、 剣の柄に手を添えた。
「そ、そうね！ ちょうど魔王を 倒しにいくところだったのよ!」
その高らかな宣言に、
客たちは顔を合わせて盛り上がる。
「本当か？ さすがは聖騎士さまだ！」
「アナスタシアさまが言うなら安心だな」

Page 2-11

[ページ種別：青]
期待の眼差しに押されるように、
アナスタシアはじりじりと後退した。
その背には 「注意!」 の
二文字がでかでかと踊っている。
「み、見ててくださいまし！ 魔王なんてちょちょいのちょいで ぶっ飛ばしてやりましてよ！
おーっほっほっほ! おーっほっほのほ!」

Chapter 3

最強ですわー!

Page 3-1

[ページ種別：青]
「こ、困りましたわー！」
酒場から転がるように逃げ出て、
アナスタシアは自身の両頬に手を当てた。
そのまま、 よよよ …… とへたり込む。
「魔族を率いる魔王を倒すなんて、
到底無理ですわよ……」

Page 3-2

[ページ種別：青]
そもそもアナスタシアは、
実力で聖騎士まで上り詰めたわけではない。 親のコネで末席にありついただけだ。
しかも度重なる戒律違反で破門されている。
破門は自分の良心に従った結果だ。
後悔はしていない。
だが聖騎士という身分で羨望の眼差しを
受ける快感を、忘れられずにいた。
汚名返上のために、
ひとりで聖騎士の活動をしていたが、
実力不足で大したことはできていない。

Page 3-3

[ページ種別：青]
「無理ですわよ。 私には……」
このまま逃げ出してしまおうか、と
甘い自分が顔を出す。
(でも…… それでいいのかしら)
脳裏によぎるのは、魔王と倒すと言った時の
みなの嬉しそうな顔。
アナスタシアは自分の頬を叩き、
すくっと力強く立ち上がった。
「ここはいっちょやってやりますわ！」
今度こそ、 汚名返上をするために。

Page 3-4

[ページ種別：青]
かくしてアナスタシアの 魔王退治の旅は始まった。
だが長くは続かなかった。
「魔王死す!」の報が国中に広まったのだ。
旅の途中でそれを知ったアナスタシアは、
間抜けな顔でその場に立ち尽くした。

Page 3-5

[ページ種別：青]
「そんな……この私がせっかく
やる気になったというのに!?
あんまりですわー!」
なんでも、魔王は腹心の部下である
魔術師アルブレヒトに
殺されたのだという。
魔術師アルブレヒト。
名前も初めて聞くようなヤツが、
自分の道を絶っただなんて信じられない。
アナスタシアの胸に、
怒りと悔しさが渦巻く。

Page 3-6

[ページ種別：青]
「アルブレヒトとやらのツラを拝まなければ、納得いきませんわ！」
アナスタシアは走り出した。
主のいなくなった魔王城へ、たったひとり、乗り込むために。

Page 3-7

「それー!いけー! アナスタシア!」
私は思わず勢いよく拳を上げました。
なかなか面白い女の夢を見ましたわ。 高潔な心や見た目はもちろん、
少々見栄っ張りなところや、 後先を考えないところも親近感が湧きます。
すると横にいた軍医が、 ぴくっとおばけでも
見たように肩を跳ねさせました。
「アナスタシア……？ 大丈夫ですか？」 「いいえ、ちっとも」
だって、夢はいいところで
終わってしまいましたもの。
きっとあの女なら、
悪の魔術師を倒したはずでしょう。
なのにその勇姿を見られなかったのは、
心残りでしかありません。

Page 3-8

「アナスタシアが目を覚ましたって？」
「まさかこんなヤツが天使になるとは……」
にわかに辺りが騒がしくなりました。
私が目覚めたと噂になっているようですわ。
「……ん？ 天使？」
そこでやっと気がつきました。
林檎をかじった私は気を失い、 そして――目覚めた今、天使になっていたのですわ!

Page 3-9

「まあ、当然のことですわね」
だって私ですもの。
これでやっと、最強になりましたわ！
天使になった選ばれし者は
天使部隊へ配属になるとのこと。
私は可憐な翼をばさりと広げ、 小汚え同僚どもにさよならを告げました。

Page 3-10

「天使部隊に行く前に
やることがありますわ！」
大空を飛びながら、
「最強になった私を見れば、
私は華麗なUターンを決めました。
「ポメを取り返しにいきますわよ！」 私は愛犬 ポメを探して飛び回りました。
ポメが売られた先は心当たりがあります。 山上のとある貴族の家に、 ポメはいました。
きっとポメもすぐに帰ってきてくれますわ」
淡い期待を胸に、
私は貴族の家の庭に降り立ちました。
ですが、 そこで私が見たものは

Page 3-11

貴族のお子様と一緒に元気に跳ね回る
ポメの姿。 ちぎれんばかりに尻尾を振り、 目もキラキラ。 毛艶もよくなってますわ！
「ポメ……私よりも懐いてる……」
はっきり言って、私といた時の
三万倍くらい幸せそうでした。

Page 3-12

衝動的に駆け出して、 ポメを抱え 連れ去ってやろうかと思いました。
ですがそれでは、私からポメを奪った
あのハゲタカ男と変わりません。 同じことをすれば、
高潔な私の心は、汚れてしまいます。

Page 3-13

「ポメ、どうかお達者で……」
私は涙と鼻水まみれになりながら、 そっとポメに背を向けました。
「私、成長しましたわ……」
胸の痛みはきっとその証拠。
ぐっと涙を呑み、 私は飛び立ちました。
ああ、ポメ。 そしてこれまでの日々よ。 さようなら。 さようなら!
私はこれから天使として、
テッペンを取りにいきますわ!!
Fin.
