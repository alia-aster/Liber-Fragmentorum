Chapter 1

憧れの章

Page 1-1

「すんげぇなぁ! クラリスちゃん、
まるで帝都の宮殿だぁ!」
屋敷の豪華な丁度においちは目を丸くした。
「宮殿はこんなものじゃないわ」
クラリスが目を細めて言う。 「ほんげ~。 そうなんだぁ」

Page 1-2

クラリスは政府高官のひとり娘で、
おいちの暮らす土地へ、 夏の間だけ
避暑に訪れていた。
「それに、こんな美味しいもん、 おいち食べたことねえ!」
田舎娘と、お嬢様。 正反対な育ちの
ふたりは出会ってすぐに、 姉妹のように仲良くなった。
口いっぱいに頬張るおいちを見つめて、
クラリスは微笑んだ。

Page 1-3

「おいちちゃんのおにぎりだって、 とっても美味しかったですよ」
クラリスの言葉に、 おいちは赤くなる。
「いや、いや、だって、
あんな不格好な握り飯・・・・・・
丸でも三角でもなくて、
具もなんも入ってなくて・・・・・・」
「おいちちゃんが作ってくれたから、
とっても美味しかったの!」

Page 1-4

はじめは緊張していたおいちだったが、
クラリスとおしゃべりしているうちに
いつもの笑顔を取り戻し、
モリモリと料理を平らげていく。
別荘の主人であるクラリスの父は、
目を細めてふたりの様子を眺めていたが、
ふと口を開くとおいちに語りかけた。
「おいちさん、 クラリスと
仲良くしてくれて感謝するよ。 こうして君に会えたのはきっと父上の・・・
ソウカク
惣角殿のお引き合わせに違いない」

Page 1-5

おいちはむせそうになった。 「おっとうじゃなくて父を、
知ってるだか······ ですか!?」 惣角とは、亡き父の名だった。
「惣角殿とは戦友だった」
クラリスの父は惣角がいかに勇敢だったか、 力尽きる最後の瞬間まで神獣と戦い、
いかに多くの人を救ったかを彼女に伝えた。
「おっとうが そんなに大勢の人を・・・・・・」
それは、初めて聞く父の逸話だった。
「おいちのおっとうは、 すげえ人だったん
だねぇ............... ちっとも知らなかっただ・・・・・・」 だねえ・・・
涙をこぼし、おいちはつぶやいた。

Page 1-6

「おいちも、おっとうのようになりてぇ。 神獣からみんなを守れるような人に・・・・・・」 クラリスの別荘を訪れたときから、
それがおいちの夢になった。
しかし、父のように神獣と戦うためには
まず帝国軍士官学校に入り、
軍人にならなければならない。
そう目標を定めたおいちは、 翌日から猛勉強を始めた。

Page 1-7

数年後、入学試験に合格した彼女は
意気揚々と帝都へ向かう。
それはもちろん、
彼女の努力の成果ではあったが、
クラリスの父による紹介が
後押しとなったこともまた事実ではあった。

Chapter 2

現実の章

Page 2-1

帝国軍士官学校への入学を
許されたおいちは、
亡き父のように立派な軍人になろうと、
懸命な努力を続けていた。
「クラリスちゃん・・・・・・
おいちは、もうくじけそうだよ・・・」 便せんを涙でぬらしながら、 おいちは
クラリスに手紙を書いた。
教官からはいつも叱られ、成績はどん底。 それは能力不足というよりも、
おいちの優しすぎる性格が原因だった。

Page 2-2

リアリズム
士官学校では徹底的に現実主義を
叩き込まれる。 命令とあらば、いくらでも
非情にならねばならない。
理屈では分かっても、おいらはどうしても 弱い人や困っている人の
味方になりたいのだ。
父、惣角ならば、この疑問に
どう答えてくれるのだろうか? おいちはずっと悩み続けていた。
それでも、くじけずに士官学校を 卒業できたのは、クラリスから届く 励ましの手紙のおかげだった。

Page 2-3

見習い士官として部隊に配属された
おいちに、出撃命令が下った。
初めての実戦である。 緊張しながら、 おいちは戦場へ向かう列車に揺られる。 列車の向かう先は、国境ではなく、 帝国の中心部だった。
囁かれる噂では、内乱が起こったらしい。
つまり、戦う相手は同じ帝国の人間なのだ。
おいちは動揺した。

Page 2-4

士官になされた説明では、
列車から降ろされ、 行軍が始まる。
反乱の首謀者はクラリスの父だと言う。
行く先は、おいちの知っている土地だった。 クラリスの父は、帝国の圧政に苦しむ人々を
何度も手紙の宛先に書いた。
クラリスの故郷だ。
救うため、自ら武器を取り反乱の先頭に 立ったのだと言う。 その娘も武装蜂起に
加わっているそうだ。

Page 2-5

「クラリスちゃんとは戦えねぇ・・・・・・」 クラリスの父親が反乱の首謀者だと 言うのなら、何か事情があるはずだ。
戦うべきでない相手とは戦えない。
攻撃の前に話をすることはできないのか。
自分が使者になれば対話の糸口は
つかめるかも知れない。 おいちは訴えた。
軍は情で動く組織ではない。 既に、反乱軍を鎮圧せよとの命令は
下されたのだ。

Page 2-6

おいちは命令不服従による抗命罪に
問われた。 戦地における抗命は重罪であり、
死刑もあり得る。
おいちは即座に身柄を拘束された。

Chapter 3

決断の章

Page 3-1

営倉代わりの倉庫に
監禁されたおいちは、
ひもじい思いをしながら、
軍法会議が開かれるのを待っていた。
おいらが軍人を志したのは父への憧れだ。 父のように、人を守る立派な人に
なりたかった。それだけなのに·····

Page 3-2

軍はクラリスとその父に、クラリス父娘が
守ろうとした人々に銃を向けている。
軍隊は国家を守り弱者を守る組織で あると同時に、権力者の道具なのだ。
憧れだけで突っ走り、 軍人は何をして、
何をさせられるのか、十分に考えなかった。
「おいちが弱かったせいだなぁ・ 見たくないもんと向き合うのが怖くて、
ずーっと目をそして・・・
こうなっちまっただ...」

Page 3-3

軍法会議の前夜。
おいちのもとに食事が届けられた。
「処刑前の最期のメシかりなあ・・・・・・」
皿の上には、丸とも三角ともつかない。 不格好な握り飯があった。 昔、おいちがクラリスに作ってあげた
握り飯を思い出す。
「なして、 こんな握り飯が?」
おいらは戸惑い そしてひとつの
可能性に思い当たった。
「クラリスちゃん・・・・・・!?」

Page 3-4

おいちは握り飯を頬張る。
その中に、妙な具が入っていた。 小さな紙片だ。
紙片には、おいらが閉じ込められている 倉庫からの脱出経路が記されていた。
「クラリスちゃん・・・・・・。 おいちを助けに
来てくれただか?
捕まったら、 自分が危ないのに・・・・・・?」
おいちはクラリスの思いに胸を打たれ、 涙をこぼしながら握り飯を飲み込んだ。 「クラリスちゃん。おいちは決めただ」

Page 3-5

翌朝。
おいちは逃げずに軍法会議の場に臨んだ。
「弱くて臆病なおいちだけど、
クラリスちゃんのために出来ることはある」
略式の軍法会議で、おいちの罪状が
並べ立てられる。 その場でも、おいちは
歩も退かず、反乱軍の正当性を主張した。
もちろん、それでどうにかなると
おいちは考えていない。
ただ、クラリスたちの思いを偉い人たちの
前で代弁したかった。

Page 3-6

「クラリスちゃん。 これがおいちにできる、握り飯のお礼······。
これがおいらの、精一杯の勇気だよ••••」

Page 3-7

正規の手順にのっとり、死罪が
言い渡された。 おいちは静かに目を閉じ、 判決に聞き入る。
「――ただし昨今の戦況を考慮し、
被告人には特例として選択権を与える」
驚いて目を開けたおいちの前に、 奇妙な色の林檎が差しだされた。
「被告人は、この場で選択するように。
抗命罪により銃殺刑に処されるか、
あるいはその林檎をかじった上で、 対神獣部隊に志願するか」

Page 3-8

対神獣部隊。その噂はおいちも知っていた。
「天使」 と呼ばれる、
翼を持った少女たちを集めた特殊部隊。
だが天使になるためには一
「林檎を食べれば
天使になれる可能性がある。
しかし君が林檎と適合できなければ

Page 3-9

おいらは裁判官の言葉を最後まで聞かず、 林檎をかじった。
「今度こそ人を傷つけるためじゃなくて、
人を守るために戦える・・・・・・。
おいちの夢がかなうだよ おっとう・・・・・・」
おいちは眠るように意識を失った。

Page 3-10

目が覚めるとおいちは別室に寝かされていた。
背中には大きな翼、 頭には角が生え、
全身に力がみなぎっている。
「これが天使になるってこと」
妙に現実感のない、 不思議な気分で おいちは変化した自分の体を見下ろす。 「なんだか変な夢を見てた気もするな............」
戸惑うおいちを衛兵が呼びに来る。

Page 3-11

衛兵に連れられていった上官の執務室で、 おいらは転属命令を受け取った。 神獣との戦いの最前線に立つ部隊に、 これから彼女は向かうことになる。
「天使部隊は極めて戦死率が高い。 死刑執行の引き伸ばしと変わらんぞ」 上官はおいちに命令書を手渡し、告げた。
それでも、おいちは
晴れ晴れとした笑みを浮かべていた。
「天使部隊なら、おいちは
「人を守る戦いができる」だよ」

Page 3-12

おいちが林檎をかじり、 天使となるまでの
間に軍は反乱を鎮圧していた。
反乱軍は壊滅し、幹部は捕らえられるか
殺害された。 だが指導者である クラリス父娘は、いまだに行方不明と なっている。

Page 3-13

「クラリスちゃんは、きっと生きてるだ。
いつかまた会えるだよ・・・・・・」
大空へと羽ばたきながら、
おいちは祈るようにつぶやいた。
