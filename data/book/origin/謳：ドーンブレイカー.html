Chapter 1

鉄格子の向こう

Page 1-1

ベッドと、 小さな棚と鏡。
それ以外はがらんとした部屋の中で、
唯一の彩りは鉄格子のはまった窓でした。
もう一度、 外に出たい。
窓から見える、あの鳥のように
自由に大空を飛んでみたい
そう心の中で呟いて、
私、ナルアー ・ ヴァン・ヴォクトは 溜息をつく日々を送っていました。

Page 1-2

私は望んで 「病院」に来たわけでは
ありません。 ある日突然、 生まれ育った町に
帝国の軍隊がやってきて、子供たちを集め
ここへ連れてきたのです。
父と母、街の大人たちとは
そのときに別れたきりです。
皆がどうなったのか、 私たちは知りません。
きっと殺されてしまったんだろう
そう今では思っています。

Page 1-3

帝国の人が言うには、
私は病気なのだそうです。
ですが帝国は慈悲深いので、
治療をしてもらえる、 そう聞いています。
薬を打たれたり、血を取られたり。
オーパーツと呼ばれる変わった物を 触ったり、奇妙なアクセサリーをつけたり。
合間に帝国の偉大な歴史を教えられながら、 私は今まで過ごしてきました。

Page 1-4

身体の調子がよくないのは本当です。 ベッドから起き上がれない目が続いたり、
意識を失ったまま季節が変わっていた
こともありました。
私と一緒にやってきた子供たちも
同じように、
いつも体調がよくありませんでしたから。
きっと。
ずっと続いている「治療」のせいでしょう。

Page 1-5

初めはたくさんいた子供たちも
いつの間にか数が減り、
気付けば残ったのは私だけでした。
いつだったか、白く長い服を着た大人が 「実験動物」の話を
していたことがあります。
動物がいるなら一緒に遊びたい。
そうお願いしてみましたが、
笑われてしまいました。
その瞬間、私は理解したんです。
私こそが 「実験動物」だということを。

Page 1-6

とある日のことです。
「君の病気に、
まだ試していない治療法がある」
そう言って医者が出してきたのは、
不思議な色の林檎でした。
虹色に輝く林檎は
まるで作り物のようにも見えましたが、
甘い匂いを漂わせていました。

Page 1-7

これも、他の「治療」と
変わらないものなんだろうな。
私はそう思いましたが、
拒否するという選択肢などありません。
せめて、匂い通りに
甘いといいな・・・・・・。
そう思いながら、
私はその林檎をかじりました。

Chapter 2

肉体の向こう

Page 2-1

[ページ種別：青]
「う......」
目を開けたつもりなのに、
視界は真っ暗でした。
体中に激痛が走り、頭痛で吐き気がします。
「聞こえますか。 僕は医者です。
落ち着いて話を聞いてください」

Page 2-2

[ページ種別：青]
「あなたはテロに巻き込まれて、
全身に重傷を負いました。
脳と心肺機能は生きていますが、 率直に言って、これ以上の回復は難しい」
唐突に、一体何を言っているのでしょうか。
言葉は理解できても、 意味を飲み込めません。
「今、あなたは生命維持装置に
繋がれています。
ソーシャル
ですが、あなたの社会ランクでは 36時間しか使用料金を支払えません」
「これは僕からの提案です。
安楽死を選ぶか、
あるいは生体部品として、 第二の人生を送りませんか?

Page 2-3

[ページ種別：青]
世の中の機械は、ほぼ全てが
もちろん、そんなことはあり得ません。 けれど、可能性はゼロではない
コントロール
機械知性による率を受けています。
でも、もし機械知性が暴走したり、 ハッキングされたら?
だから、一部の航空機や軌道機には、
機体制御のために生体部品が
使われているのです。

Page 2-4

[ページ種別：青]
「飛行機に生まれ変わる、ということ?」
「簡単に言えばそうなります」
ああ、 生まれ変われるんだ。
医師の言葉を聞いた途端、
私の中で、それまでの焦りが消えました。
だって、 私はまだ何もしていない。
ここで終わりたくない。
このまま死んでいくのは嫌。

Page 2-5

[ページ種別：青]
だから。
自由のために、
私が今できることをしたい。
頬を撫でる風の冷たさも、
髪がたなびく心地よさも
私にはもうわからない。
でも、夜明けとともに燃え上がり
やがて青ざめていく空の、
世界の美しさはわかる

Page 2-6

[ページ種別：青]
手も足も失ってしまったけれど、鋼鉄の翼と、大出力のエンジンで
私は今、大空を飛んでいます。
おしゃれなんて一生することもないだろうと思っていたけれど、
この煌めく直線的なボディはお気に入り

Page 2-7

[ページ種別：青]
空を飛ぶ機体となって知ったのは、 世界の美しさだけではありませんでした。
古今東西の知識を閲覧できましたし、
パイロットや整備士といった 々な人たちとも友達になれました。
皆が私のことを大切に扱ってくれる
こんなことは、
今まで生きてきて、初めてでした

Chapter 3

空の向こう

Page 3-1

[ページ種別：青]
私の充実した日々とは逆に、
いつからか世界には重苦しい空気が
漂うようになっていました。
そうならなければいいという
淡い希望は打ち砕かれ、ついに
今日という日はやってきてしまったのです。
機械知性との戦争が始まりました。

Page 3-2

[ページ種別：青]
これまでとは違い、
今日、私の内部には
武装した兵士たちが詰め込まれています。
この後、私は軌道上へ打ち上げられ 兵士とともに、 機械知性が占拠している
宇宙ステーションへ突入します
空を飛び始めた日のことが
嘘のように、
私の気持ちは沈んでいました。
兵士たちは一様に固い表情をしています。 この中の何人かは、地上に戻ることは
できないでしょう。もしかしたら、私も

Page 3-3

[ページ種別：青]
結局のところ、私は道具なのです。
任務を拒否すれば凍結され、別の部品に
交換される。
それだけはです。
この身体を失いたくない。
また、暗闇の中に閉じ込められたくない。
機械知性には何の恨みもありません。
なぜ戦うのかすらもよくわかりません。
でも、きっと同じ想いを抱えた兵士とともに
私は宇宙へ向かって飛び立ちました

Page 3-4

目を開けると、鉄格子の向こう側に
沁みるような青空が広がっていました。
「今のは、夢······ ?」
だとしたら、
私は一体どのくらい眠っていたのでしょう。
さすがに、以前のように季節がいくつも
過ぎていたりはしていないようです。
身体を起こして、私ははたと気付きました。

Page 3-5

身体が軽いのです。 どこにも痛みがない。
林檎をかじるまでは、
常にどこかが重く、痛く、 不調だったのに。
「ど、どういうこと?」
私が呟くと、鏡の中の私の唇も動きます。
私はペッドから降り、鏡を覗き込みました。 これが、「治療」の結果なのでしょうか。
そこには、機械の翼を持った
見たことのない姿の私が映っています。

Page 3-6

鏡に映る羽根は、
からだ
夢で見た 「私」の機体と
よく似た形をしていました。
背中に意識を集中し、
動かしてみると
身体がふわりと浮きました。
であれば、やることはひとつだけ。
私は小さな牢獄を飛び出しました。

Page 3-7

高いところまで一気に開け昇ると、
今までいた建物が豆粒のようでした。
私は今まで、
小さい建物から、小さい大人たちが、 私に向かって何かを叫んでいますが、
私は何とも思いませんでした。
なんて小さな世界にいたのでしょう。 自然に笑みが浮かんできます。

Page 3-8

ふと、飛んできた鳥と目が合いました。
いつか私が、
鉄格子の向こうから見上げていた鳥です。
私は翼を羽ばたかせ、鳥に並びます。 今の私なら、どこへでも飛んでいける。
もう誰にも、何にも、縛られない。 何も諦めない。

Fin.
