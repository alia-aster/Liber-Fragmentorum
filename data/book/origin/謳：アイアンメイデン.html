Chapter 1

誰が為の林檎

Page 1-1

ステンドグラスを通した陽光が
修道院の廊下に淡い色彩の影を落とす。
「ごきげんようエリザベートさま」 清らかなシスターたちが、わずかに頬を染め
修道女長のエリザベートに挨拶する。
「ごきげんよう」
穏やかな微笑みを浮かべ、
挨拶を返すエリザベートであったが
そのはらわたは怒りで煮えくり返っていた。

Page 1-2

なぜ! なぜ! なぜーっ!!
エリザベートは、手にした分厚い書物を
へし折れんばかりに握りしめる。

Page 1-3

エリザベートが怒り狂っている原因は、 これまで散々手を焼いた問題シスター、
ドロシーにあった。
あのファッンクソシスターが、
聖女さまのお導きで
天使になったと言うのだ。
聖女さまに真っ先に認められるのは、 私であるはずなのに!よりにもよって、 あのビチグソクソピッチが!

Page 1-4

これまで誠心誠意、身も心も捧げて 聖女さまにお仕えしてきたというのに。
「なぜ聖女さまはあんなやつを・・・・・・」
「それは、 自分が一番
よく分かっているでしょう?」
その声にエリザベートは振り返る。

Page 1-5

「はっっ!」
愛らしく美しい笑み。
そこには、まさしく心から愛する
聖女さまがいらっしゃった。
時間差で聖女さまの言葉が胸に突き刺さる。
天使に選ばれない理由は、
エリザベート自身が一番良く知っていた。

Page 1-6

――それはエリザベートが
まだ若く、 未熟だった頃。
修道院のあった街が、 神獣に襲われたのだ。
「きゃあああああ!」
「いやあっ、やだ、 たすけてっ!」
シスターたちの悲鳴は、今も忘れられない。
あの日、エリザベートは何もできなかった。
身を震わせ、立っているだけで
精一杯だった。
そして、エリザベートは逃げ出した。 助けを求める仲間に背を向けて。

Page 1-7

あの日の出来事を思い出すたびに、
心臓がしぼられるように痛む。
「自分が浅はかでした。 私は
仲間を置いて逃げたような人間です。
どうして、 選ばれましょうか」

Page 1-8

「しかも自分の事を棚に上げて、 ドロシーに嫉妬して・・・・・・ 私は未熟で、
天使などほど遠い存在……。聖女さま、
こんな私を認めないでくださいましっ!」
一人懺悔大会を開いていたエリザベートに、
聖女さまの白い手が突きつけられた。
「それはいいとして……」
聖女さまはごそごそと懐を探る。

Page 1-9

「あなたも食べる？」 聖女さまが差し出したのは、
輝かしい虹色の果実――グレゴールの林檎だった。
これを食べた者は天使になるが、 運が悪ければ命を落とすと聞く。
「よ、よろしいのですか？」 「もちろん」
聖女さまは愉快そうに微笑み、
エリザベートの震える手に林檎を乗せた。

Page 1-10

聖女さまが、手ずから林檎をお与え
くださるなんて!
エリザベート、もう死んでもいい!
いやいや、まだ死ぬわけにはいかない。
天使となって聖女さまのために尽くさねば!
「みみみ、身に余る光栄です!!」
エリザベートは宝物（ほうもつ）のように林檎を掲げ、
感謝と感激の涙を流しながら、
大事に大事に林檎をかじった。

Chapter 2

誰が為の銃声

Page 2-1

[ページ種別：青]
「オオオオオオオオオ!」
獣のような咆哮が辺り一面に響く。
静謐（せいひつ）な教会は、解き放たれた
デーモンがひしめく地獄へと
変貌を遂げていた。

Page 2-2

[ページ種別：青]
「……ここまでとは」
エリザベートは奥歯を噛みしめる。
自分がいながら、このような事態を
招いてしまった。
後悔は後だ。今はすべきことがある。
「聖女さま、 必ずお救いします」
手にした銃を構え直し、 教会へ突入した。

Page 2-3

[ページ種別：青]
聖別された銃弾を、異形のデーモンに叩き込む。 死体を乗り越え、次のデーモンを撃つ。
見敵必殺。群がるデーモンを次々と殺す。

Page 2-4

[ページ種別：青]
一刻も早く聖女さまの元へ、
たどり着かねばならない。 邪魔する者はすべて殺す。
だが、 デーモンの数は無尽蔵だ。
押し寄せるデーモンたちの 背後で空間がゆがみ、 地獄大公アスモの
醜く太った巨体が顕現した。

Page 2-5

[ページ種別：青]
聖女への信仰を持つエリザベートは 地獄大公だろうとデーモンを恐れない。
エリザベートのわずかな隙をつき、
デーモンたちが津波のように、
だが地獄大公の放つ邪悪な瘴気に、 肉体が反応し、一瞬攻撃の手が止んだ。
「しまった……！」
エリザベートへ一斉に襲いかかる。

Page 2-6

[ページ種別：青]
海を割る奇跡のように、
デーモンの群れを、無数の銃弾が
引き裂いた。
「おう修道女長！
ドロシー様のお出ましだぜ！」
そこには巨大な回転速射砲（ガトリングガン）を抱えた
問題児シスターの姿があった。

Page 2-7

[ページ種別：青]
「なぜお前がここに？」
「あたしがいなきゃ始まんねーだろ」
ドロシーが憎まれ口を叩く。
「聖女さまの前でそんな言葉づかいを したらケツの穴を増やしてやるからな」
エリザベートは頬の血を拭いながら笑う。

Page 2-8

[ページ種別：青]
ドロシーは散々手を焼かされてきた
問題児だが、増援は助かる。
ドロシーとふたりで、大量の銃弾を
ばらまき雑魚デーモンたちを一掃していく。
地獄大公であろうが毎分三千発の連射速度を 誇るガトリングの前ではただの脂肪の塊だ。
クソビッチが頼もしく思えたのは初めてだ。
「ほんと、ムカつく・・・・・・」 「あたしも同じ事思ってた」
飛び散った肉体を、銃から持ち替えた 火炎放射器で焼き尽くすと、あとには
何も残らなかった。
エリザベートとドロシーは、
教会の奥、 聖堂へと続く扉を蹴り開けた。

Page 2-9

[ページ種別：青]
穢（けが）れなき祭壇の上に置かれた拷問器具
その周囲では、大小無数のデーモンが
踊り狂っている。
鋼鉄の処女（アイアンメイデン）を象ったその目から、血の涙が
流れていた。 聖女さまの血だ。
「聖女さま、ただ今、お救いいたします！」
エリザベートとドロシーは瞬く間に
デーモンを一掃した。

Page 2-10

[ページ種別：青]
「聖女さまっ、 聖女さま!」
エリザベートは銃を投げ捨て、
祭壇の上の拷問器具へ駆け寄る。
固く閉ざされた扉を慎重に開け、内部に
閉じ込められていた聖女を救い出した。
「聖女さまっ」
血まみれの聖女は、
力なくエリザベートの腕に倒れ込む。
デーモンにより拷問された、
そのいたわしい姿に、 エリザベートは
胸をかきむしられる。

Page 2-11

[ページ種別：青]
突如訪れた多幸感。
聖女さまが笑ったああ！
なんと尊い！
聖女さまが、私のために、
「ありがとう。 エリザベート」
聖女が微笑んだその瞬間、
微笑んでくださったあああ！
これが……ときめき！
すべてが吹き飛んだ。
幸せ!!
「おい、大丈夫か?」
ドロシーの声が遠くから聞こえる。
だがエリザベートは「はわ、はわわ……」と
幸せそうな喘ぎを残し、気を失った。

Chapter 3

誰が為の罪

Page 3-1

「はっ!」
気付けばエリザベートは修道院の中にいた。
地獄のような風景はもうない。
夢を見ていたのだろうか。
聖女さまだけが、 夢と同じ微笑みを浮かべて
エリザベートを見上げている。
(見上げている•••・・・?)
エリザベートが不思議に思い、
自身を見下ろすと

Page 3-2

「と、飛んでいる!?」
エリザベートは宙に浮いていた。
翼を持つ天使となっていたのだ。
しかもなぜか、聖女さまを閉じ込めていた
拷問器具を背負っている。

Page 3-3

「これでエリザベートも天使ね。
「おめでとう」
もう不安になる必要もないでしょう？」
ぱちぱちぱち、と聖女さまの
可愛らしい拍手がエリザベートを讃える。
聖女さまはエリザベートに歩み寄り、
慈しむように両手をすくい取った。

Page 3-4

「私はいつも、
エリザベートを頼りにしているよ」
聖女さまはエリザベートだけを瞳に映した。
その無垢な瞳は雄弁に語る。 エリザベートはとっくに選ばれている。
嫉妬することなどなかったのだと。
「私はあやまちばかり……」 知らずうちに頬に涙が流れる。
「今回ばかりではありません。
私は仲間を捨て神獣から逃げました。
夢の中でも、私がいながら聖女さまが 汚らわしいものに捕らわれてしまった……」

Page 3-5

「私は長く生きている分、
罪を数えるエリザベートに、聖女さまはゆっくりと首を振る。
「それは私も同じ。 私もあやまちばかりよ」
数えきれないほどのあやまちを重ねてきた。 償えないあやまちを背負っている分、 それ以上の事をしなければならないわ」
聖女さまは覚悟を語り、
「え？」
意外な答えにエリザベートは目を見開く。
「あなたにはそれができると思う」
エリザベートの両手を胸に寄せた。

Page 3-6

「ひゃあっ」
聖女さまに両手を引き寄せられ、
エリザベートは反射的に身を引いた。
そしてガシャン!と音を立て、
背中の拷問器具の中に閉じこもる。
「イテテテ……ッ」
当然中に生えた針のむしろとなるが、 今はその痛みがありがたかった。
（これは贖罪にちょうどいい……）

Page 3-7

「聖女さま！ 私がんばります！ これからもより一層、身を粉にして 聖女さまのために働きます!! 贖罪もしますー! イテテ」
鉄製の拷問器具の中から、 ぐわんぐわんと
エリザベートの宣誓が聞こえる。
引き寄せた手を払われ、
ぽかんとその光景を見ていた聖女は呟く。
「まあ、面白いからいっか」
誰が聞くでもないその声は、
エリザベートの熱弁にかき消えた。
Fin.
