Chapter 1

止まない雨

Page 1-1

帝都の郊外にあるサナトリウム。
さやべ
茶谷部あめりは、カーテンを開けると、
笑顔で振り返った。
「見て、 かなた姉さん! いい天気!
私の「雨女」 パワーも、お休みかな!」
「ふふ、そうね、あめり。
あなたが元気なら、 世界中がお天気だわ」 姉のかなたは、林檎の皮をむきながら
優しく微笑んだ。

Page 1-2

本当のあめりは、臆病で悲観的だ。
あめりは生まれつき体が弱く、 入退院を繰り返していた。
けれど、自分のために身を削る姉の前では、 明るい妹でいたかった。
両親を早くに亡くしたあめりにとって、自分を変えたくて、無理に笑っていた。
軍需工場で働いて家計を支えてくれる
かなたは、たったひとりの家族で、 一番大切なひとだった。
「止まない雨はないし、
そのあとは虹が出るんだから」 それが、姉の口癖だった。

Page 1-3

悲劇は突然訪れた。
姉が働く工場で
原因不明の火災が発生した。
「姉さん・・・・・・。 かなた姉さん!」
病室の窓から見える空が、 不気味な色に染まっている。
あめりは祈った。 叫んだ。
雨よ降れ。あの火を消して。 私が本物の雨女なら、
今すぐ雨を降らせてよ!

Page 1-4

祈りは届かない。
工場が焼け落ち、 灰になるまで、
・滴の雨も降ることはなかった。
数日後、 かなたは小さな箱に入って、 あめりの元へ帰ってきた。
「······ なんで···・・・。
あんなに、あんなに願ったのに・・・・・・」
皮肉にも、葬儀の日は土砂降りだった。

Page 1-5

火災の原因は、 放火だった。
凄惨ないじめにあっていた
元工員の復讐。
犯人もまた、火災に焼かれて死んだ。
仕方が無い、と誰かが言った。
前線の要求に応えるため、 重いノルマを
課した軍も、過酷な勤務で工員を追い詰めた 工場の幹部も、犯人に暴力を振るっていた 工員たちも、なるべくしてなったのだ、と。
社会の歯車が歪み、
噛み潰した犠牲者の中に、 たまたま姉がいた。 ただ、 それだけのことだと。

Page 1-6

「保証人であるお姉様が亡くなられ、
お支払いも滞っておりますので・・・・・・」 入院費が払えなくなったあめりは、 サナトリウムを追い出された。
雨に濡れる帝都の路地裏。
あめりは、
姉がむいてくれた林檎の味を
思い出していた。
世界は、あまりにも身勝手で、
救いようがなく、間違っている。

Page 1-7

「世界に合わせて、
自分のかたちを変えてきた。
でも・・・・・・世界が間違ってるなら、 世界を変えるしかないよね」
あめりの瞳から、 光が消えた。
彼女は、 ブラックマーケットの売人から、
アンプル
小瓶を受け取る。
「ハリコン」
帝都の裏社会で出回る、
驚異的な力を引き出すという違法薬物
その正体は、かつて第十三研究所で リンファが開発した実験薬だった。

Page 1-8

「人の思い通りにならないものを
あやつる力は···・・
運命をあやつる力なんだ」

Page 1-9

帝都を豪雨が襲った。
通常の雨ではない。
いつまでも空を覆う黒雲は
容赦なく雨を降らせ続けた。
下水道はあふれ、 道路は川へと変わった。
水流は意志を持つかのように荒れ狂い、
帝都の機能は麻痺した。

Page 1-10

「雨、雨、 ふれられ......。
汚い世界を、 全部洗い流して・・・・・・」
中央広場の時計塔の頂上で、
あめりは歌っていた。
かつての気弱な少女はもういない。
濁流が橋を落とし、建物を飲み込んで、 人々が逃げ惑う。 その様子を見ても、 彼女の心は、不思議なほど広いでいた。
かなた姉さんがいない世界なんて・・・・。 そんなもの、沈んでしまえばいい。

Page 1-11

雨雲を切り裂き、
「漆黒」 が舞い降りた。
激しい雷を背に、黒い翼を広げた
シルエットが浮かび上がる。
「あなた······誰?」
「ダークエンジェル」
豪雨の中、 漆黒の天使は
名乗りをあげた。

漆黒のドレス。 禍々しくも美しい翼。
圧倒的な 「力」の気配。

リンファ

今、少女の人生を狂わせている。

「邪魔なんてさせない。
間違った世界を全部、洗い流してやる!」
あめりが叫ぶと同時に、 閃光が走った。 稲妻がダークエンジェルを貫く。 衝撃で、周囲の建物の窓が一斉に割れた。
雷に打たれたダークエンジェルの姿は、

「私は対話を望んでいますのに」
自らを繭のように包んでいた黒い翼を広げ、
ダークエンジェルが現れた。
「うるさい、うるさい!
バカにして!」
あめりの背後で、水流がうねり、
持ち上がった。 津波のような波頭を
形成し始める。
「全部、洗い流してやる! 姉さんのいない世界なんて、 消えてしまえ!」

Page 2-5

(・・・・・・この子は、私だわ)
リンファは、暴走するあめりの中に、
かつての自分を見ていた。
思い通りにならない現実を呪い。
力を誇示し、大切なものを壊そうとする。
その先にあるのは、果てしない 後悔と孤独だけだというのに。
「スノ... 私に、力を貸して」
リンファは小さくつぶやき。
胸元のペンダントに口づける。

Page 2-6

ダークエンジェルの翼にある、
無数の瞳が開いた。
「あなたの「涙」はすべて、
私が受け止めて差し上げますわ!」
「だまれ! キモいんだよ!」
「チクチク言葉は許しませんわ!」 漆黒の翼から、 熱線が放たれる。
狂乱の濁流と熱線が、
帝都の空で激突する。

虹

「あはは! 無駄だよダークエンジェル!
雨はどこにでも降る。
水はどこにだって入り込むんだ!
「あなたのその翼も、濡れて重くなって、
狙いがつけられなくなる・・・・・・」
きょせい
あめりは虚勢を張った。
無理に明るい声を出す。
そうしていないと、 どす黒い感情に
飲み込まれてしまいそうだから。

Page 3-2

「終わりだ!」
あめりが右手を振り上げると、
巨大な竜巻が、
ダークエンジェルを包み込んだ。
帝都の瓦礫を吸いこみ巻き上げた、
巨大な破砕兵器だ。
「天使」でも何でも、
跡形も残らず消し去るはずー

Page 3-3

竜巻の中から、
漆黒の線がほとばしると、
一瞬で竜巻が蒸発した。
その中から、 傷ひとつ負っていない
ダークエンジェルが、
心底嫌そうに自分の髪を弄りながら
あらわれた。
「そんな、 どうして・・・・・・」
「私は美しいからですわ。
美しさこそパワー」

Page 3-4

「言ったでしょう。 美しさこそパワー。 私の意志のほうが美しいからですわ」
ダークエンジェルの瞳に温かな光が有る。 数多の後悔を乗り越えてきた者だけが
宿すことができる光だ。
「あなたの痛みも、 姉を失った苦しみも、
私にはどうすることもできませんわ。
・・・でも、ごらんなさい」

Page 3-5

リンファが静かに地上を指さす。
濁流に飲み込まれた屋根の上。 必死に子供を抱きかかえて、 空を見上げている母親がいた。
「腰まで水に浸かり、震えている人がいた。 泥だらけになって、 土嚢を積む人がいた。
彼らの中には、 かなた姉さんのような
優しい人もいるはずだ。

Page 3-6

あめりの手の震えが止まらない。
雨を操る力が、 急速に弱まっていく。
「気付きましたわね。
あなたが洗い流そうとしたのは、
かつてのあなたや、あなたの姉と同じ、
無事の人々ですわ」
ダークエンジェルの声が、
容赦なくあめりに突き刺さる。
「あなたもまた、
間違った世界の一部なのです」

Page 3-7

私は、世界を変えたかった。
けれど、実際にやっているのは、
世界をより醜く、より残酷にすること。
涙があふれて止まらない。
目の前の景色が、 ゆがみ、僕んでいく。
「うああ...つ。
姉さん・・・・・・」

Page 3-8

その隙を リンファは見逃さなかった。
「終わりにしましょう」
闇の翼から放たれた線が
あめりの身体を貫いた。
「あ、がっ......!」
あめりの身体が、 真っ逆さまに堕ちていく。

Page 3-9

冷たいアスファルトの上で、
あめりは身動きできず、 空を見上げていた。 雲の切れ間から、太陽が顔を出している。
コツコツとヒールの音が響く。
ダークエンジェルが、 近づいてきた。
「惨めですわね。
泥にまみれ、涙に濡れて。
さっきまでの勢いはどこへ行きましたの?」

Page 3-10

「・・・・・・ 殺して。
もう、いいんだ。 私・・・・・・。
姉さんのところへ、行きたいから」
「選びなさい。
このままヴィランとして野垂れ死ぬか」
「私に手を汚させようとは、 どこまでも甘ちゃんですわね」
リンファは、 虹色に輝く林檎を あめりの目の前に差し出した。

Page 3-11

「・・・・・・ あるいは、この
「グレゴールの林檎」 をかじり、
呪われた天使として生きるか」
「天使······ ?」
「ええ。人間であることを捨て、
罪を背負い、戦い続ける存在。もっとも、 死ぬ可能性のほうが高いですけれど」

あめりは、自分の手を見た。 世界を壊そうとした、 汚れた手。
「止まない雨はない······。
そのあとは虹が出る......」 あめりは虹色の林檎に、 汚れた手を伸ばした。
