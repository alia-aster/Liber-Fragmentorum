Chapter 1

その手を伸ばして

Page 1-1

ミリアムがパンを差しだすと、 ボロボロの
服を着た子供たちが我先にと手を伸ばした。
街は廃墟となり空には暗雲が広がっている。 大人たちは疲れ切り、 ただ座り込んでいた。 皆、神獣に生活を奪われた人々だ。
「みなさん、 もう大丈夫ですからね」 ミリアムは、声をかけながら人々に食糧や
生活必需品を配って回る。
被災地や紛争地に物資を届ける。
民間の慈善団体——そこでミリアムは
働いていた。

Page 1-2

神獣も戦争も、人々の暮らしを破壊する。
どれだけ、食料や物資を届けても
焼石に水でしかない。
「おい、俺は腹が減ってるんだ! 小僧、その林檎をよこせ!」
いつになったら平和は訪れるんだろう。「これは僕が拾ったんだ! 僕のものだ!」
子供と大人が言い争う声が響いた。
ミリアムはため息を飲み込む。
この地獄は永遠に続くように思えた。

Page 1-3

ミリアムが目をやると、大の大人が少年から
林檎を奪い取ろうとしていた。
こんなときに、何をしているのか……。 怒りが胸にこみあげる。
仲裁に入ろうとした矢先、仲間が大声を
あげながら走ってくるのが見えた。
「神獣が出た!
急いでここから離れろ!」
仲間が大声で叫ぶ。

Page 1-4

「神獣よ! 早く逃げて!」
ざわつく人々にミリアムは大声で叫んだ。 少年は林檎を落とし、 逃げ出した。
オオオオオオオオ!
耳をつんざく咆吼が、上空から降り注ぐ。
顔を上げると、 雲の向こうに
「――あ」
目を焼く閃光と、爆発。 熱と衝撃を感じた次の瞬間には、
ミリアムは気を失っていた。
神獣の影が見えた。

Page 1-5

焦げ臭さで目が覚めた。
かすむ視界に映るのは焼けた地面。
辺りに転がる黒々とした、 何か。
さっきまでたくさんの人がいたのに、
みんな死んでしまった。
争っていた男も少年も、みんな。
まただ..................。
何度も、この光景を見てきた。
みんな、死んでしまった。
神獣にやられたのだ。

Page 1-6

ミリアムは動けなかった。
右腕の感覚がない。
瓦礫の下敷きとなり、潰されたようだ。
いつもこうだ。
私がどれだけ頑張っても、 結局いつも助けられない。
自身の無力さが憎い。
神獣も戦争もすべてが憎い。
それでもどうしようもない一 絶望しかけたとき、 ミリアムは視界の隅に
林檎が転がっていることに気付いた。

Page 1-7

何もかもが焼き尽くされたというのに、 林檎だけは傷ひとつなく、 輝いていた。
グレゴールの林檎?
以前訪れた地域で聞いたことがある。 いわく、かじれば天使の力を得られる
林檎があるが、運が悪ければ死ぬ。
このままではミリアムも死ぬだろう。 だがもし、この林檎を食べることで、 力を手に入れられるとしたら?

Page 1-8

私は、争いのない世界を作りたい。
人を助ける力が欲しい。
涙で目の前が滲む。
それでも林檎へ、 動く方の左手を伸ばした。
どうか、グレゴールの林檎で
ありますように。
ミリアムは、 林檎をつかんだ。

Chapter 2

たとえ手だけでも

Page 2-1

[ページ種別：青]
「よう、 あんさん。 新入りかー？」
うずたかく積み上がったゴミの山の間で、
気の抜けた声が響く。
ネイオンシティが大量消費の果てに
吐き出すゴミは放棄地区へ流れ、
そこでも不要となったものが
最下層であるザ・ピットへ流れ着く。
「ピッカピカやのに、 何でここ来たん？」
声は捨てられたばかりのガラクタに
話しかけていた。
返事はない。

Page 2-2

[ページ種別：青]
「駄目かー。 やっぱわての他に知性のある
ヤツはおらんのかいな。
もう退屈で死にそうや!」
声の主は、巨大な機械の腕だった。
名前はファイブ。 人間の指を模した
五本の指が力無く閉じる。
ファイブは巨大な人型ロボット兵器の
腕として造られた。 だが、 巨大ロボ兵器の
有用性に疑問符がつき、計画は頓挫。
ゴミ溜め送りとなった。

Page 2-3

[ページ種別：青]
風の噂では、ネイオンシティの
ファイブ以外のパーツはゴミ漁りの人間が
持っていった。 ファイブが盗られなかった
のは「わても連れてけ!」 と騒いだせいで、
気持ち悪がられたからだ。
超有名音楽プロデューサーは、 捨てられた
機材をリユースした楽器を使う、 環境に優しいサステナブルなやつらしい。
「このままは嫌や。
でも、兵器に戻るんも嫌や。
「わてもキーボードになったら
絶対ええ音出すで。 アイドルとか詳しいし」
街の光さえ届かないゴミ溜めに、
兵器やのうて、楽器になりたいナァ・・・・・」
ファイブの声を聞く者はいない。

Page 2-4

[ページ種別：青]
ある日、ファイブの前に人間の少女が
現れた。 少女は、喋る機械腕のファイブにも
物怖じせず、 リルムと名乗った。
「ママとはぐれちゃったの」

Page 2-5

[ページ種別：青]
リルムは、着古したボロ服をまとい
髪はべたつき 垢まみれだった。
何日も風呂に入っていないのだろう。
(はぐれたんやなくて捨てられたんやな) 物も人も、捨てられたものが最後に
行き着くのがザ・ピットだ。
ファイブは少女を眺めているうちに、
妙案を思いついた。
なあちゃん。 アイドルやらんか？」

Page 2-6

[ページ種別：青]
「は?何言ってんの？」
眉をひそめる少女に、ファイブは
ガチャガチャと指を鳴らし屁理屈を並べる。
「アイドルになれば、 有名になるやろ?
きっと親御さんに見つけてもらえるで。 しかもぎょーさん儲かってウハウハや。
こうもう、アイドルやるしかないな」
「アイドル 考えたこともなかったけど
何か楽しそう」
少女の目に光が宿る。
(チョロい小娘やな~。
ちょうどええわ。 この小娘を利用して、
こっから脱出してやるで!)

Page 2-7

[ページ種別：青]
スクラップヤードに、少女の歌声が響く。
「ええ声やんか・・・。 これはワンチャン、
いけるかもしれんで……」
リルムは意外と筋がよく、 ファイブの レッスンでメキメキと歌唱力をあげていた。
「時は来た! 明日ネイオンシティに
向けて出発や!」
「うん! いよいよだね!」

Page 2-8

[ページ種別：青]
明日は例の音楽プロデューサーが主催する、
新人発掘オーディションが
開催されるのだ。
ゴミ溜めの中からマシな衣装を
でっちあげると、 リルムははしゃいで、
ファイブの指に抱きついた。

Page 2-9

[ページ種別：青]
夜明けより早く、ゴミ溜めの端が
明るく輝いた。
陽光ではない。 炎だ。
ネイオンシティに続く道が、
火と煙に閉ざされる。

Page 2-10

[ページ種別：青]
火炎放射器を背負ったドローンが、 リルムとファイブの前に現れた。
「速やかに市民IDを提示してください」
ドローンが機械音声を繰り返しながら、
火炎放射器をリルムに向けた。

Chapter 3

その手を握って

Page 3-1

[ページ種別：青]
ザ・ピットは火炎地獄となっていた。
ここを根城とする犯罪者を一掃するためか、
国際的スポーツ大会のための浄化作戦か
その両方かもしれない。
火炎放射器を搭載したドローンが
飛び回り、動く者すべてに火炎を浴びせる。
その中に、 リルムがいた。

Page 3-2

[ページ種別：青]
「あかん! リルム!」 ファイブはとっさに駆け寄り、 リルムを手の中に包み込む。
ファイブごと リルムが炎に包まれる。
「リルム、 リルムーっ」
ファイブは熱に耐えられても、人間である
リルムは耐えられない。
……あたし、 自分が捨てられたって
分かってた」
震える声でリルムがつぶやく。

Page 3-3

[ページ種別：青]
「でもファイブのおかげで夢を見られたよ。
生まれ変わったら、 ファイブみたいに誰かを助けられる人になりたい……」

Page 3-4

[ページ種別：青]
「リルム! リルム! 返事せえ!」
ファイブが必死に呼びかけても、 リルムの返事はない。
朝が来て、 夜になり、周りの炎が消えても、
リルムは動かないままだった。
リルムの呼吸が止まる。

Page 3-5

虹色のがほどけていく。 繭の中から出た ミリアムは、 瓦礫で潰れたはずの右腕が
元通りになっているのを見た。
その上、背中には今までなかった
翼が生えている。 天使になれたのだろう。

Page 3-6

黒焦げになった街の中で、 ミリアムは
立ち上がる。
「他に生き残りは……?
早く助けに行かないと」
「娘ちゃん! ちょい待ち!」
ミリアムの背後から、呼びかける声がした。

Page 3-7

「は？」
振り向くと、ガチャガチャと騒がしく
機械の腕が歩み寄ってきた。
「わてはファイブや!
忘れてもらっちゃ困るで ! 」
「夢で見たものが、 なぜここにいる？」
「夢? 夢ならどんなに良かったか……
嬢ちゃん、 人助けに行くんやろ? なら、 わても手伝うで!」
「それがわての……
わてなりの、リルムの供養なんや!」

Page 3-8

「分かった。 ならば共に行こう」 ミリアムの言葉に、 ファイブの指が ぱっと広がった。 喜びの表現だろう。
「おおきに! よろしくな嬢ちゃん」 「ミリアムだ」
「ミリアムはん。
おいちゃん手助けは得意やで。
なんせ手やからな! ガハハ!
Fin.
