Chapter 1

身に過ぎた果報

Page 1-1

いかせる
アリスは 「不幸な少女」だった。
アリスがまだ幼いころ、
大好きだった両親を流行病で亡くし、
父の妹に引き取られたのだ。
叔母はアリスを慰め、
優しく包み込んでくれた。
アリスも叔母を慕い、子供のいない叔母は
アリスをとても可愛がった。
だが、ふたりの幸せは長く続かなかった

Page 1-2

アリスの父が残したわずかな遺産を狙って、 ある夜、何者かが家に押し入ったのだ
アリスはベッドの下へと身を隠した。 そこで、目を背けることもできず。
叔母が刃に倒れるさまを見てしまった。
アリスは恐怖のあまり声も出せず、
身動きひとつできないまま。
光を失った叔母の瞳を、
夜明けまで見つめていた。

Page 1-3

次に引き取ってくれた遠い親戚は、
アリスの目の前で心臓発作を起こし急死した。 誰もがアリスを恐れ、距離を置いた。
アリスに優しくしてくれた人は
昔、死んだ。
アリスは 「不幸を呼ぶ少女」と呼ばれても
否定しなかった。
もう誰も、アリスを 「不幸な少女」と呼ばなくなった。
アリスも自分のせいで周りが不幸になると
信じていたからだ。
人々はアリスを憐れむことをやめ、
「不幸を呼ぶ少女」と呼んだ。
大事な人たちが死んだのは、自分のせいだと
アリスは分かっていた。

Page 1-4

もう誰も不幸にしたくない。
もう、大事な人を失いたくない。
アリスは、独りで生きるようになった。 独りは寂しいけれど、
これで誰も不幸にせずに済む。
そう自分に言い聞かせた。
そうして孤独に生活を続けて、 しばらく経ったあと、ひとりだけ、 アリスの家を訪ねてくる者がいた。

Page 1-5

それは、縁もゆかりもない少女だった。
「あんたがアリスよね? あたしはミア! あんた、あたしと一緒に遊びなさい!」

Page 1-6

最初、 アリスはミアの言葉に応えなかった。
きっと、たちの悪いいたずらだ。
すぐ飽きるだろうと思っていたが、予想とは
裏腹に、ミアは毎日アリスを訪ねてくる。
アリスはとうとう根負けし、
ミアと一緒に過ごすようになった。
お茶する日もあれば、ものを知らないアリスに
ミアが本で勉強を教えてくれる目もあった。

Page 1-7

早く関係を絶ち、離れなければ、
ミアを不幸にしてしまう。
そう分かってはいるのに、 ミアとの時間は 楽しくて、温かくて・・・・・・。 もう少しだけ
一緒にいたいと、 アリスは願ってしまった。
その日は、突然訪れた。

Page 1-8

ミアと街を歩いているとき。
近くで馬車馬が暴れ出した。
惨い音が響いた。
血の色が鮮明に映し出されていた。
馬は馬車を引いたまま、 ふたりがいるほうへアリスの視界には、馬車に轢かれたミアの
まっすぐ突っ込んでくる。 突然のことで 動けずにいると、 アリスは横へ突き飛ばされた。 ミアが突き飛ばしたのだ。

Page 1-9

幸い、ミアは命を落とすことはなかった。 だが、ミアは大怪我を負い、自宅での療養を
余儀なくされた。 片目が見えなくなり、 歩くこともままならなくなっていた。
包帯に包まれ、痛々しい姿のミアを
アリスは開かれた窓の外から見ていた。
(アリスと一緒にいたから。
アリスのせいで、ミアは不幸になったんだ)

Page 1-10

ミアのためを思うなら距離を置くべき
だったのに。 離れるのが嫌だから、 ミアなら大丈夫だと思い込もうとしていた。 アリスのせいで、 ミアを傷付けてしまった。
もう、 ミアに関わってはいけない。 アリスがその場を離れようとすると、 「こう!」と怒ったような声が聞こえた。 振り向くと、 ミアがアリスのほうを見ていた。

Page 1-11

「・・・・・・あたし、 昔はダメな子だったわ。
けど、アリスに色んなことを教えたくて、 本を読むようになって勉強も好きになった。 あたしの世界はアリスが広げてくれたのよ」
そんな言葉をかけられたのは、
アリスが生きていて初めてだった。

Page 1-12

ミアから奪ってばかりじゃなかったんだ。
アリスも ミアに与えていた物があった。 ミアの言葉が心に染み渡り、
「アリスと会ってから毎日楽しくて幸せよ。
だから、 勝手にいなくならないでよね」
そう言って、ミアはにんまりと笑った。
今までの悲しみや孤独が癒えていく。

Page 1-13

翌日、アリスはひとりで街を歩いていた。
ミアへのお見舞い品を探すためだ。
どうせなら、ミアがうんと喜ぶ物にしようとこの辺りの露天商には怪しい噂があるから
アリスは張り切っていた
近付くな、とミアに言われていた。
だが、なかなか決められず、
あれこれ悩むうちに露天商が立ち並ぶ
エリアまで来てしまった。
引き返そう。 そう思い、身を翻しかけた
アリスの目に、ある物が留まった。

Page 1-14

それは、不思議な装丁の本のセットだった。
どうやら、露天商の売り物のようだ。
「お目が高いねぇ、 お嬢さん。
こりゃあとっても珍しい本なんだよ」
露天商の老婆が、 アリスにそう言ってくる。

Page 1-15

珍しい本・・・・・・ ミアが喜ぶかもしれない。
だが、ここで買ってもいいのだろうか? 悩んでいると、 老婆がアリスの手に
本を押し付けてくる。
「ほれ、気になるんだろう?
ここで逃したら二度と手に入らないよ」
本を買うか、この場から去るか。
アリスが選んだ答えは

Page 1-16

アリスは結局、あの本を買った。
老婆の押しが強かったのもあるが、
何より、 ミアに喜んでほしかったのだ。
ミアに本を渡すと、
想像以上に喜んでくれた。
読むのが楽しみだと笑ってくれた。
面白い本だといいな······。
そう思いながら帰路に就いていると、 どこからか悲鳴が聞こえてきた。
人々が、 逃げるようにこちらへ走ってくる。
ーミアの家の方角からだ。

Page 1-17

嫌な予感がして
アリスはミアの家まで走った。
けれど、もうそこに家はなかった。
周囲は炎で燃え盛り、家だったものは
瓦礫に成り果てていた。
見上げると、空に巨大な黄金が浮いていた。 中央の黄金の箱がくるくると回っている。
あれはまさか神獣?
あの神獣がここら一帯を襲ったの?

Page 1-18

なら、ミアはこの瓦礫の下に・・・・・・。
咄嗟に瓦礫をかき分けようとすると、
ミアに渡した本が瓦礫の上に
落ちているのを見つけた。
本のページが開かれている。
そこに書かれていた文章をみて、 アリスは目を見開いた。

Page 1-19

「神獣が現れ、 友達の家はなくなりました。 これもアリスが不幸を呼んだせいでした」
これは、まさかアリスの事?
アリスがそう思った瞬間、
本がひとりでに閉じた。 それと同時に、
アリスの姿もそこから消えた。

Chapter 2

最上は凶に還る

Page 2-1

気が付くと、アリスは暗闇の中にいた。
目の前にあったはずの瓦礫も本もない。
「ようこそ、 アリス」
暗闇に誰かの声が響く。
だが、見渡しても声の主の姿はない。

Page 2-2

「あなたは誰? ここはどこなの?
「僕は本だよ。 君が買ったあの本。
名前が必要なら、ラミィとでも呼んで。
で、ここは僕の中。簡単でしょ?」
突拍子もない回答に、 アリスは困惑した。
これは、きっと夢だ。
そう思い、頬をつねるが、
痛いだけで何も起こらなかった。

Page 2-3

「くだらないことしてないで、聞いてよ。 君のお陰で、面白い物語が手に入ったよ」 暗闇に巨大な本が現れ、ひとりでに開いた。 白紙のページに文字が浮かび上がってくる。
「アリスは孤独な彼女を救ってくれた
友達さえも、不幸にしてしまいました。
彼女は存在するだけで周りを不幸にします。
アリスは一生、孤独でいるしかないのです」

Page 2-4

「面白いだろう? 素晴らしい悲劇だよね。
はあ、僕ってば天才かり!」
ラミイは恍惚としながら、そう言った。
「まさか・・・・・・ あなたがやったの?」
「違うよ。 やったのは神獣だ」
「じゃあ、あなたは関係ないの?」
「いや、神獣を放ったのは僕だよ?」

Page 2-5

平然と言うラミィに、
沸々と怒りがこみ上げてくる。
なら、こいつのせいでミアは、
あの瓦礫の下敷きに・・・・・・?
「あなたのせいで······
あなたのせいで、 ミアは・・・・・・ ! 」
「ミア?あ、お友達ね。 彼女は無事だよ」

Page 2-6

本がパラパラと捲られ、
また、白紙のページで止まった。
今度は文章と挿絵が浮かび上がってくる。
「ミアは命からがら生き延びましたが、 家も家族も何もかも失ってしまいました。
ああ、アリスのせいだ!
アリスのせいで、 私は不幸になったんだ!」
隣のページには、涙を流し、 嘆き叫ぶミアが描かれていた。

Page 2-7

――その通りだ。
「えっ!それはいいアイデアだね!
アリスが本を買わなければ、本を渡さなければ、
じゃあ死んでみようか!」
ミアは不幸にならなかった。
ミアを不幸にしたのは、
愉しそうに、残酷に、 ラミィは語り続ける。
「君の死を恨みの果てに知り
ミアが恨むべき相手は・・・・・・ アリスだ。
初めて彼女は精神的に成長するんだろうね。
何がいい? 手伝ってあげるよ」
「アリスだけ、不幸になればよかったのに。 最高の死に様じゃないか! あ、死に方は
アリスが死ねばよかったのに・・・・・・」

Page 2-8

全部・・・・・・ アリスのせいだ。
でも······ それでいいの?
このまま一生を終えて、本当にいいの?
ずっと、どうして自分は生きて、大事な人が
死ななければならないのか、疑問だった。
まだアリスは何もできてないのに。
まだミアも、誰も幸せにできてないのに!
死ぬなら自分だ とずっと思っていた。
ミアのために死ねるなら、 それもいいのかもしれない。
「・・・・・・ 待って。 思い付いたよ。 この物語をもっと面白くする方法」
「へえ?」

Page 2-9

「アリスもあなたに協力してあげる。 ここから、 生きて出してくれたらだけど」 アリスの言葉に、 ラミィは笑った。
「いいよ。ああでも、人間のままじゃ
ただ無駄死にするだけか」
ことん、と音がする。 音がした場所に、
虹色に輝く林檎が転がっていた。
グレゴールの林檎だ。
かじれば死ぬか、天使となり、
神獣に対抗する力を得る林檎だと
ミアから聞いたことがある。

Page 2-10

「それ、 あげるよ。 あ、 まさか、 死ぬのが怖いから食べれな~い! なんて言わないよね? アハハ!」
ケタケタ笑う声を無視して、
アリスは林檎を拾った。
死ぬのなんて怖くない。
だけど・・・・・・ まだ、死ぬつもりはない。
「さあ、面白い物語を紡いでみせてよ」
アリスは、 林檎をかじった。

Chapter 3

禍福己による

Page 3-1

目覚めると、 アリスの視界に
瓦礫と毒の炎が広がった。
起き上がり、 自分の姿を確認する。
服が変わり、 背中には翼が生えていた。
どうやら天使になれたようだ。
頭上では黄金の箱を持つ神獣が暴れている。 これ以上、 被害を出すわけにはいかない。 アリスは神獣に飛び込んだ。
だが即座に弾き飛ばされた。

Page 3-2

天使になったものの、
アリスには武器も戦闘技術もない。
幸い、 肉体だけは強靭になり、
すぐに死ぬことはないが、 防戦一方だ。
「なーんだ、 ほどにもないじゃん」
退屈そうな声が横から聞こえてきた。
横を飛んでいたのは、あの本
ラミィだった。
「君に期待した僕が馬鹿だったよ。
勇敢に戦って、ダメでしたーって死ぬだけ?
あーあ、つまんない結末だなぁ」

Page 3-3

確かに、このままでは何も守れず アリスは死ぬだろう。 神獣の攻撃は、 絶え間なくアリスに向かってくる。
ーならば。
アリスはラミィの一部である本を
一冊つかむと、
その本を后代わりに、攻撃を弾いた。
「はあ!? 何するのさ!」
憤慨するラミィに、
アリスは冷静に語り掛ける。
「つまらないなら、力を貸してよ
これはアリスとあなたが紡ぐ
物語なんだから」

Page 3-4

「不幸を呼ぶと言われた少女は、 命を賭けて人類の敵と戦いました。
そして、彼女は見事、不幸に打ち勝ち、 英雄となって人々を救ったのです」
「そんなハッピーエンドが見たくはない?」
アリスは不敵に微笑んだ。
神獣がアリスに向けて、強大な光線を放つ。 これをくらってしまえば、
いくら天使でもひとたまりもないだろう。

Page 3-5

だが、 光線が届くよりも先に、本が
アリスの前に躍り出た。 本は巨大化すると、
ひとりでに開き、 光線を吸収した。
「交渉成立だ。 アリス。
君が英雄となり、死ぬその瞬間まで、 僕の力は君の物だ」
光線を吸収した本が、 アリスの目の前に
やってくる。 アリスは神獣を見据えると、
導かれるまま、 本に触れた。

Page 3-6

本が開く。 その直後、
先ほど吸収した光線が本から放たれた。
光線は神獣に向かって伸び、 直撃する。

Page 3-7

重傷を負った神獣が空の彼方へ逃げていく。 「あの神獣はまた別の人間を殺しに行くよ」
ラミィが面白がるようにささやいた。
そんなことはさせない。
そうなる前に倒しに行かなければ。
神獣を追うべく。
アリスが飛び立ちかけた。 そのとき。
「アリス!」
後ろからそう呼びかけられた。

Page 3-8

振り向くと、ミアが動かない足を
引きずりながら、必死にアリスのほうへ
向かってきていた。
アリスはミアを散々不幸にしてきたのだ。
合わせる顔なんてない。 だけど・・・・・・。 逃げたくなる気持ちを抑え、
アリスはミアに向き合った。
ミアはアリスの傍まで来ると、
力を振り絞ってアリスを抱き締めた。
「無事で良かった。
こんなにボロボロになって・・・・・・」
[Page41]
予想外の状況にアリスは目を見開いた。
「何で・・・・・・全部アリスのせいなのに・・・・・・。
恨まれて、 当然なのに」
「恨めるわけないじゃない。 大事な親友が あたしのためにしてくれたことなんだから」
ミアにどんな恨み言を言われても
受け止めるつもりだった。
なのに、ミアは恨むどころか、こんな自分を
まだ親友だと言ってくれる。
こみ上げる感情に胸が熱くなり、
アリスの頬を涙がつたった。
嬉しくて泣いたのは、初めてだった。

Page 3-9

「ミア。 アリス、 神獣と戦うよ。
たくさんの人々を幸せにするために。
・・・・・・応援してくれる?」
「もちろん。 でも、絶対に死んじゃダメよ。
それと、たまには会いに来て。 あんたがいないと、寂しいから」
アリスは微笑み、強くうなずいた。

Fin.
