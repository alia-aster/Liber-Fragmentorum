Chapter 1

孤児院の秘密

Page 1-1

「アイドラ先生、みんな、 お手紙書くね!」
少女は里親となった夫婦に手を引かれ、 跳ねるように孤児院の門を出て行った。
見送る子供たちは、
笑顔で手を振りながらもどこか寂しそうだ。
「ボクにも早くお迎えが来ないかな」
ぽつりとつぶやいた少年の手を、
アイドラはぎゅっと握った。

Page 1-2

「大丈夫。 次はみんなの番だから。
きっといい人が迎えに来てくれるよ」
「本当? アイドラ先生」
「もちろん! 楽しみだね」
アイドラの言葉に子供たちが笑顔になった。
みんないい子ばかりだ。
孤児院に来た経緯は様々だけどー
これまで、つらい目にあった分、
幸せになって欲しい。
ならなくちゃおかしい。
アイドラはそう思う。

Page 1-3

「先生 先生!
助けてアイドラ先生!」
アイドラが鍵を開けると、 髪を振り乱し、 汚れた少女が転がり込んでくる。
「先生、助けて!」
深夜。 子供の悲痛な叫びと共に
孤児院のドアが叩かれた。
アイドラに必死にすがりついたのは、
半年前、満面の笑みで
孤児院を去った少女だった。

Page 1-4

「もう大丈夫。 先生がいるから」 アイドラは少女を抱きしめる。
やがて、少女は落ち着きを取り戻し、
ソファで眠ってしまった。
「この子、 虐待されたのかもしれない」
集まってきた職員にそう告げる。
いい里親だと思ったのに。
自分の見る目のなさが嫌になる。 アイドラの胸に後悔が押し寄せた。

Page 1-5

しばらくして、軍人たちが孤児院を訪れた。
どうして軍人が?
いぶかしむアイドラの傍で、職員が 逃げてきた少女を引き渡そうとする。
「保護してもらえば安心ですからねぇ」 笑顔の職員に、少女は怯えた顔を見せた。

Page 1-6

「違うの、あいつらが私に変な事をする。 この気持ち悪い林檎を食べさせてくるの」 少女が、持っていた林檎をアイドラに
手渡した。
グレゴールの林檎!
アイドラは聞いたことがあった。
女性を天使化し、 神獣と戦わせるための
オーパーツだと。

Page 1-7

「子供に、どういうつもりですか!」 アイドラは少女と軍人の間に割って入る。
「林檎と子供を、こちらへ渡したまえ」
「早く保護してもらうのよ。 アイドラ」 職員は軍人の味方のようだ。 怯えた少女が
アイドラの背中にしがみつく。
「渡しません!」
アイドラの手の中で、 虹色の林檎が輝く。 食べれば、死ぬこともあると聞く。

Page 1-8

そうか――
軍は天使にするために、
死んでもいい子供と
して、孤児を集めていたのだ。
孤児院も、それに加担していた。
許せない。怒りで頭がクラクラする。 こいつら軍人も、職員たちも、
そして私も。
何も知らず、
「いい人が迎えに来るよ」 なんて言って、
どれだけの子供を犠牲にしてきたのだろう。

Page 1-9

「こんなものがあるから!」
私は林檎をかじった。

Chapter 2

湖の秘密

Page 2-1

[ページ種別：青]
傾き始めた太陽の光を受けて
遙か遠くまで広がる荒野が黄金に輝いた。
まばらに生えた草地に
建てられたテントの合間を
風が吹き抜けていく。
巻き上げられた髪を抑えつつ、
彼女はラクダにくくりつけた
大きな空の皮袋をぽんと叩いた。
「アイドラ姉ちゃーん!」
呼ばれて振り返る。 駆けつける子供たちに、 アイドラは微笑みかけた。

[ページ種別：青]

くしゃくしゃと次々に撫でながら、
アイドラは首を振った。
「だめ。 怪物が出るかも知れないんだぞ?
お前たちにはまだ早いよ。
もっと大きくなったらね」
えー、 と重なる不満の声に
ケラケラと笑いながら、 アイドラはラクダに飛び乗った。

[ページ種別：青]
「日暮れ前には帰ってくるよ!」
行ってきます、 とラクダに揺られながら

テントから少し離れた場所には、大地から
突き出すようにそびえる岩山がある。
アイドラが目指す水源は、 そこにある両だ。
噂では、恐ろしい怪物が出るという。
遊牧民であるアイドラと仲間たちは、 豊かな草地を求めて旅をしている最中だ
そうでなければ湖の近くにテントを
建てたはずだ、とアイドラは口を尖らせた。

Page 2-4

[ページ種別：青]
「こーら、動いて。 動けってば!」
岩山を二分する隘路の入り口で、
ラクダがピタリと動かなくなってしまった。
水源である湖は、この隘路の先にある。 アイドラは小さく溜め息を付いた。 何往復かするかもしれないが、仕方ない。
アイドラはラクダにくくりつけてきた 皮袋を持って、 隘路へと入っていく。
高い岩壁に囲まれているせいだろうか。
進むごとに空気が
冷たくなっていくようだった。

Page 2-5

[ページ種別：青]
「はあ・・・・・・ やっと着いた・・・・・・」
隘路の先の行き止まりに、その湖はあった。
迫る岩壁が大きな湖をぐるりと囲んでいる。

Page 2-6

[ページ種別：青]
アイドラはぷろりと身震いをして
空の皮袋をドサリと降ろす。
「・・・・・・何か、寒い?」
湖は、底から光が溢れるように、
幻想的に輝いていた。
汗をかいたからだろうか。 四方から岩が
覆い迫るような水辺だからだろうか。

Page 2-7

[ページ種別：青]
尽きることを知らないような湖を前にして、
アイドラは急に喉の渇きを覚えた。
ここまでやって来た自分へのご褒美だ。 まずは喉の渇きを癒やそうと、
湖の畔に膝をつく。
輝く何かが水底に沈んでいる。
まるで、空からこぼれ落ちたような、 美しい青の宝石だった。

Page 2-8

[ページ種別：青]
「きれい・・・・・・」
アイドラは澄んだ湖へ手をいれた。
湖の水は心臓が縮み上がるほど冷たい。
あと少しで、 青い宝石に手が届きそうだ。
顔を、頭を、上半身を水中に投げ出
指先を水底の宝石に伸ばす。
あと少し一
アイドラの指先が、ついに宝石に触れた。
ーやった!

Page 2-9

[ページ種別：青]
水面から顔をあげ、取りあげた青い宝石を
天にかざす。
その輝きにみとれていると、背後から
身の毛もよだつ恐ろしい鳴き声が聞こえた。

Page 2-10

[ページ種別：青]
巨大な顎を開く、顔の無い怪物がいた。
ひりゅう
卑竜だ。

[ページ種別：青]
アイドラが悲鳴をあげるより早く、
卑竜がアイドラに飛びかかった。
卑竜の大きな口の中へ、 アイドラが呑み
まれていく。 そのままの勢いで卑竜と アイドラは、 湖面へとなだれ込む。
大きな水柱があがり、 やがて、静かになった。

Chapter 3

私の秘密

Page 3-1

[ページ種別：青]
「う......」
アイドラが目を覚ましたとき、
夜の闇の中、湖の畔に横たわっていた。
「私は•••••• そうだ、 卑竜が!」
とっさに辺りを見回すが、
卑竜の姿はどこにもない。
ただ、暗く沈黙した湖があるだけだった。
「夢・・・・・・?」
光り輝く青い宝石も、
アイドラを喰らった卑竜も、何もない。
夢だったのだろうか?

Page 3-2

[ページ種別：青]
アイドラは重たい身体を引きずるように
湖から離れ、岩山を出た。
辺りはすっかり日が暮れて、
空には満天の星が輝いている。
連れてきたはずのラクダの姿は
どこにもなかった。
卑竜に食べられてしまったのだろうか。
やむなく、 アイドラは徒歩で 仲間たちの元へと帰路を急いだ。

Page 3-3

[ページ種別：青]
野営地の明かりを目にして、
アイドラは泣きたくなるほど嬉しかった。
水汲みはできなかったが、
生きて帰ってこられたのだ。
怒られるくらい、 何でもなかった。
「みんな、 ただいま!」
けれど、 アイドラを出迎えたのは、 仲間たちの悲鳴と、怒号だった。

[ページ種別：青]
「卑竜だ! みんな逃げろ!」 敵意のこもる切っ先が向けられた。
卑竜が追いかけてきたのかと
後ろを振り返ったが、
夜の闇には何の姿も浮かばない。
ゴツン、と頭に石が当たった。
大した痛みもなかったが、思わず頭を手で
押さえる。 その手に、違和感があった。

両手には鋭い爪があった。
身体は冷たく輝く鱗で覆われていた。

[ページ種別：青]
太い尻尾が揺れて、大きな翼が背中に
生えている。
ようやく気付いたアイドラは悲鳴を上げた。
「待って
っ、待って、違う。私だよ イドラだ。 竜じゃないんだ
信じて!!」
卑竜となった身で叫んでも、
誰の耳にも届かない。
仲間たちは逃げ惑った。
アイドラはただ信じてほしくて
彼らに追いすがった。

[ページ種別：青]
「お願いだ、聞いて。 私だよ。
アイドラだ。 アイドラなんだ!」
目の前で子供が。 アイドラは
いつものように、子供を抱え起こした。
「お母さん、 助けて、助けて! おか
暴れる子供を逃がすまいと
おか――」
「痛い!!」
子供が叫ぶ。アイドラの鋭い爪が、
子供の軟らかな肉を裂いていた。
アイドラがわずかに力を込めたその瞬間、 の砕ける音と共に、子供は切れた。
「いやああああああ!」 絶叫をあげた母親が アイドラから子供を奪い返す。

Page 3-7

[ページ種別：青]
「違う違う。こんなはずじゃ
敵が、殺意が、恐怖が、憎しみが
すべてが刃のようにアイドラに向いていた。
(夢だ、夢だ!
こんなの、違う、違う、違う!!)
耐えられなかった。
アイドラは一卑竜は、おぞましい
咆吼を上げると、逃げ惑う人間たちを
すべて殺し尽くすまで止まらなかった。

Page 3-8

「一つは!」
ドクドクと脈打つ心臓の音がうるさい。 アイドラは忙しなく目を動かした。
「あ! みんな、アイドラ先生起きたよー」 子供の声が、軽やかな足音と共に遠ざかり、
複数の足音共に戻ってくる。
孤児院の子供たちと職員だ。
その見慣れた顔ぶれを見て、 アイドラは両手で顔を覆った。
(よかった...... 夢だったんだ)
生々しい夢だったと安堵の息を つきかけて、 アイドラはハッとした。

Page 3-9

「これは・・・・・・私っ」
卑竜の尻尾と翼が生えている。
まるで夢の続きだ。
アイドラは集まってきた子供や職員たちを
怯えた目で見回した。
「先生、 すげーかっこいーね!」
ひとりの少年が言うと、 他の子供たちも
口々にアイドラの尻尾と翼を褒めだした。
その中には、グレゴールの林檎を
アイドラに渡した少女の姿もあった。

Page 3-10

「軍人たちは、あなたが林檎をかじったあと
どうしてか慌てて帰っていったわ」
子供たちをなだめながら、職員が告げる。
「ごめんね、私たちがバカだったの」
アイドラが子供たちを守ろうと天使化を 選択した姿に目が覚めたのだと彼らは言う。
「信じてもらえないかもしれないけれど...
これからは私たちもアイドラと一緒に
子供たちを守るわ」
その言葉を聞いていたアイドラは、 両手を見下ろし、
ゆっくりと首を横に振った。

Page 3-11

夢で子供を引き裂いた爪はここにはない。
けれど、 天使の力は少し間違えただけで
子供たちを傷つけうる、強い力だ。
「私は、この力で神獣を倒すよ」 そうすることが、 孤児院のみんなを
守ることにもきっとつながるから。
「みんな、 元気でね。
いつも見守ってるから!」
アイドラは翼を広げ、 空へと飛び立った。 子供たちが安心して暮らせる世界を、 必ず実現させると誓いながら。
