Chapter 1

光失い未来射す

Page 1-1

アンシーは、旅芸人の一座で生まれた。
大きなテントを積んだトラックで旅をして、 街から街へ行く先々で芸を見せる暮らしだ。
アンシーは、不器用で運動音痴。 たいした芸はできなかったけど、 仲間の芸を見るのが、大好きだった。

Page 1-2

黒煙に塗れた空を見上げると、
そこには神獣の巨体が浮かんでいた。
街は火に包まれ、地面は砕け散っていく。る。
わたしはその渦中で、
為す術もなく力なくへたり込んでいた。
旅芸人の仲間が必死に腕を引いてくれる。 「立て、 アンシー! 死ぬぞ!」
怒鳴られた瞬間
激しい閃光が黒い空を切り裂いた。

Page 1-3

感じたのは強烈な痛みだった。
神獣が放った光を見たのだと理解する前に、
眼球が焼かれていた。
「ぐあ、あぁあぁああっ!」
熱い。 痛い。 痛い痛い痛い。
何も見えない。
ひとりだけ暗闇に取り残されたみたい。
旅芸人の仲間がわたしを抱えて逃げ出す。
運ばれながら、私は震えていた。
このまま目が見えなくなったらどうしよう。

Page 1-4

「ふうむ……視力は戻らんようじゃの」 座の占い師のババの声が聞こえる。
髪を揺らす温かいそよ風と、 座った足に触れる柔らかな野草。
身体で感じることはできても
見ることはできない。
恐ろしい神獣が街を去り、
旅芸人の一座が街を後にしてからも、 わたしの目の前は真っ暗なままだった。

Page 1-5

ババのしわだらけの手が、
わたしの頬をいたわるように撫でる。
「かわいそうに……
そうじゃなぁ。
ババの力
をあげようか」

Page 1-6

翌朝、 わたしは目を開けすぐに飛び起きた。
見えてる！ 視力が戻っている！
「ありがとう、ババ！」
「もうひとつの約束。
飛び跳ねるわたしに、ババは口を開いた。
「いいかい、アンシー。
ふたつ約束をして。
これから先、見えるはずないものが 視えたとしても、人に
喋ってはいけないよ」
虹色の林檎を
かじってはいけない」
「分かった！」
わたしはとにかく嬉しくて
すぐに答えた。

Page 1-7

鏡を見ると、瞳の色が変わっていた。
それは磨かれた宝石のようであり 夜にいっとう光る星のようでもあった。
わたしはすぐにその色を気に入った。
見えるはずないものが視えても、
人に喋ってはいけない。
それが何を意味するのか、
すぐに分かった。

Page 1-8

わたしは未来が視えるようになったのだ。
ひらりと舞う蝶々を見かければ、 そのすぐあとに鳥に食われる未来を
旅芸人の仲間が高い梯子に登れば、 落ちて骨を折る未来を。
――ババが老いて弱り、
旅の道中で死んでしまう未来を
見えた未来は、必ずその通りになった。 大好きなババは、よく晴れた日の朝、
旅するトラックの荷台で
息を引き取った。

Page 1-9

約束をやぶってごめんね、ババ。
ババが亡くなってから、
わたしは未来を視る力を利用して
占い師になった。
本当にごめん。
でも、わたしには
他に取り柄がないの。

Page 1-10

「おい！ チャンスがやってきたぞ！」
ある日、団長が上機嫌で帰ってきた。 どうやら、景気の良い街の大きな広場を
使わせてもらえることになったらしい。
「実はあそこの市長は、
若い頃世話してやったことがあってな！」
「さっすが団長！ 人望ある！」
団長と仲間たちは両手を叩き合い、
前祝いとでもいうように
酒を用意し始める。
わたしも輪に加わるつもりだった。
でも、一歩前に出た足が止まる。
「がっぽり稼ぎましょうぜ!!」

Page 1-11

――あ。
視えてしまった。
炎で燃えるわたしたちのテントが。
焼け野原に転がる
虹色の林檎を拾う自分が。
「待って! やめたほうがいいんじゃない?」
水を差すとわかっても、わたしは口にした。
わたしの占いは――
未来を視る力は当たる。

Page 1-12

「何を言っているんだ、アンシー。
またとないチャンスなんだぞ。
うまくいけば、きっとババだって喜ぶ」 団長に続き、 そうだそうだとみんなが言う。
ババの名前を出されると何も言えない。
「……そっか、そうだよね」
視えた未来は、きっと気のせいだ。
自分自身に言い聞かせながら、
わたしは未来を見て見ぬふりをした。

Chapter 2

ふたつめの約束

Page 2-1

――視た未来は現実になった。
わたしは焦げ落ちたテントを見て 呆然と立ち尽くす。
神獣が襲ってきたのだ。
大きな広場は見る影もなく、
建物は焼け崩れ、道はえぐれている。

Page 2-2

呆然と立ち尽くすわたしの視線の先に、
虹色の林檎が落ちている。
焼け野原に不自然なほど綺麗に輝く それは、先日視た光景と全く同じだった。
わたしは林檎を拾う。
旅芸人の仲間たちは散り散りになった。
これからは、ひとりで生きて
いかなければならない。

Page 2-3

「さあさあ、そこの御人！
わしがおぬしの未来を占ってやるぞよ！」 帝都の街の隅に小さな屋台を構え、 わたしは通りかかる人に声をかける。
「あたしと彼の未来を占って！」
「病気のこの子がどうなるか教えて……！」
「鳩の喫茶店がうまくいくか知りたい」
「実は国の機密に関わる占いを……」
「別れる」 「治る」
「女性客多し」 「即、処刑」
視えた未来をそのまま言うだけで、 あれよあれよと大評判。
帝都に流れ着いてはや一年。
裏八丁ではじめた占い稼業は
思いのほか成功し、当たるたびに大騒ぎ。
わたしはすっかり有名人になっていた。

Page 2-4

「さあさあ、お次は誰の未来を
おや? おやおや?」
衛兵がこそっと耳打ちした依頼主は 「皇帝」だという。
その日やってきたお客は、
かっちりと軍服を着た衛兵だった。 「占い師アンシー。 さるお方がお呼びだ」
なんとわたしをこのまま宮殿に
連れていきたいと言うではないか。

Page 2-5

わたしはいちもくさんに
「行きます!!」
と立ち上がった。
まさかまさかの人生大逆転!
宮廷占い師になれるかもしれない!!
浮かれ気分を隠すこともないまま。
わたしは衛兵についていった。
気に入られれば、 今後の人生は安泰だ。 根無し草の人生もこれで終わるのだ。

Page 2-6

わたしはすっかり人生勝った気でいた。
しかし宮殿の門をくぐる時、
わたしは足を止めるはめになる。
――あれ？
また視えてしまったのだ。
薄曇りの下で、重たい刃が吊るされている。
処刑台だ。
その下で捕えられているのは、 わたしだ。

Page 2-7

逃げてたまるか。
人生が上に向き始めると、 必ず良くない未来が視える。 そんな日々にはうんざりだ。 なら、未来を変えてやればいい。
わたしは震える足を再び進めた。
処刑台に送られる前に、
この足で逃げてやればいいのだ。
わたしは衛兵の後をついて、
宮殿内の謁見の間に入る。

Page 2-8

そして一息吐く間もなく、
皇帝と正面から向き合わされた。
「占いの力を見せてもらおう」
……いきなりですか!?
「陛下は戦の行く末を気にしておられます」
白ひげをたくわえた従者が耳打ちする。 そんなものを占いで視ようとするな。
「では占ってしんぜましょう……」 心の準備も整っていなかったが、 それらしく始めてみるしかない。
だが、何も視えなかった。

Page 2-9

数分が経ち、 従者が呆れたように息を吐く。
皇帝からの刺すような視線が痛い。
「何も視えません」
正直に答えるしかなかった。
「何も視えない?
それは、余の未来が暗黒だということか?」
皇帝は怒りと嫌悪を滲ませた。

Page 2-10

（あ、処刑される……）
わたしは空にいるババを思い出す。 きっとこうなると分かっていて、
ババは力のことを喋るなって言ったんだ。
だが後悔しても遅い。
「連れて行け」
皇帝は凍てつくような目で わたしを見下ろし、立ち去っていった。
衛兵たちに両側から挟まれる。
「いたっ……」
引っ張り上げられたその時
わたしの懐から林檎がこぼれ落ちた。

Page 2-11

瞬間、目の前が淡く光る。
視えた。
漆黒の羽の先にある宝石のような瞳。
わたしが、天使になっている。

Page 2-12

怒鳴られ引きずられながら、
わたしは必死に首を伸ばして抵抗した。
ちぎれるほどに腕を引かれるが、
亀のように這いつくばり――
ごめんババ！
わたしは林檎を、 かじった。

世界の未来は

[ページ種別：青]
これは夢なのだろうか。
世界の滅亡を視るアンシーの瞳は 彗星と同じ輝きを放っている。
「アンシー」
名を呼ばれはっと周囲を見る。
そこにはアンシーと
同じ目をした人たちが大勢いた。 その中に、懐かしい顔を見つける。

Page 3-3

[ページ種別：青]
「ババ！」
アンシーを呼んだのは、
死んだはずの占い師のババだった。
「ここに来るとは……。
約束を守れなかったんじゃな」
「ごめん……」
視えたものを人に言わない。
虹色の林檎を食べない。
どちらの約束もアンシーは破ってしまった。

[ページ種別：青]
「これはな、 アンシー。
世界の終わりの光景なんじゃよ」 ババの手がアンシーの頭を撫でる。
「世界は終わってしまうの？」
「ふうむ……」
アンシーは信じられないというように
アンシーは再び終わりに目を向ける。
大きな目を瞬いた。
「たぶんね」
地球は彗星の衝突により、散っていく。
それでもアンシーは笑った。
ババは恐れることもなく穏やかに答えた。
「いくら未来を視ようとしても、
最後にはこの景色しか
見えなくなるのじゃ」

[ページ種別：青]
「でもなんとかなるよ、きっと」
根拠はないが
希望は少女の中にある。
ババはそれを知り、
あたたかく目を細めた。

Page 3-6

「ん……はっ！ あれ!?」
わたしは目を開けた。
林檎をかじって気を失ってから、
しばらく時間が経ったらしい。
(林檎を食べて死ななかったってことは・・・・・・ わたし、 天使になったんだ!やった!) 歓喜に打ち震え、
さらば宮殿とばかりに 逃げてやろうとしたが、腕が動かない。
腕どころではない、足もだ。
「んん?」
身体を見下ろすと、わたしを包む柔らかい
皮の上から、鎖が巻かれている。
頭上には見覚えのある光景が広がっていた。 薄曇りの下で、重たい刃が吊るされている。 ――処刑台だ。
その下で捕えられているのは、わたしだ。

Page 3-7

「これじゃあ視た未来と同じじゃない!」
嘆き叫んでいると、
死刑執行人が近づいてくるのが見えた。
占いで未来が視えなかっただけで、
なにもここまで…… と思ったが、
処刑台の刃につながる紐を
死刑執行人が切り落とそうとする。 刃が落ちれば首ちょんぱだ。
皇帝が占いに頼るような
弱いところがあると
国民に知れては困るのだろう、と。

Page 3-8

「死んでたまるかー!!」
わたしは力任せに鎖を引きちぎった。 そのまま、翼を広げ、 空へと飛び立つ。
死刑執行人も衛兵も従者も、
呆気に取られ、私を見上げている。
「危なかったぁ、でもわたしすごい！」
わたしは翼を羽ばたかせ、
高く高く、雲を破るように昇った。

Page 3-9

帝都は小さなミニチュアになっていく。 地面が、 国土が、大地が――
綺麗な星の輪郭が視えるようだった。
「いい景色だね、ババ」
大好きな人を想い心に決める。
いつか世界が終わるとしても
わたしは未来を生き延びてやる、と。
